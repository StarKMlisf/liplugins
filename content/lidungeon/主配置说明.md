# 主配置说明

主配置位于 `plugins/LiDungeon/config.yml`。修改前备份，修改后可用 `/lidungeon reload` 重载；世界池、依赖和服务端加载顺序变更建议完整重启。

## General

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `Language` | `zh_CN` | `lang/` 下不含 `.yml` 的语言文件名 |
| `PartyPlugin` | `Default` | 队伍提供方；`Default` 为内置队伍 |
| `PartyChat` | `false` | 是否启用内置队伍聊天 |
| `MaxInstances` | `10` | 全服最多同时运行的地牢实例数，必须至少为 1 |
| `InstanceLoadTimeout` | `60` | 实例加载最长等待秒数，复杂 Folia 地牢建议不低于 60 |
| `AutoSaveInterval` | `300` | 编辑实例自动保存间隔，秒；0 关闭 |
| `FunctionBuilderItem` | `FEATHER` | 功能构建器 Bukkit 材质 |
| `RoomEditorItem` | `GOLDEN_AXE` | 程序化房间工具材质 |
| `StuckKillsPlayer` | `false` | `stuck` 是传送到检查点，还是让玩家死亡走重生流程 |
| `LeaderOnlyQueue` | `true` | 是否仅队长可为队伍发起 |
| `ReadyCheckOnCommand` | `true` | 命令直接进入前是否准备确认 |
| `ReadyCheckInQueue` | `true` | 排队获得实例后是否准备确认 |
| `ReadyCheckTime` | `45` | 准备确认秒数 |
| `StartWithoutUnreadyPlayers` | `false` | 超时后是否只带已准备玩家 |
| `ReadyCheckRequireLeader` | `true` | 非全员进入时是否至少要求队长准备 |
| `MultiverseGroup` | `default` | Multiverse-Inventories 使用的分组名 |

`General.PartyFinder.AutoBroadcast` 控制定时招募广播，`ListingBroadcastPeriod` 是分钟间隔。

全服实例上限与单地牢 `General.MaxInstances` 会共同限制并发。Folia 还受世界池容量限制：某维度只有 2 个有效池世界时，不可能让该维度同时独占 3 个池实例。

## Generator

`Generator.Timeout` 是程序化布局计算的最长秒数，默认 5。布局频繁失败时先修房间连接、包围盒、最小数量和严格条件，再逐步提高超时。

## Folia.MultiWorld

```yaml
Folia:
  MultiWorld:
    Enabled: true
    Worlds:
      NORMAL: []
      NETHER: []
      THE_END: []
```

列表只能填写插件加载地牢前已经加载完成的 Bukkit 世界名，并且世界环境必须与配置段一致。空列表、未加载或维度不匹配会记录中文警告并回退到远端隔离模式。

详细部署见 [Folia 与多世界实例](Folia与多世界.md)。

## Experimental

| 字段 | 默认值 | 风险 |
| --- | --- | --- |
| `MovingBlocksMoveEntities` | `false` | 让移动方块带动上方实体；网络延迟和起跳仍可能异常，向上移动要求 `allow-flight=true` |
| `OneWorldDungeons` | `false` | Paper 把实例放入专用容器世界；Folia 会强制使用容器/池模型 |

`OneWorldDungeonsWorld` 可设置难度、时间、天气和游戏规则。固定时间只有 `doDaylightCycle=false` 时持续有效；固定天气只有 `doWeatherCycle=false` 时持续有效。

## Spectator

`UseLegacy: true` 使用旧版旁观系统。设为 `false` 时使用依赖 PacketEvents 的现代旁观系统，增删 PacketEvents 后应重启。

`Hotbar` 可设置传送、设置和离开物品的材质、槽位、名称、Lore。槽位范围 0 到 8。

`GUI.Teleport.GuiTitle` 和 `GUI.Settings.GuiTitle` 是当前实际读取的标题键。`Title` 是旧版兼容键。夜视当前读取 `NightVision.ItemSlot` / `ItemLore`，飞行速度读取 `FlySpeed` 段；旧 `Slot`、`Lore`、`Speed` 段仅为已有配置兼容。

## 配置修改没有生效

按实际读取链排查：

1. 确认改的是 `plugins/LiDungeon/config.yml`，不是 Jar 内资源或备份。
2. YAML 缩进使用空格，不使用 Tab。
3. 执行 `/lidungeon reload` 并观察成功或解析报错。
4. 世界池与可选依赖变更完整重启。
5. 确认某个地牢没有用同名覆盖字段覆盖全局值。
6. 重启后重新打开文件，确认面板或同步脚本没有恢复旧内容。

配置“存在”不等于运行时“读取了该路径”。本页明确标出的兼容键不要作为新配置主键。
