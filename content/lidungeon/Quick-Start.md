# 五分钟快速开始

## 1. 备份并部署

1. 停服，备份 `plugins/LiDungeon/`（配置与数据）
2. 替换 `LiDungeon-*.jar`
3. 启动一次，确认插件中文化初始化日志
4. 检查 `plugins/LiDungeon/` 下已生成缺失配置

## 2. 快速可玩流程

1. 玩家运行：
   - `/lidungeon help`
2. 服主进入编辑：
   - `/lidungeon edit dwdw`
3. 设置出生点与终点区，补齐出口与奖励
4. 保存退出编辑并退出
5. 玩家测试：
   - `/lidungeon play dwdw`
   - 结束后执行 `/leave`

## 3. 首次建议

- 先按默认配置启动一次，再开始深度定制
- 记录每次编辑和重载时间点，便于回退与排障
- 多世界副本建议先配置实例池再对外开服
