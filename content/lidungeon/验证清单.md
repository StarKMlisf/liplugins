# 上线验收清单

本页适合每次安装、升级、迁移或修改大型地牢后逐项勾选。

## A. 启动与版本

- [ ] 服务端与 Java 版本符合支持范围。
- [ ] `plugins/` 中只有一个 LiDungeon Jar。
- [ ] `/lidungeon help` 显示 `2.0.1-zhcn-folia.8` 和中文帮助。
- [ ] 无依赖下载失败、类缺失或 YAML 解析错误。
- [ ] 基础环境加载 38 功能、15 触发器、9 条件；可选依赖数量变化符合预期。
- [ ] 旧 `/md` 没有出现在菜单、NPC、公告和玩家教程。

## B. Folia 与实例容量

- [ ] 每个池世界在 LiDungeon 初始化前已加载。
- [ ] 世界环境与 NORMAL/NETHER/THE_END 列表一致。
- [ ] 日志报告的有效池数量符合配置。
- [ ] 计划并发不超过池数、全局上限和单地牢上限的最小值。
- [ ] 空闲、满池、排队、实例清理和再次分配都测试通过。
- [ ] 没有 watchdog、跨区域非法访问或全局线程同步等待。

## C. 创建与编辑

- [ ] `create`/迁移后地牢目录完整。
- [ ] `edit` 可进入且不会卡主线程。
- [ ] 大厅、正式出生点和出口位置正确。
- [ ] `functiontool` 可打开完整菜单。
- [ ] 程序化地牢 `roomtool`、房间边界、连接点和门正确。
- [ ] `save` 成功，正常退出后重启再编辑仍保留。
- [ ] 自动保存不会造成明显卡顿。

## D. 玩家进入

- [ ] 普通玩家可用 `/lidungeon play <地牢>`。
- [ ] 无权限玩家被正确拒绝。
- [ ] 最小/最大队伍人数正确。
- [ ] 队员距离与跨世界处理正确。
- [ ] 准备、取消准备、超时和队长要求正确。
- [ ] 费用只扣一次，余额不足不进入。
- [ ] 钥匙匹配、消耗、队长模式正确。
- [ ] 冷却开始时机和绕过权限正确。
- [ ] 难度菜单、直写难度权限和倍率正确。

## E. 地牢流程

- [ ] 地牢开始触发器执行一次。
- [ ] 每个关键触发器用消息功能单独验证过。
- [ ] 条件通过与反向分支都验证过。
- [ ] 生物死亡计数、半径和 Mythic ID 正确。
- [ ] 门、红石、远程信号没有循环触发。
- [ ] 检查点、死亡、耗尽生命和旁观正确。
- [ ] 断线重连和战斗退出惩罚正确。
- [ ] 时间限制和无人清理正确。

## F. 完成与奖励

- [ ] 终点使用“完成地牢”，不是只离开。
- [ ] 完成记录写入并在重启后保留。
- [ ] 前置地牢条件正确。
- [ ] 普通、随机、战利品表奖励正确。
- [ ] `GiveLootAfterCompletion` 开/关都符合设计。
- [ ] 背包满、奖励冷却、重复触发和中途退出已测试。
- [ ] 完成/离开/失败的 AccessCooldown 时机正确。

## G. 规则与数据恢复

- [ ] 非 OP 测试了放置、破坏、桶、容器、合成、拾取、爆炸和命令。
- [ ] 背包、生命、饥饿、经验、药水效果进出恢复正确。
- [ ] Multiverse-Inventories 没有与 LiDungeon 恢复链冲突。
- [ ] 地牢物品和禁用物品不能异常带出或复制。
- [ ] 每日备份包含 maps、globalplayerdata、主配置、语言和当前 Jar。
- [ ] 已在隔离测试服完成一次恢复演练。

## H. 发布记录

记录以下信息，便于下次快速回滚：

```text
发布日期：
服务端构建：
Java：
LiDungeon 版本与 SHA-256：
可选依赖版本：
地图版本/备份路径：
世界池列表：
验证人员：
已知限制：
```

任何一项关键流程未验证，都应标为“未验证”，不要写成“已兼容”或“已修复”。
