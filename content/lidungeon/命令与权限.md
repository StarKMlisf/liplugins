# 命令与权限

对外主指令统一为 `/lidungeon`。一级子命令提供按权限过滤的 Tab 补全，`/lidungeon help [页码]` 也只显示当前发送者可用的命令。

## 玩家与队伍命令

| 命令 | 用途 | 主要权限 |
| --- | --- | --- |
| `/lidungeon help [页码]` | 分页帮助 | `lidungeon.core` |
| `/lidungeon play <地牢>[:难度] [玩家]` | 自己进入，或为指定玩家发起 | `dungeons.play`；替他人需要 `dungeons.play.send`；直写难度需要 `dungeons.play.difficulty` |
| `/lidungeon leave` | 离开当前地牢 | `lidungeon.core` |
| `/lidungeon stuck` | 返回检查点或死亡重生 | `dungeons.stuck` |
| `/lidungeon lives` | 查看剩余生命 | `lidungeon.core` |
| `/leave` | 快速离开 | `lidungeon.quickleave` |
| `/stuck` | 快速卡点自救 | `lidungeon.quickstuck`，实际处理仍检查 `dungeons.stuck` |
| `/ready` / `/notready` | 确认/取消准备 | `lidungeon.ready` / `lidungeon.notready` |
| `/recruit` | 招募队友 | `lidungeon.recruit`，玩法动作还可能检查 `dungeons.party.recruit` |
| `/rewards` | 奖励仓库 | `lidungeon.rewards` |
| `/party` | 内置队伍系统 | `lidungeon.party` |
| `/p <消息>` | 内置队伍聊天 | `lidungeon.party.chat` |

## 创建与编辑命令

| 命令 | 用途 | 权限/限制 |
| --- | --- | --- |
| `/lidungeon create <名称> [类型] [生成器] [维度]` | 创建空白地牢 | `dungeons.admin`，仅玩家；Folia 不建议运行期使用 |
| `/lidungeon import <世界> [维度]` | 导入服务端世界 | `dungeons.admin` |
| `/lidungeon dxlimport <DXL地图>` | 导入 DungeonsXL 地图 | `dungeons.admin`，需要可转换的数据 |
| `/lidungeon edit <地牢>` | 打开已有地牢编辑会话 | `dungeons.edit` 或 `dungeons.edit.*`，并检查 `dungeons.edit.<地牢>` |
| `/lidungeon save [force]` | 保存当前编辑实例 | `dungeons.edit`；`force` 主要用于程序化房间 |
| `/lidungeon setlobby` | 设置大厅出生点 | `dungeons.edit`，必须在编辑实例中 |
| `/lidungeon setspawn` | 设置正式出生点 | `dungeons.edit`，必须在编辑实例中 |
| `/lidungeon setexit <地牢>` | 把当前位置设为出口 | `dungeons.edit` 或 `dungeons.edit.*` |
| `/lidungeon functiontool` | 领取功能构建器 | `dungeons.functioneditor`，必须在编辑模式 |
| `/lidungeon roomtool` | 领取房间工具 | `dungeons.roomeditor`，仅程序化编辑实例 |
| `/lidungeon cleansigns` | 清理功能位置告示牌 | `dungeons.cleansigns` |
| `/lidungeon addregion` / `removeregion` | 添加/移除地牢区域标记 | `dungeons.edit` |

## 物品、钥匙与奖励命令

| 命令 | 用途 | 权限 |
| --- | --- | --- |
| `/lidungeon addkey <地牢>` | 把手持物品加入进入钥匙列表 | `dungeons.edit`/`dungeons.edit.*`，并检查地牢级编辑权限 |
| `/lidungeon removekey <地牢>` | 移除匹配的手持钥匙 | 同上 |
| `/lidungeon givekey <玩家> <地牢>` | 发放一个地牢钥匙 | `dungeons.admin` |
| `/lidungeon banitem` / `unbanitem` | 在当前地牢禁用/解除手持物品 | `dungeons.edit`，必须在编辑模式 |
| `/lidungeon dungeonitem` | 把手持物标为地牢物品 | `dungeons.edit`，必须在编辑模式 |
| `/lidungeon loot create <名称>` | 创建并打开战利品表 | `dungeons.loottables` |
| `/lidungeon loot edit <名称>` | 编辑战利品表 | `dungeons.loottables` |
| `/lidungeon loot remove <名称>` | 删除战利品表 | `dungeons.loottables` |

## 运维与救援命令

| 命令 | 用途 | 权限 |
| --- | --- | --- |
| `/lidungeon status [地牢]` | 查看活动地牢和实例 | `dungeons.admin`，游戏内执行 |
| `/lidungeon reload [地牢\|all]` | 重载全局或地牢配置 | `dungeons.admin` |
| `/lidungeon delete <地牢>` | 删除地牢，第二次执行确认 | `dungeons.admin` |
| `/lidungeon join <玩家>` | 进入指定玩家所在实例 | `dungeons.admin`，不是玩家进本命令 |
| `/lidungeon kick <玩家>` | 把玩家移出当前地牢 | `dungeons.admin` |
| `/lidungeon force <玩家> <地牢>[:难度] [选项]` | 跳过队列与准备强制进入 | `dungeons.play.force` |
| `/lidungeon setcooldown <地牢> <玩家> [时长]` | 设置进入冷却 | `dungeons.setcooldown` |
| `/lidungeon resetcooldown <玩家> [地牢]` | 清除一个或全部地牢冷却 | `dungeons.resetcooldown` |
| `/lidungeon getmap` | 获取当前地牢地图 | `dungeons.admin` |
| `/lidungeon testdoor <门>` / `testalldoors` | 测试程序化房间门 | `dungeons.admin` |

`force` 可选参数为：

```text
bypassreqs=true|false
party=true|false
allowindungeon=true|false
```

默认分别为 `true`、`false`、`false`。它适合管理员救援和测试，不适合普通玩家入口。

## 权限分组建议

### 普通玩家

```text
lidungeon.core
lidungeon.quickleave
lidungeon.ready
lidungeon.notready
lidungeon.recruit
lidungeon.quickstuck
lidungeon.rewards
lidungeon.party
lidungeon.party.chat
dungeons.play
dungeons.stuck
dungeons.party.recruit
```

### 地牢设计师

在玩家权限基础上按需增加：

```text
dungeons.edit
dungeons.edit.<地牢ID>
dungeons.functioneditor
dungeons.roomeditor
dungeons.loottables
dungeons.cleansigns
```

地牢级限制要结合权限插件行为测试。不要只授予 `dungeons.edit.<地牢>` 却漏掉命令入口所需的父级节点。

### 管理员

```text
dungeons.*
lidungeon.*
```

`mythicdungeons.*` 是早期中文版本误用节点的兼容入口，新权限组统一使用 `lidungeon.*`。`dungeons.*` 仍是地牢玩法与管理的内部兼容权限，不应改名。
