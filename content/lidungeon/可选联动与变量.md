# 可选联动与变量

可选插件必须在 LiDungeon 之前成功加载。运行中安装 Jar 后使用重载通常不足以注册新菜单、监听器和 API，应完整重启。

## PlaceholderAPI

LiDungeon 的 PAPI 标识为 `md`，这是为了兼容既有菜单和地图，不随主命令更名。

### 当前实例变量

| 占位符 | 输出 |
| --- | --- |
| `%md_dungeon_name%` | 地牢 ID |
| `%md_dungeon_display_name%` | 显示名 |
| `%md_dungeon_id%` | 实例世界名 |
| `%md_dungeon_players%` | 当前玩家数 |
| `%md_dungeon_players_living%` | 存活玩家数 |
| `%md_dungeon_lives_left%` | 当前玩家剩余生命或“无限” |
| `%md_dungeon_time_left%` / `_seconds%` | 剩余时间 |
| `%md_dungeon_time_elapsed%` / `_seconds%` | 已用时间 |
| `%md_dungeon_dead%` | 死亡玩家数 |
| `%md_dungeon_spectators%` | 旁观者数 |
| `%md_dungeon_progress%` | 时间进度百分比 |
| `%md_dungeon_progress_fraction%` | 0 到 1 的小数进度 |
| `%md_dungeon_environment%` | NORMAL/NETHER/THE_END |
| `%md_dungeon_max_players%` | 配置最大人数 |
| `%md_dungeon_time_limit%` | 生效的时间限制 |
| `%md_dungeon_time_limit_formatted%` | 格式化时间限制 |

不在地牢中的玩家对部分实例占位符会得到空白；展示前要测试菜单插件对空白和 `null` 的处理。

### 程序化房间与怪物

| 占位符 | 输出 |
| --- | --- |
| `%md_dungeon_room_name%` | 当前房间模板名 |
| `%md_dungeon_room_rotation%` | 当前房间旋转 |
| `%md_dungeon_room_depth%` | 房间深度 |
| `%md_dungeon_rooms_total%` | 房间总数 |
| `%md_dungeon_rooms_cleared%` | 已清理房间数 |
| `%md_dungeon_rooms_remaining%` | 剩余房间数 |
| `%md_dungeon_mobs%` | 当前追踪 Mythic 生物数 |
| `%md_dungeon_mobs_<MobID>%` | 指定 MythicMob 数量 |

房间统计只适用于程序化实例；经典地牢通常输出空或 0。

### 指定地牢与玩家进度

把 `<id>` 替换为地牢 ID：

```text
%md_dungeon_<id>_lives%
%md_dungeon_<id>_min_players%
%md_dungeon_<id>_max_players%
%md_dungeon_<id>_unlock_time%
%md_dungeon_<id>_unlock_time_seconds%
%md_dungeon_<id>_finished%
```

### 队伍与招募

```text
%md_party_leader%
%md_party_size%
%md_party_in_dungeon%
%md_party_queued%
%md_party_member_1%
%md_party_member_1_health%
%md_alive_member_1%
```

招募变量使用在线发起者名字：

```text
%md_recruitment_<玩家>_host%
%md_recruitment_<玩家>_label%
%md_recruitment_<玩家>_description%
%md_recruitment_<玩家>_players_present%
%md_recruitment_<玩家>_players_needed%
%md_recruitment_<玩家>_total_players%
%md_recruitment_<玩家>_needs_password%
```

## MythicMobs

安装后会启用：

- Mythic 生物死亡计数器；
- Mythic 条件；
- Mythic 技能功能；
- Mythic 信号功能；
- 支持 Mythic 掉落表的奖励；
- 地牢进入 `JoinSkill` 与 `denyjoin` 机制；
- 一组地牢条件、目标器、机制、触发和占位符。

Mythic ID 区分拼写。升级 MythicMobs 后必须在测试服验证技能加载、信号目标、怪物追踪和跨区域执行，不要只确认插件显示绿色。

## Citizens

Citizens 成功加载后出现“NPC 生成器”。配置已有 NPC ID 和朝向。实例复制、房间旋转、玩家离开与实例清理后都应检查 NPC 是否重复、残留或丢失。

## Vault

Vault 与一个实际经济实现共同存在时，`Requirements.Cost` 才能扣费。测试：

- 余额不足不进入；
- 成功进入只扣一次；
- `LeaderOnlyCost` 符合预期；
- 排队取消、加载失败时是否出现异常扣费；
- `dungeons.bypasscost` 只授予管理员。

## PacketEvents 与旁观

`Spectator.UseLegacy: false` 使用现代旁观系统并依赖 PacketEvents。缺失或版本不兼容时先改回 legacy 或修复 PacketEvents，再重启。

## 队伍插件

`General.PartyPlugin` 决定队伍提供方。使用外部队伍插件时，要验证队长识别、成员列表、跨世界距离、离队、断线和队伍聊天。第三方 API 的“队伍中只有自己”可能被 LiDungeon 当作无队伍处理。

## Multiverse

Multiverse-Core 可用于管理服主预建世界，但 Folia 世界池要求世界在 LiDungeon 初始化前已经加载。Multiverse-Inventories 使用 `General.MultiverseGroup` 分组；若同时由 LiDungeon 保存/恢复背包，必须测试避免两套插件互相覆盖。
