# 玩家游玩指南

玩家日常只需要记住 `/lidungeon play` 与 `/lidungeon leave`。`/lidungeon join` 不是玩家进本命令，它用于管理员进入指定玩家所在的实例。

## 进入地牢

```text
/lidungeon play <地牢>
```

若地牢启用了难度菜单，未写难度时会打开菜单。拥有 `dungeons.play.difficulty` 的玩家也可直接指定：

```text
/lidungeon play tutorial:HARD
```

服主或控制台替其他在线玩家发起：

```text
/lidungeon play tutorial 玩家名
```

该写法需要 `dungeons.play.send`。

## 进入前会检查什么

插件可能按地牢配置依次检查：

- `Requirements.Permissions`：额外权限列表；
- `MinPartySize` / `MaxPartySize`：队伍人数；
- `MaxPartyDistance`：队员与队长的距离和世界；
- `DungeonsComplete`：前置地牢是否已完成；
- `PlayerLevel` / `PlayerLevelType`：原版或 MythicRPG 等级；
- `Cost`：Vault 经济费用；
- `AccessKeys`：进入钥匙；
- `AccessCooldown`：进入冷却；
- `JoinSkill`：MythicMobs 自定义进入条件。

管理员绕过权限 `dungeons.bypasscost`、`dungeons.bypasskeys`、`dungeons.bypasscooldown`、`dungeons.bypassjoin` 不应授予普通玩家。

## 队伍、排队与准备

全局设置通常由以下字段决定：

- `LeaderOnlyQueue`：是否只有队长可发起；
- `ReadyCheckOnCommand`：命令进入前是否确认；
- `ReadyCheckInQueue`：排队获得实例后是否确认；
- `ReadyCheckTime`：确认时限；
- `StartWithoutUnreadyPlayers`：超时后是否只带已准备玩家；
- `ReadyCheckRequireLeader`：未全员准备时是否至少要求队长准备。

快捷命令：

| 命令 | 用途 |
| --- | --- |
| `/ready` | 确认准备 |
| `/notready` | 取消准备 |
| `/recruit` | 创建或加入内置招募 |
| `/party` | 内置队伍管理 |
| `/p <消息>` | 队伍聊天；需启用 `General.PartyChat` |

某个地牢可在自己的 `config.yml` 覆盖全局准备设置，也可以使用 `IgnoreParties: true` 让每名玩家独立进入，适合持续型副本。

## 地牢内常用命令

| 命令 | 用途 | 注意 |
| --- | --- | --- |
| `/lidungeon lives` | 查看剩余生命 | `PlayerLives: 0` 表示无限 |
| `/lidungeon stuck` 或 `/stuck` | 返回最近检查点 | 若全局 `StuckKillsPlayer: true`，会改为让玩家死亡并走重生流程 |
| `/lidungeon leave` 或 `/leave` | 保存进度并离开 | 不等同于完成；离开监听器可阻止普通离开 |
| `/rewards` | 查看奖励仓库 | 仅在存在待领取奖励时有意义 |

若 `Rules.AllowCommands: false`，只有地牢 `AllowedCommands` 白名单里的命令可用。默认白名单包含队伍命令与离开命令；服主修改后应重新测试。

## 死亡、旁观与复活

- `PlayerLives: 0`：无限生命。
- `InstantRespawnPlayers: true`：跳过原版死亡界面。
- `DeadPlayersSpectate: true`：耗尽生命后进入旁观，否则直接离开实例。
- `CloseDungeonWhenAllSpectating: true`：全员旁观后关闭实例。
- “玩家复活器”功能可让仍在旁观的死亡玩家被队友复活。
- “重生检查点”功能决定死亡后的返回位置；断线重连也可按 `ReturnToCheckpointOnRejoin` 回到最近检查点。

## 无法进入时先看提示

“人数不足”“离队长太远”“没有钥匙”“冷却中”“费用不足”对应不同检查，不要让管理员直接使用 `force` 掩盖配置问题。只有测试或紧急救援时才建议使用强制进入。
