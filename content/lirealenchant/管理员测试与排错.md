## 启动检查

正常启动应包含类似日志：

```text
LiRealEnchant2 v2.0.0-dev196-paper26 已启用；
单附魔配置已读取 122/122，跳过 0，重复 ID 0；
Registry 注册 122/122
```

优先处理最早出现的错误，不要只看后续“插件已禁用”。

## 管理员快速测试

```text
/lre testkit <玩家>
/lre menu
/lre debug hand
```

建议在隔离区域依次测试：

- 剑、斧、弓弩、三叉戟和矛的 PVE/PVP 命中。
- 护甲受击、防御和濒死触发。
- 镐、斧、锄与剪刀的方块破坏。
- 主动技能的按键、冷却和地面条件。
- 附魔台、村民交易、战利品和铁砧。
- 扩槽器在生存、冒险和创造模式的消耗与 Lore 刷新。
- 砂轮、祛魔、抽魔和净咒后的真实附魔与 Lore。

## 常见启动问题

### 配置读取不是 122/122

查看紧邻日志中的文件名和原因。常见原因：

- YAML 缩进错误。
- 文件中混入第二个文档或不可见 BOM。
- `id` 为空或两个文件使用相同 ID。
- 把一段配置粘贴到了另一个节点内部。

插件会隔离错误文件，不应让一份 YAML 拖垮全部附魔。

### Registry 注册不足

Registry 在启动阶段建立。确认：

- 使用正确的 Paper 26.1.2 构建。
- `plugins/` 内没有多个 LiRealEnchant2 Jar。
- Java 为 25。
- 修改注册字段后执行了完整重启。

### 修改来源后不生效

单附魔来源修改后先 `/lre reload`，再完整重启以重建候选池标签。全局 `acquisition.enabled` 必须完整重启。

### Lore 不刷新

先用 `/lre debug hand` 确认物品真实附魔。插件只刷新自己管理的 Lore 区域，不会无条件接管所有物品 Lore。

### 铁砧吞书或结果为空

检查动作栏提示、目标适用性、冲突、槽位、经验与最高费用。保留问题发生时的 `latest.log`、左右两件物品截图和 `/lre debug hand` 输出。

## 提交问题需要的信息

- Paper 完整版本和 Java 版本。
- LiRealEnchant2 Jar 文件名。
- `latest.log` 从服务器启动到问题发生的完整片段。
- 对应单附魔 YAML、`slots.yml` 或 `anvil.yml`。
- 复现步骤、玩家模式和物品截图。
- 是否安装基岩互通、Vault、经济或物品修改类插件。
