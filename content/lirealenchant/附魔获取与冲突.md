# 附魔获取与冲突

[返回首页](./Home.md) · [查看附魔图鉴](./附魔图鉴.md)

## 三种自然来源

每个 LiReal 附魔可分别控制：

```yaml
tradeable: true      # 图书管理员交易
discoverable: true   # 战利品箱
enchantable: true    # 附魔台
```

修改后执行 `/lre reload` 会更新运行过滤。为了让 Paper 启动期构建的注册标签和原版候选池完全一致，生产服应再完整重启。

## 全局来源开关

`enchantments.yml`：

```yaml
acquisition:
  enabled: true
```

设为 `false` 时，只禁止 LiReal 附魔自然生成：

- 原版附魔台结果保持正常。
- 原版村民附魔书保持正常。
- 原版战利品保持正常。
- 已有 LiReal 物品不会被删除。
- 管理员 `/lre givebook` 和测试套装不受影响。

## 村民交易

LiReal 附魔书只在图书管理员真正获得新交易时确定一次。打开交易界面不会重新随机替换已有交易；已经关闭来源的旧 LiReal 交易会在购买时被拦截。

## 冲突规则

每个单附魔配置都有 `conflicts`：

```yaml
conflicts:
  - efficiency
  - haste
```

插件会把冲突视为双向关系。即使管理员只在 A 中填写 B，铁砧从 A 合到 B 或从 B 合到 A 都会拦截，并保留装备和附魔书。

典型冲突：

- 急迫、急速与效率、范围挖掘类互斥。
- 时运与精准采集、霉运及改变矿物掉落的附魔互斥。
- 同类主动位移技能互斥，避免一个按键同时触发多个技能。
- 部分治疗、暴击和固定增伤附魔互斥，防止组合倍率失控。

## 适用装备

`targets` 同时用于注册、附魔台、基岩菜单、铁砧、战利品和管理员给予命令。护甲附魔不能附到剑，矛专属附魔只接受 Paper 26 的矛材质。

需要排查时，手持物品执行 `/lre debug hand` 查看真实附魔和槽位信息。
