# 命令与权限

[返回首页](./Home.md)

主命令为 `/lre`，别名为 `/lirealenchant`。所有主要参数均提供 Tab 补全。

## 玩家命令

| 命令 | 说明 | 权限 |
|---|---|---|
| `/lre help` | 查看帮助 | 无 |
| `/lre menu [分类] [页码]` | 打开附魔资料库 | `lirealenchant.menu.open` |
| `/lre gui [分类] [页码]` | 资料库别名 | `lirealenchant.menu.open` |
| `/lre disenchant` | 打开祛魔台 | `lirealenchant.disenchant.open` |
| `/lre qumo` | 祛魔台别名 | `lirealenchant.disenchant.open` |
| `/lre removeenchant` | 祛魔台别名 | `lirealenchant.disenchant.open` |

资料库分类包括：`all`、`helmet`、`chestplate`、`leggings`、`boots`、`sword`、`pickaxe`、`axe`、`shovel`、`hoe`、`spear`、`fishing`、`trident`、`bow`、`crossbow`、`mace`、`curse`。

## 管理命令

以下命令统一要求 `lirealenchant.admin`：

| 命令 | 说明 |
|---|---|
| `/lre reload` | 重载运行配置和受管理物品 Lore |
| `/lre givebook <玩家> <附魔ID> <等级>` | 给予真实附魔书 |
| `/lre giveitem <玩家> <材质> <附魔ID> <等级>` | 给予带指定附魔的测试物品 |
| `/lre givematerial <玩家> <材料键> [数量]` | 给予祛魔材料 |
| `/lre giveslotitem <玩家> [数量]` | 给予扩槽器 |
| `/lre testkit <玩家>` | 给予覆盖主要触发入口的测试套装 |
| `/lre debug hand` | 查看主手真实附魔和槽位诊断 |

材料键：`disenchant_stone`、`extract_scroll`、`purify_talisman`、`holy_purify_talisman`。

## 权限节点

| 权限 | 默认 | 说明 |
|---|---|---|
| `lirealenchant.admin` | OP | 使用管理命令 |
| `lirealenchant.menu.open` | 所有人 | 打开资料库 |
| `lirealenchant.menu.givebook` | OP | 从资料库领取测试附魔书 |
| `lirealenchant.disenchant.open` | 所有人 | 打开祛魔台 |
| `lirealenchant.disenchant.remove` | 所有人 | 使用普通祛魔 |
| `lirealenchant.disenchant.extract` | 所有人 | 使用抽魔 |
| `lirealenchant.disenchant.purify` | 所有人 | 使用净咒 |
| `lirealenchant.disenchant.bypass` | OP | 绕过祛魔费用和材料 |
