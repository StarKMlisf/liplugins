# 粒子与技能表现

[返回首页](./Home.md) · [查看附魔图鉴](./附魔图鉴.md)

## 重要边界

单附魔文件中的 `mechanics.particles` 和 `effects.parameters.particles` 用于资料库与 Wiki 展示当前实际效果。它们不是通用粒子脚本，单纯把“无”改成其他文字不会自动让代码生成粒子。

需要改变真实粒子类型、数量、形状或位置时，仍需修改对应机制实现并重新构建插件。

## 当前主动视觉效果

| 类型 | 代表附魔 | 当前表现 |
|---|---|---|
| 冰冻 | 永冻、冰霜 | 目标周围雪花，并短暂生成发光浮冰外壳 |
| 暴击 | 幸运暴击、强力暴击 | 命中位置生成暴击粒子，数量随等级增加 |
| 烟雾 | 烟雾弹、亡魂 | 玩家周围扩散烟雾 |
| 爆炸 | 震动 | 玩家脚下出现爆炸粒子并播放爆炸声 |
| 横扫 | 回锋 | 目标附近生成横扫粒子并播放横扫声 |
| 雷电 | 雷击、风暴、雷神、火花 | 目标位置显示无实体伤害的闪电视觉，再执行插件伤害 |
| 透视 | 透视 | 使用发光方块展示实体标记目标方块，最多 96 个 |
| 挖掘 | 范围挖掘、矿脉挖掘、伐木等 | 主要使用方块破坏或变化效果 |

## 药水粒子

中毒、凋零、黑暗、定身、麻痹、吸收和抗性类附魔多数依赖原版药水状态粒子。`haste`、`hasten`、`streamlining`、`slipstream`、`obsidianshield` 等持续或高频被动会关闭药水粒子，防止长期刷屏。

因此“药水效果粒子”不等于插件额外生成了一套粒子动画；它表示玩家客户端显示对应状态效果。

## 矛附魔

| 附魔 | 当前视觉反馈 |
|---|---|
| 贯势 | 击退和命中反馈，无额外主动粒子 |
| 长锋 | 被动距离加成，无粒子 |
| 破阵 | 伤害反馈，无额外主动粒子 |
| 回锋 | 4 个横扫粒子和横扫声 |
| 定锋 | 减速、挖掘疲劳的药水粒子和三叉戟命中声 |
| 腾跃 | 慢落状态粒子关闭，播放烟花火箭发射声 |

当前最完整的是冰冻外壳和幸运暴击；矛系除回锋外偏重机制反馈，视觉表现较克制。

## 测试状态

双客户端 QA 已确认两名客户端都收到 `world_particles` 和 `sound_effect` 数据包，说明粒子与声音网络发送链正常。

自动测试不能判断粒子的美术观感。发布前仍建议人工检查：

1. 粒子是否出现在目标而非攻击者脚下。
2. 范围技能的粒子是否覆盖实际伤害半径。
3. 高频附魔是否造成视觉刷屏或客户端掉帧。
4. PVP 隐身、黑暗和烟雾是否影响公平性。
5. 基岩客户端是否能正确显示所用粒子和展示实体。
