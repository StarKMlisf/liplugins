## 当前能力

- 122 个 LiReal 真实附魔，合计 385 个等级。
- 覆盖武器、工具、护甲、弓弩、三叉戟、矛、盾牌、钓鱼竿与鞘翅。
- 支持附魔台、战利品、村民交易、铁砧、真实附魔书和管理员指令。
- 支持附魔槽、扩槽器、双向冲突拦截和可配置铁砧费用上限。
- 支持普通祛魔、抽魔成书、净咒与可选 Vault 经济费用。
- Java 玩家使用原版附魔台；识别到基岩玩家时使用兼容菜单流程。
- 菜单、装备 Lore、消息、来源、适用物品和主要机制参数均可配置。
- API v1 支持第三方插件编写新的真实附魔行为，并提供独立 API Jar 与示例扩展。
- 纯 YML 支持六类触发器、条件、变量和安全动作白名单，不需要额外扩展 Jar。
