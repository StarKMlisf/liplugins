# dev199 更新说明

[返回首页](./Home.md)

## 重点

管理员现在可以只写一个 YML 文件创建新的 LiReal 真实附魔，不需要编写扩展 Jar。写法参考成熟附魔框架的“资料、变量、限制、触发机制”分层，同时坚持白名单执行，不开放服务器命令或脚本注入。

## 能力

- 六类触发器：攻击、受击、挖掘、交互、射击、投射物命中。
- 八类动作：追加伤害、伤害倍率、药水、粒子、声音、治疗、点燃、击退。
- 概率、冷却、PVP/PVE、蓄力、潜行、权限、世界、交互、实体和生命条件。
- 等级变量、固定变量、运行时生命/伤害变量和安全数学公式。
- 单文件错误隔离、自然获取自动熔断、热重载和完整中文模板。

## 安全边界

YML 不支持 `command`、`script`、`kether` 或 `class`。追加伤害直接修改当前事件，不创建二次伤害事件；复杂方块破坏仍要求使用 API 的领地安全方法，不会给配置开放绕过 Residence、Dominion、Lands 等保护的入口。

## 使用

启动一次后复制 `plugins/LiRealEnchant2/enchants/_yaml-enchant-example.yml`，去掉文件名前导下划线，修改 ID 和机制，再完整重启。详细字段见 [YML 自定义附魔](./YML自定义附魔.md)。

正式服只需要 `LiRealEnchant2-2.0.0-dev199-paper26.jar`；YML 功能没有新增必装前置。

## 验证

Paper 26.1.2 双客户端最终报告共 2,843 行、0 失败。启用的 YML 示例已确认真实注册、成功写入钻石剑、伤害由 5.0 提升到 9.5，并对目标实际施加缓慢；原有概率、PVP/PVE、粒子、声音和领地保护回归保持通过。
