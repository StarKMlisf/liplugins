# 安装与更新

[返回首页](./Home.md)

## 环境要求

| 项目 | 要求 |
|---|---|
| 服务端 | Paper 26.1.2 |
| Java | Java 25 |
| 必需前置 | 无 |
| 可选前置 | Vault、经济插件、PlaceholderAPI、基岩互通组件 |

当前正式构建使用 Paper 26 的真实附魔注册链，不要放入旧版 Paper、Spigot、Mohist 或其他不兼容核心。

## 首次安装

1. 完整关闭服务器。
2. 将 `LiRealEnchant2-2.0.0-dev196-paper26.jar` 放入 `plugins/`。
3. 启动服务器，等待插件生成 `plugins/LiRealEnchant2/`。
4. 检查启动日志是否显示 `单附魔配置已读取 122/122` 和 `Registry 注册 122/122`。
5. 执行 `/lre menu` 检查资料库，再使用 `/lre testkit <玩家>` 在测试区域验证。

## 从旧版本更新

1. 完整关闭服务器，备份旧 Jar 和整个 `plugins/LiRealEnchant2/` 目录。
2. 删除旧的 `LiRealEnchant2-*.jar`，确保 `plugins/` 内只保留一个正式版本。
3. 放入新 Jar。不要删除现有配置目录。
4. 启动服务器。缺失配置节点和仍等于旧默认值的资料会自动迁移，自定义配置尽量保留。
5. 检查控制台是否有重复 Jar、YAML 跳过、Registry 缺失或异常堆栈。
6. 抽查铁砧、附魔台、村民交易、扩槽器、砂轮和祛魔菜单。

## dev195 升级到 dev196

- 不需要重置玩家装备。
- 不需要删除 122 份单附魔配置。
- 旧默认抽魔卷轴 Lore“需要额外放入一本书”会迁移为“成功后直接生成真实附魔书”。
- 管理员已经自行修改过的其他材料名称和 Lore 不会被整份覆盖。

## 重载还是重启

| 修改内容 | `/lre reload` | 完整重启 |
|---|---:|---:|
| 菜单、Lore、消息 | 可以 | 可选 |
| 槽位、祛魔、材料、铁砧费用 | 可以 | 可选 |
| 单附魔启用和来源运行过滤 | 可以 | 推荐 |
| 全局自然获取总开关 | 不完整 | 必须 |
| 注册键、最高等级、目标、冲突和候选池标签 | 不完整 | 必须 |
| 更换插件 Jar | 不可以 | 必须 |

不要使用 Bukkit `/reload`、PlugMan 或热卸载工具替换 Jar。

## 正式服文件

正式服只放 `LiRealEnchant2-2.0.0-dev196-paper26.jar`。

`LiRealEnchantBehaviorQA-1.0.0.jar` 会创建测试实体、执行伤害和修改测试世界，只允许放在隔离测试服。
