# dev198 更新说明

[返回首页](./Home.md)

## 重点

LiRealEnchant2 现在提供 API v1。开发者可以用独立扩展插件编写新的真实附魔，不需要修改 LiRealEnchant2 主 Jar。

## 能力

- 从扩展 Jar 安装带中文说明的单附魔 YAML。
- 完整接入真实 Registry、附魔台、村民、战利品、铁砧、冲突、附魔槽、附魔书和 Lore。
- 行为回调覆盖攻击、受击、挖掘、交互、射击和弹射物命中。
- 提供领地安全破坏方法，每个附带方块仍会经过标准 `BlockBreakEvent`。
- 扩展异常隔离、回调重入保护和插件卸载自动注销。

## 兼容性

不安装任何扩展时，原有 122 个附魔的行为和配置保持不变。API 扩展只允许绑定标记为 `implementation: api` 的定义，不能覆盖内置附魔。

## 产物

- `LiRealEnchant2-2.0.0-dev198-paper26.jar`：正式服主插件。
- `LiRealEnchantAPI-2.0.0-dev198.jar`：扩展项目的 `compileOnly` 编译依赖，不放进服务器。
- `LiRealEnchantAPI-2.0.0-dev198-sources.jar`：IDE 源码浏览包，不放进服务器。
- `LiRealEnchantExampleAddon-1.0.0.jar`：隔离测试示例，不是必装前置。

详细开发方法见 [API 自定义附魔](./API自定义附魔.md)。
