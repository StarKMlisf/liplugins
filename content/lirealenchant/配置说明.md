## 文件结构

```text
plugins/LiRealEnchant2/
├─ enchantments.yml
├─ slots.yml
├─ anvil.yml
├─ display.yml
├─ messages.yml
├─ disenchant.yml
├─ materials.yml
├─ placed-ancient-debris.yml
└─ enchants/
   ├─ lifesteal.yml
   ├─ reaping_arc.yml
   └─ ... 共 122 份
```

`placed-ancient-debris.yml` 是插件内部放置追踪数据，不建议人工编辑。

## 配置职责

| 文件 | 负责内容 | 常规修改后 |
|---|---|---|
| `enchantments.yml` | LiReal 自然获取总开关、战斗蓄力阈值、少数运行机制数值 | `/lre reload`；总开关需重启 |
| `enchants/<ID>.yml` | 单附魔启用、名称、说明、最高等级、来源、目标、冲突和机制资料 | 重载后更新运行过滤，注册结构需重启 |
| `slots.yml` | 默认槽位、最大槽位、扩槽器 | `/lre reload` |
| `anvil.yml` | LiReal 铁砧最高经验费用 | `/lre reload` |
| `display.yml` | Java/基岩菜单、资料卡、装备 Lore、槽位 Lore、扩槽器显示 | `/lre reload` |
| `messages.yml` | 铁砧和村民提示，使用 MiniMessage | `/lre reload` |
| `disenchant.yml` | 祛魔模式、成功率、失败惩罚、经验与经济费用 | `/lre reload` |
| `materials.yml` | 祛魔材料的材质、名称和 Lore | `/lre reload` |

## 单附魔配置

需要新增附魔时，可使用 `implementation: yaml` 直接声明变量、条件、触发器和安全动作，完整格式见 [YML 自定义附魔](./YML自定义附魔.md)。复杂方块、经济和第三方插件交互继续使用 [API 自定义附魔](./API自定义附魔.md)。

```yaml
id: reaping_arc
namespace: yunmengze
enabled: true
display-name: "回锋"
description: "完整蓄力的矛命中有概率横扫周围敌人。"
type: normal
rarity: epic
max-level: 3

tradeable: true
discoverable: true
enchantable: true

targets:
  - spear

conflicts:
  - sweeping_edge
```

| 节点 | 说明 |
|---|---|
| `id`、`namespace` | 真实注册键；不要在已有服务器随意修改 |
| `enabled` | 是否启用该 LiReal 附魔 |
| `display-name` | 中文显示名 |
| `description`、`placeholders` | 资料库与 Lore 展示资料 |
| `type` | `normal` 或 `curse` 等类型 |
| `rarity` | 稀有度和随机权重依据 |
| `max-level` | 最高等级 |
| `tradeable` | 是否进入村民交易 |
| `discoverable` | 是否进入战利品 |
| `enchantable` | 是否进入附魔台 |
| `targets` | 适用装备类型 |
| `conflicts` | 冲突附魔 ID；运行时会补齐反向关系 |
| `mechanics`、`effects` | 实际机制资料和菜单展示参数 |

单附魔启用和来源只在 `enchants/<ID>.yml` 修改。旧版 `enchantments.yml` 中重复的 `enabled`、`max-level` 和 `sources` 不再作为来源真值。

## 全局关闭 LiReal 自然获取

```yaml
acquisition:
  enabled: false
```

该开关只关闭 `yunmengze:*` 附魔的附魔台、战利品和村民交易，不影响原版 `minecraft:*` 附魔，也不影响管理员指令。修改后必须完整重启服务器。

## MiniMessage

`display.yml` 和 `messages.yml` 支持 MiniMessage，例如：

```yaml
title: '<gradient:#55FFFF:#AA55FF>附魔资料库</gradient>'
```

无效显示节点会回退到内置默认值。配置文件统一保存为 UTF-8，不要加入第二份 YAML 文档或粘贴不可见 BOM。

## 自定义安全建议

- 更新前备份整个数据目录。
- 不要同时保留两个 LiRealEnchant2 Jar。
- 大范围修改前先复制到测试服。
- 修改注册键、最高等级、目标或冲突后完整重启。
- 启动后确认日志为 `122/122`，不要忽略“跳过配置”提示。
