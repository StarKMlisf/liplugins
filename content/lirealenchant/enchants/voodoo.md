# 巫毒

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

将部分伤害或负面效果反馈给攻击者。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:voodoo` |
| 类型 | 普通 |
| 稀有度 | 史诗 |
| 最高等级 | 3 |
| 适用装备 | 护甲 |
| 实际触发 | 穿戴者受到攻击 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [力场](./forcefield.md) (`forcefield`)、[熔甲](./molten.md) (`molten`)、[震荡波](./shockwave.md) (`shockwave`)、[烟雾弹](./smokebomb.md) (`smokebomb`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 9% | 向攻击者反馈本次伤害的 12%，最低 1 点 | 瞬时 | 无 | 无 | 无 |
| 2 | 13% | 向攻击者反馈本次伤害的 16%，最低 1 点 | 瞬时 | 无 | 无 | 无 |
| 3 | 17% | 向攻击者反馈本次伤害的 20%，最低 1 点 | 瞬时 | 无 | 无 | 无 |

## 配置位置

`plugins/LiRealEnchant2/enchants/voodoo.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
