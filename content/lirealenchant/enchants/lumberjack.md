# 伐木工

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

连锁砍伐同一棵树的原木，并额外消耗耐久。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:lumberjack` |
| 类型 | 普通 |
| 稀有度 | 史诗 |
| 最高等级 | 3 |
| 适用装备 | 斧 |
| 实际触发 | 破坏原木且未潜行 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | 无 |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 100% | 连锁破坏最多 40 个同类原木 | 瞬时 | 无 | 方块破坏效果 | 原版方块声 |
| 2 | 100% | 连锁破坏最多 64 个同类原木 | 瞬时 | 无 | 方块破坏效果 | 原版方块声 |
| 3 | 100% | 连锁破坏最多 88 个同类原木 | 瞬时 | 无 | 方块破坏效果 | 原版方块声 |

`plugins/LiRealEnchant2/enchants/lumberjack.yml`
