# 速掘

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

破坏方块后按对应等级概率短时间获得急迫效果。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:hasten` |
| 类型 | 普通 |
| 稀有度 | 普通 |
| 最高等级 | 3 |
| 适用装备 | 全部工具 |
| 实际触发 | 破坏方块 |
| 自然获取 | 村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [破坏诅咒](./breaklessness_curse.md) (`breaklessness_curse`)、[丰富挖掘](./digging.md) (`digging`)、效率 (`efficiency`)、[区域挖掘](./excavation.md) (`excavation`)、[急迫](./haste.md) (`haste`)、[矿脉挖掘者](./veinminer.md) (`veinminer`) |

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 10% | 获得急迫 I | 4 秒 | 无 | 药水效果粒子关闭 | 无 |
| 2 | 20% | 获得急迫 I | 5 秒 | 无 | 药水效果粒子关闭 | 无 |
| 3 | 30% | 获得急迫 I | 6 秒 | 无 | 药水效果粒子关闭 | 无 |

## 配置位置

`plugins/LiRealEnchant2/enchants/hasten.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
