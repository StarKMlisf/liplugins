# 滑流

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

手持三叉戟时提升移动速度，水中速度等级翻倍。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:slipstream` |
| 类型 | 普通 |
| 稀有度 | 优秀 |
| 最高等级 | 3 |
| 适用装备 | 三叉戟 |
| 实际触发 | 手持三叉戟 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [疾速逃脱](./escape.md) (`escape`)、[动量](./momentum.md) (`momentum`)、[火箭逃脱](./rocketescape.md) (`rocketescape`)、[流线型](./streamlining.md) (`streamlining`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 100% | 陆地获得速度 1，水中获得速度 2 | 7 秒，每 5 秒刷新 | 无 | 药水效果粒子关闭 | 无 |
