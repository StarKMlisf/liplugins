# 刷怪笼采掘

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

破坏刷怪笼时完整回收刷怪笼，并保留内部生物类型。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:spawner_miner` |
| 类型 | 普通 |
| 稀有度 | 传说 |
| 最高等级 | 1 |
| 适用装备 | 镐 |
| 实际触发 | 生存或冒险模式破坏刷怪笼 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [霉运诅咒](./misfortune_curse.md) (`misfortune_curse`)、精准采集 (`silk_touch`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 100% | 掉落保留生物类型的刷怪笼物品 | 瞬时 | 无 | 无 | 试炼刷怪笼破坏声 |

## 配置位置

`plugins/LiRealEnchant2/enchants/spawner_miner.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
