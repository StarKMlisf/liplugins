# 暴击率

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

命中时每级提高 10% 伪暴击概率，触发后造成额外伤害并显示暴击效果。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:crit_luck` |
| 类型 | 普通 |
| 稀有度 | 优秀 |
| 最高等级 | 3 |
| 适用装备 | 武器 |
| 实际触发 | 非原版暴击的近战命中 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [强力暴击](./criticals.md) (`criticals`)、[伤害提升](./damage_boost.md) (`damage_boost`)、[攻击失效诅咒](./harmlessness_curse.md) (`harmlessness_curse`)、[生命偷取](./lifesteal.md) (`lifesteal`)、[海神](./neptune.md) (`neptune`)、[过载](./overload.md) (`overload`)、[绝境爆发](./shura.md) (`shura`)、[颅骨穿刺](./skull_puncture.md) (`skull_puncture`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 10% | 伪暴击伤害 +20%；原版或强力暴击额外 +2% | 单次命中 | 无 | 暴击粒子 20 个 | 玩家暴击声 |
| 2 | 20% | 伪暴击伤害 +24%；原版或强力暴击额外 +2% | 单次命中 | 无 | 暴击粒子 26 个 | 玩家暴击声 |
| 3 | 30% | 伪暴击伤害 +28%；原版或强力暴击额外 +2% | 单次命中 | 无 | 暴击粒子 32 个 | 玩家暴击声 |

## 配置位置

`plugins/LiRealEnchant2/enchants/crit_luck.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
