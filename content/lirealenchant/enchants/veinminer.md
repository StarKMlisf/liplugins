# 矿脉挖掘者

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

连锁挖掘同类矿石，并额外消耗耐久。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:veinminer` |
| 类型 | 普通 |
| 稀有度 | 稀有 |
| 最高等级 | 3 |
| 适用装备 | 镐 |
| 实际触发 | 破坏矿石且未潜行 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [破坏诅咒](./breaklessness_curse.md) (`breaklessness_curse`)、[丰富挖掘](./digging.md) (`digging`)、效率 (`efficiency`)、[区域挖掘](./excavation.md) (`excavation`)、[急迫](./haste.md) (`haste`)、[速掘](./hasten.md) (`hasten`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 100% | 连锁破坏最多 20 个同类矿石 | 瞬时 | 无 | 方块破坏效果 | 原版方块声 |
| 2 | 100% | 连锁破坏最多 32 个同类矿石 | 瞬时 | 无 | 方块破坏效果 | 原版方块声 |
| 3 | 100% | 连锁破坏最多 44 个同类矿石 | 瞬时 | 无 | 方块破坏效果 | 原版方块声 |

## 配置位置

`plugins/LiRealEnchant2/enchants/veinminer.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
