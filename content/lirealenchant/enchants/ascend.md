# 悬浮

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

空中右键主动触发，短暂升腾并获得缓降，冷却 %cooldown% 秒。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:ascend` |
| 类型 | 普通 |
| 稀有度 | 传说 |
| 最高等级 | 2 |
| 适用装备 | 剑 |
| 实际触发 | 空中右键 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [箭跃](./arrow_leap.md) (`arrow_leap`)、[突进](./charge.md) (`charge`)、[火箭逃脱](./rocketescape.md) (`rocketescape`)、[传送](./transmission.md) (`transmission`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 100% | 获得漂浮 3 与缓降 I | 漂浮 3.5 秒；缓降 11 秒 | 90 秒 | 无 | 烟花大型爆炸声 |
| 2 | 100% | 获得漂浮 4 与缓降 I | 漂浮 5 秒；缓降 14 秒 | 90 秒 | 无 | 烟花大型爆炸声 |

## 配置位置

`plugins/LiRealEnchant2/enchants/ascend.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
