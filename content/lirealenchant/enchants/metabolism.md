# 新陈代谢

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

进食后按等级额外恢复饥饿值。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:metabolism` |
| 类型 | 普通 |
| 稀有度 | 稀有 |
| 最高等级 | 2 |
| 适用装备 | 胸甲 |
| 实际触发 | 食用任意可食用物品 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [天使庇护](./angelic.md) (`angelic`)、[饥饿诅咒](./hunger_curse.md) (`hunger_curse`)、[生命偷取](./lifesteal.md) (`lifesteal`)、[复原](./restore.md) (`restore`)、[耐力](./stamina.md) (`stamina`)、[生机勃发](./thrive.md) (`thrive`)、[生命复苏](./vitality.md) (`vitality`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 100% | 额外恢复 1 点饥饿值 | 进食完成后下一调度执行 | 无 | 无 | 无 |
| 2 | 100% | 额外恢复 2 点饥饿值 | 进食完成后下一调度执行 | 无 | 无 | 无 |

## 配置位置

`plugins/LiRealEnchant2/enchants/metabolism.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
