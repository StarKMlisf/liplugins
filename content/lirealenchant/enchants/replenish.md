# 补种

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

收获成熟作物后自动重新种植原作物。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:replenish` |
| 类型 | 普通 |
| 稀有度 | 优秀 |
| 最高等级 | 1 |
| 适用装备 | 锄 |
| 实际触发 | 破坏成熟作物且背包有对应种子 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [丰收之手](./harvest.md) (`harvest`)、[播种](./planter.md) (`planter`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 100% | 消耗 1 个对应种子并在原位置重新种植 | 下一调度执行 | 无 | 方块变化效果 | 无 |

## 配置位置

`plugins/LiRealEnchant2/enchants/replenish.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
