# 缚灵猎手

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

击杀普通生物时，按等级概率将其灵魂封入生物蛋。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:mob_egg_hunter` |
| 类型 | 普通 |
| 稀有度 | 稀有 |
| 最高等级 | 3 |
| 适用装备 | 剑、斧 |
| 实际触发 | 击杀非玩家、非 Boss 生物 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | 无 |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 2% | 额外掉落对应生物刷怪蛋 | 瞬时 | 无 | 无 | 无 |
| 2 | 4% | 额外掉落对应生物刷怪蛋 | 瞬时 | 无 | 无 | 无 |
| 3 | 6% | 额外掉落对应生物刷怪蛋 | 瞬时 | 无 | 无 | 无 |

## 配置位置

`plugins/LiRealEnchant2/enchants/mob_egg_hunter.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
