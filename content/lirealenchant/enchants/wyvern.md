# 翼刃

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

鞘翅滑翔或飞行状态下近战攻击造成额外伤害。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:wyvern` |
| 类型 | 普通 |
| 稀有度 | 史诗 |
| 最高等级 | 2 |
| 适用装备 | 鞘翅 |
| 实际触发 | 鞘翅滑翔时近战命中 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | 无 |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 100% | 伤害 +8.55% | 单次命中 | 无 | 无 | 无 |
| 2 | 100% | 伤害 +17.1% | 单次命中 | 无 | 无 | 无 |

## 配置位置

`plugins/LiRealEnchant2/enchants/wyvern.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
