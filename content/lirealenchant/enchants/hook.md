# 钩拽

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

鱼钩命中实体时将目标拉近。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:hook` |
| 类型 | 普通 |
| 稀有度 | 优秀 |
| 最高等级 | 3 |
| 适用装备 | 钓鱼竿 |
| 实际触发 | 鱼钩钩中活体实体 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [电闪雷鸣](./sparks.md) (`sparks`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 100% | 将目标拉向玩家，力度 0.5 | 瞬时 | 无 | 无 | 无 |
| 2 | 100% | 将目标拉向玩家，力度 0.65 | 瞬时 | 无 | 无 | 无 |
| 3 | 100% | 将目标拉向玩家，力度 0.8 | 瞬时 | 无 | 无 | 无 |

## 配置位置

`plugins/LiRealEnchant2/enchants/hook.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
