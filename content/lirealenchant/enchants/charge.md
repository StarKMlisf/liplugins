# 突进

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

冲刺右键主动触发，向前快速突进，冷却 %cooldown% 秒。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:charge` |
| 类型 | 普通 |
| 稀有度 | 稀有 |
| 最高等级 | 2 |
| 适用装备 | 剑 |
| 实际触发 | 冲刺右键 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [箭跃](./arrow_leap.md) (`arrow_leap`)、[悬浮](./ascend.md) (`ascend`)、[火箭逃脱](./rocketescape.md) (`rocketescape`)、[传送](./transmission.md) (`transmission`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 100% | 向前突进，水平速度 1.3 | 瞬时 | 25 秒 | 无 | 烟花发射声 |
| 2 | 100% | 向前突进，水平速度 1.6 | 瞬时 | 25 秒 | 无 | 烟花发射声 |

## 配置位置

`plugins/LiRealEnchant2/enchants/charge.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
