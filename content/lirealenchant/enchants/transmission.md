# 传送

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

潜行左键主动触发，向面朝方向水平传送，冷却 %cooldown% 秒。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:transmission` |
| 类型 | 普通 |
| 稀有度 | 传说 |
| 最高等级 | 2 |
| 适用装备 | 剑 |
| 实际触发 | 潜行左键 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [箭跃](./arrow_leap.md) (`arrow_leap`)、[悬浮](./ascend.md) (`ascend`)、[突进](./charge.md) (`charge`)、[火箭逃脱](./rocketescape.md) (`rocketescape`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 100% | 向视线前方安全位置传送，最远 7 格 | 瞬时 | 45 秒 | 无 | 末影人传送声 |
| 2 | 100% | 向视线前方安全位置传送，最远 10 格 | 瞬时 | 45 秒 | 无 | 末影人传送声 |

## 配置位置

`plugins/LiRealEnchant2/enchants/transmission.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
