# 生命复苏

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

生命低于一半时右键主动触发，恢复大量生命，冷却 %cooldown% 秒。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:vitality` |
| 类型 | 普通 |
| 稀有度 | 特殊 |
| 最高等级 | 1 |
| 适用装备 | 剑、斧 |
| 实际触发 | 生命不高于 50% 时右键 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [天使庇护](./angelic.md) (`angelic`)、[生命偷取](./lifesteal.md) (`lifesteal`)、[新陈代谢](./metabolism.md) (`metabolism`)、[复原](./restore.md) (`restore`)、[生机勃发](./thrive.md) (`thrive`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 100% | 恢复最大生命的 55% | 瞬时 | 120 秒 | 无 | 玩家升级声 |

## 配置位置

`plugins/LiRealEnchant2/enchants/vitality.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
