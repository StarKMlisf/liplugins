# 下界勘探者

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

提高下界采矿收益，重点提升远古残骸收益。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:nether_prospector` |
| 类型 | 普通 |
| 稀有度 | 稀有 |
| 最高等级 | 2 |
| 适用装备 | 镐 |
| 实际触发 | 破坏下界石英矿或非玩家放置的远古残骸 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [宝石化](./gemify.md) (`gemify`)、[自动熔炼](./infernal_touch.md) (`infernal_touch`)、[霉运诅咒](./misfortune_curse.md) (`misfortune_curse`)、精准采集 (`silk_touch`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 石英金粒 2%；残骸碎片 4% | 石英额外掉落 1 个金粒；远古残骸必定额外掉落 1 个残骸并可能掉落碎片 | 瞬时 | 无 | 无 | 无 |
| 2 | 石英金粒 3%；残骸碎片 5% | 石英额外掉落 2 个金粒；远古残骸必定额外掉落 2 个残骸并可能掉落碎片 | 瞬时 | 无 | 无 | 无 |

## 配置位置

`plugins/LiRealEnchant2/enchants/nether_prospector.yml`

- `enabled`、`max-level`、`targets` 和三个自然获取开关修改后可先执行 `/lre reload` 更新运行过滤。
- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
