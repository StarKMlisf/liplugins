# 疾速逃脱

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

穿戴者受击后获得短暂速度效果。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:escape` |
| 类型 | 普通 |
| 稀有度 | 史诗 |
| 最高等级 | 2 |
| 适用装备 | 靴子 |
| 实际触发 | 穿鞋受到未取消的伤害 |
| 自然获取 | 附魔台、战利品、村民交易 |
| 默认启用 | 是 |
| 冲突附魔 | [动量](./momentum.md) (`momentum`)、[火箭逃脱](./rocketescape.md) (`rocketescape`)、[滑流](./slipstream.md) (`slipstream`)、[流线型](./streamlining.md) (`streamlining`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 100% | 获得速度 3 | 3 秒 | 无 | 药水效果粒子 | 无 |
| 2 | 100% | 获得速度 4 | 3.75 秒 | 无 | 药水效果粒子 | 无 |

`plugins/LiRealEnchant2/enchants/escape.yml`

- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
- 本页参数来自 dev195 最终实服 QA 报告；服务器自行修改机制参数后，以服务器配置与实测结果为准。
