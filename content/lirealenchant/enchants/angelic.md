| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:angelic` |
| 类型 | 普通 |
| 稀有度 | 稀有 |
| 最高等级 | 3 |
| 适用装备 | 胸甲 |
| 实际触发 | 穿戴者受到攻击 |

- 注册键、最高等级、适用物品和原版候选池标签属于启动期结构，生产环境修改后应完整重启。
