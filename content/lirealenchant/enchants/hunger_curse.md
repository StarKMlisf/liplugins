# 饥饿诅咒

[返回附魔图鉴](../附魔图鉴.md) · [返回首页](../Home.md)

饥饿值下降时额外消耗 1 点饥饿值，当前等级不继续放大该效果。

| 项目 | 内容 |
|---|---|
| 注册键 | `yunmengze:hunger_curse` |
| 类型 | 诅咒 |
| 稀有度 | 诅咒 |
| 最高等级 | 1 |
| 适用装备 | 全部可附魔装备 |
| 实际触发 | 饥饿值自然下降 |
| 自然获取 | 附魔台、战利品 |
| 默认启用 | 是 |
| 冲突附魔 | [新陈代谢](./metabolism.md) (`metabolism`)、[耐力](./stamina.md) (`stamina`) |

## 每级实际参数

| 等级 | 概率 | 伤害或效果 | 持续时间 | 冷却 | 粒子 | 声音 |
|---:|---:|---|---|---|---|---|
| 1 | 100% | 每次额外消耗 1 点饥饿值，当前实现不随等级继续增加 | 单次消耗 | 无 | 无 | 无 |
