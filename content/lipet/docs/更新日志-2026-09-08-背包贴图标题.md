# 0.27.26 · 独立宠物背包贴图标题

`0.27.26-SNAPSHOT` 将独立宠物背包的标题开放到 `gui.yml`，可按实际 1-6 行容量选择 CraftEngine 图片字体。此更新只涉及界面标题，不改变原有背包容量、物品内容、保存路径和主人权限。

## 配置

- `inventory-title`：普通标题，支持 MiniMessage 和 `<pet_name>`，默认保持旧版显示。
- `inventory-skin.enabled`：可选皮肤开关，取值 `true` 或 `false`，插件默认 `false`。
- `inventory-skin.titles.'1'` 至 `'6'`：分别对应真实 9、18、27、36、45、54 格背包的标题。没有配置或空字符串时使用普通标题。

只有先安装并下发了对应资源包，才应开启皮肤开关。不同容量使用独立背景，不拉伸六行贴图。`/lipet reload` 会重新读取标题设置；已打开的背包需要关闭后重新打开。

旧配置只补充缺失项和中文注释。此次配套的小鱼服菜单套装另包含七个主要菜单及六种背包容量背景；安装套装可以应用其 `gui.yml`，保留宠物商品、价格、权限、成长与存档文件。

## 更新

在维护窗口备份后替换 `LiPet-0.27.26-SNAPSHOT.jar`，完整启动服务器。只替换 Jar 时默认继续显示普通背包；启用配套贴图需要同时安装资源包和 GUI 配置。

## 验证范围

默认兼容 API 与 Paper 26.2 API 各通过 386 项测试，含新增的关闭回退、实际行数选择和缺失/异常容量回退测试。成品使用 Java 21 字节码，不内嵌第三方依赖。本次未进行游戏客户端贴图、背包物品存取或服务器重启验收；原有背包并发等已知边界不因标题更新而改变。
