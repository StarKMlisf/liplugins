# 测试与故障排查

## 上线前检查

1. 启动后执行 `/lipet status`。
2. 从商城或管理指令创建一只测试宠物。
3. 测试召唤、收回、坐下、骑乘、背包和改名。
4. 重启服务器，确认宠物、技能和背包数据仍在。
5. 群组服分别核对各子服的 `server.id`。

## 插件被禁用

不要只看随后出现的 `plugin is disabled`。请向上查找启动阶段第一条 LiPet 错误，常见原因包括：

- YAML 格式错误。
- 实体类型、材质、音效或粒子键拼错。
- MySQL 连接失败。
- 运行时依赖无法下载。

无效音效和粒子在当前版本会回退到安全默认值；如果仍无法加载，应确认使用的是最新配置和 Jar。

## 功能异常

- 背包未保存：确认玩家正常关闭 GUI，并检查数据库写入错误。
- 信号棒无反应：确认物品由 `/lipet signalstick` 发放、已有活动宠物，且没有其他插件取消交互事件。
- 商城购买失败：检查余额、商品的 `pet-type`、重复拥有限制，以及 Vault 与经济插件状态。
- 宠物不跟随：先切换一次坐下/跟随；再检查外部模型或 AI 插件是否持续修改实体状态。

提交问题时请附完整启动日志、LiPet 版本、服务端构建号、Java 版本及相关配置片段。
