# LiPet 0.27.2 老宠物类型兼容与独立 YML

日期：2026-08-29<br>
版本：`0.27.2-SNAPSHOT`

## 修复内容

- 旧数据库中的原版实体 ID 会兼容到当前类型 ID，例如 `bat` → `vanilla_bat`、`fox` → `vanilla_fox`。
- 同时兼容 `minecraft:bat` 形式和大小写不同的旧值，不修改、不删除旧宠物档案。
- 召唤查找、同类型持有上限和管理员按类型收回共用同一个兼容索引，避免新旧 ID 被当成两种宠物。
- 服主可在任意宠物类型节点中增加 `legacy-ids`，为历史自定义类型配置额外别名。

## 独立配置文件

商城默认 10 种宠物现在各有一个独立 YML：`狼.yml`、`猫.yml`、`狐狸.yml`、`兔子.yml`、`鹦鹉.yml`、`豹猫.yml`、`蜜蜂.yml`、`悦灵.yml`、`青蛙.yml` 与 `熊猫.yml`。

升级时只生成缺失类型。已有文件、已有类型、服主修改的数值和中文注释不会被覆盖；狼和猫原文件经过哈希对比保持完全一致。每个新增文件包含完整中文注释、属性、行为、背包、成长、食物、模型和默认关闭的 MythicMobs 等级技能示例。

## 自定义旧 ID

```yaml
types:
  vanilla_fox:
    entity-type: "FOX"
    display-name: "狐狸"
    legacy-ids:
      - "fox"
      - "minecraft:fox"
```

`legacy-ids` 只负责读取兼容，不会复制宠物，也不会重写数据库中的旧 ID。若旧 ID 与当前正式类型 ID 同名，当前正式类型始终优先。
