# LiPet 2.3.14 · MythicMobs 占位符接口更新

## 修复内容

将 8 个 lipet 属性占位符迁移至 MythicMobs 的 GenericPlaceholder 类注册接口，消除 Placeholder#meta(BiFunction) 弃用警告；原有技能配置、属性计算与 skill.power 用法保持兼容。

每个占位符使用独立实现类，通过 MM 公开的类注册 API 注册（CustomComponentRegistry 内部也调用此接口），逐项保留已有的同名冲突检查。MM 重载后重新注册，关闭挂钩后旧回调返回安全空值，不继续访问宠物数据。

支持的名称：`<lipet.level>`、`<lipet.damage>`、`<lipet.max_health>`、`<lipet.strength>`、`<lipet.defense>`、`<lipet.agility>`、`<lipet.vitality>`、`<lipet.quality>`。

`damage{amount="<lipet.damage> * 1.5"}` 与 `<skill.power>` 无需修改。@PetOwner / @LipetOwner、petExperience / lipetExperience 保留。

## 更新方式

停服后将旧 LiPet Jar 移到 plugins 外，再放入 LiPet-2.3.14.jar，保留原配置及数据库。启动时确认控制台加载版本为 2.3.14，不要同时保留两个 LiPet Jar。不建议用插件热卸载工具替换。

日志里的 DEPRECATED API 是旧接口兼容警告，不等同于召唤失败；本次也保留 2.3.13 的末影人召唤初始化雨水保护。
