# 2026-10-10 · LiPet 2.3.2 · 主动攻击名称统一

宠物设置中的默认名称统一为“主动攻击”。本次只调整玩家看到的文案与旧默认文案迁移，沿用 2.3.1 的全部功能、每宠开关和战斗规则。

## 玩家看到的变化

- 管理菜单按钮显示“主动攻击：已开启 / 已关闭”。
- 默认按钮说明首行改为“宠物设置 · 主动攻击”。
- 开启、关闭与保存失败提示统一使用“主动攻击”。
- 关闭后仍清除目标、停止主动索敌、援助反击与自动战斗技能，并继续跟随；手动技能仍遵守原有目标和冷却要求。

## 旧服配置如何迁移

加载或重载配置时，仅迁移下列完全匹配旧官方默认值的文案：

| 配置文件 | 原有配置键 | 迁移规则 |
| --- | --- | --- |
| `gui.yml` | `manage.actions.auto-attack.name` | 完整字符串与旧官方默认一致时更新按钮名称 |
| `gui.yml` | `manage.actions.auto-attack.lore` | 整份列表与旧官方默认一致时更新说明；任一行被自定义则整份保留 |
| `messages.yml` | `pet-auto-attack-enabled` | 完整字符串与旧官方默认一致时更新开启提示 |
| `messages.yml` | `pet-auto-attack-disabled` | 完整字符串与旧官方默认一致时更新关闭提示 |
| `messages.yml` | `pet-auto-attack-save-failed` | 完整字符串与旧官方默认一致时更新保存失败提示 |

自定义文字、颜色或列表内容继续保留；缺失项按原有机制补齐。已迁移的文案重复加载或重载后保持一致，不需要删除 `gui.yml` 或 `messages.yml`。若服主自己定制的文字中仍有“自动攻击”，可按需要手动改成“主动攻击”，插件不会批量替换自定义内容。

`pet-auto-attack-enabled` 旁的旧官方说明注释也同步更新：比较注释时忽略空行，仅在其余内容与唯一官方说明逐字匹配时替换，管理员添加或修改的注释文字保留。此规则仅用于注释；按钮名称、消息值及 `lore` 仍按上表严格比较。

## 保持兼容的标识与数据

`manage.actions.auto-attack`、`behavior.auto-attack.enabled`、`auto-attack:<pet_id>:<auto_attack_next>` 动作、`<auto_attack>` / `<auto_attack_enabled>` / `<auto_attack_next>` 变量以及 `pet-auto-attack-*` 消息键继续使用原名称，已有配置和扩展无需改键。

本次不修改数据库表结构，不重置已保存的每宠开关。主动攻击开启后仍受物种、主人、友方与区域保护限制；MM 自身事件触发的技能继续按第三方 Mob 配置执行。模型骑乘、MM 双向接口、112 项技能、PAPI 标题、捕捉品质与 CE 贴图功能继续保留。

## 升级

1. 正常停服，备份 LiPet 配置、数据库和恢复台账。
2. 将旧 LiPet Jar 移出 `plugins` 扫描目录，只保留 `LiPet-2.3.2.jar`；保留原有配置和数据。
3. 正常启动，确认日志为 `Enabling LiPet v2.3.2`。更换 Jar 需要重启，不能用 `/reload` 或热加载代替。
4. 重新打开宠物管理菜单，确认默认文案已更新，原有开关选择和自定义样式保持。

本次不需要更新客户端资源包。之后调整支持热更新的文本可执行 `/lipet reload` 并重新打开菜单。
