# LiPet 0.29.6 · info 界面行数修复

## 修复内容

移除旧版属性界面升级逻辑：不再把小于 5 行的 `info.rows` 强制改成 5，也不再把 `info.navigation.warehouse.slot` 强制改成 40。

属性界面支持 1-6 行，按管理员设置创建库存。保留槽位越界校验，不会自动挪动按钮或扩大界面。已有配置、按钮动作、文本和管理员注释保持不变。

## 调整已有配置

旧版已经写回文件的行数和槽位无法推断原值，升级后请重新填入希望使用的值，再执行 `/lipet reload`。修改的是 `plugins/LiPet/gui.yml`。

缩小界面时，需要同时检查 `info.pet-item`、四个 `info.attributes` 按钮、`info.navigation.warehouse`、`info.navigation.manage` 及自定义按钮。3 行合法槽位为 0-26，4 行为 0-35；两个返回按钮按进入来源择一显示，可以共用槽位。

下面仅展示需要调整的字段，请合并到原节点，保留原有材质、名称、动作与 lore，不要用该片段覆盖整个 info 段：

```yaml
info:
  # 属性界面行数，取值 1-6；此示例为 3 行。
  rows: 3
  pet-item:
    # 综合属性卡片位置；3 行时范围为 0-26。
    slot: 4
    # 非空时覆盖 slot；本示例使用单槽位。
    slots: []
  attributes:
    strength:
      # 力量按钮位置；3 行时范围为 0-26。
      slot: 10
      # 非空时覆盖 slot；本示例使用单槽位。
      slots: []
    vitality:
      # 体质按钮位置；3 行时范围为 0-26。
      slot: 12
      # 非空时覆盖 slot；本示例使用单槽位。
      slots: []
    defense:
      # 防御按钮位置；3 行时范围为 0-26。
      slot: 14
      # 非空时覆盖 slot；本示例使用单槽位。
      slots: []
    agility:
      # 敏捷按钮位置；3 行时范围为 0-26。
      slot: 16
      # 非空时覆盖 slot；本示例使用单槽位。
      slots: []
  navigation:
    warehouse:
      # 从仓库进入时显示；3 行时范围为 0-26。
      slot: 22
      # 非空时覆盖 slot；本示例使用单槽位。
      slots: []
    manage:
      # 从管理界面进入时显示；3 行时范围为 0-26。
      slot: 22
      # 非空时覆盖 slot；本示例使用单槽位。
      slots: []
```

若使用 `filler.mode: CUSTOM`，填充槽位也须在范围内。`slots` 非空时优先于 `slot`，需要一并检查；越界配置会报出节点错误，不再通过静默改写来修正。
