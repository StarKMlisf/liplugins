# 存储与跨服

## SQLite 单服

```yaml
storage:
  type: "SQLITE"
  sqlite:
    file: "lipet.db"
  shutdown-save-timeout-seconds: 20
```

宠物、技能、背包和内置货币会写入 `plugins/LiPet/lipet.db`。建议保留至少 20 秒的关服保存等待时间，让插件收回活动宠物并排空写入队列。

## MySQL 群组服

```yaml
storage:
  type: "MYSQL"
  mysql:
    host: "127.0.0.1"
    port: 3306
    database: "lipet"
    username: "root"
    password: "change-me"
    maximum-pool-size: 10
server:
  id: "survival-1"
  group: "main"
```

群组服必须使用 MySQL。同一群组的子服使用相同 `server.group`，每个子服必须使用唯一 `server.id`，避免宠物实体归属冲突。

Redis 目前是群组同步预留能力，不可替代 MySQL 持久化。切换存储前必须停服并备份现有数据。

## 数据安全

- 生产服定期备份 SQLite 文件或 MySQL 数据库。
- 不要用热加载插件切换存储后端。
- 关服时等待正常保存完成，不要直接结束 Java 进程。
- 旧版 `MEMORY` 配置会迁移到 SQLite；升级后仍应检查实际数据。
