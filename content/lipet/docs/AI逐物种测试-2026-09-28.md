# LiPet 0.30.0 AI 逐物种测试

## 测试环境与边界

隔离 Paper `26.2-111-f570646`，Java 25，插件使用 Java 21 字节码。测试枚举此服务器全部可生成的活体类型，排除 PLAYER 和 ARMOR_STAND，共 91 种。包含普通动物、敌对生物、水生生物、飞行生物及龙、凋灵、巨人、人偶等特殊类型。

Folia 使用本机已验证的 `26.2-5-codex/folia-26.2@3ae8e7a` 构建，在正常 20 TPS 复查特殊导航及本轮发现问题的类型。Paper 全量测试目标 tick rate 为 200，依然执行真实服务器 tick；不能将其等同于多人在线性能压测。

探针仅用于 `.tools/ai-matrix` 隔离服，未放入正式服或产品 Jar。使用真实服务端代理玩家、真实宠物实体、LiPet 业务管理器和事件链。每只宠物分别创建档案、召唤、注册会话、测试并清理场地，不复用上一只宠物的实体或命中统计。

## 每只宠物的检查项目

| 项目 | 检查方式 |
| --- | --- |
| 跟随 | 宠物距主人约 12 格，持续 220 tick；实际移动并进入 5 格内。龙是限速位置步进，潜影贝是逐格位移，单独说明而不冒充步行。 |
| 主动索敌 | 不手工下攻击指令，生成主人与宠物附近的敌对生物，220 tick 内观察实际伤害。 |
| 隔墙绕障 | 放置 5 格宽、8 格高石墙，下达目标指令，260 tick 内绕行并命中；统计无视线伤害。阶段开始清除上一阶段弹丸。 |
| 坐下停战 | 使用真实坐下控制，70 tick 内目标不再受到宠物伤害。 |
| 远距召回 | 恢复站立、清除目标，主人移动到 42 格位置，80 tick 内宠物返回附近。 |
| 移动助战 | 主人实际伤害一只移动的非敌对目标，检查助战事件链及持续移动目标命中。 |
| 主人保护 | 观察自然战斗，同时显式以宠物为伤害来源攻击主人，确认没有有效主人伤害。 |
| 旁观保护 | 战场放置未锁定的牛，观察其是否受到宠物伤害。此项不代表穷尽所有 PvP/第三方技能组合。 |
| 地形保护 | 开启 mobGriefing，观察宠物导致的方块变更和爆炸；每种宠物独立重置地板。 |

单元测试另覆盖攻击节奏、目标切换冷却、失去许可/取消蓄力、碰撞箱距离、宽体绕障、水体路径、岩浆避让、配置继承、迁移幂等和三叉戟实际线段碰撞。默认 API 与 Paper 26.2 API 分别通过 550 项测试。

服务端自动测试不等同于真实客户端动画、第一人称骑乘、全部皮肤/体型变种、任意地形或所有 MM/ModelEngine 自定义宠物的验收。本次保留这些验收边界，不宣称百分之百解决所有场景。
