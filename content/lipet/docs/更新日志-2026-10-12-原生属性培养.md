# LiPet 2.3.8 原生属性培养接口

新增供 LiUI 调用的原生属性培养接口，支持力量、体质、防御、敏捷，每次消耗一个真实属性点。玩家身份与权限由 LiPet 重新校验，客户端不能指定其他主人或任意增加数值。

- 确认请求携带宠物 UUID 与档案版本，旧页面不能在新档案上重复消费属性点。
- 修复空属性参数可能消耗属性点的问题。
- 旧 API 实现默认返回不支持，保持兼容；LiUI 可继续使用原插件入口。
- 904 项自动测试通过，包含重复请求、错误主人、空属性、属性点不足的事务回归。

此版本不代表宠物喂养、道具、背包、技能书等功能已经全部迁入 LiUI。原有配置、价格和数据库均不需要覆盖。正常停服备份后替换 LiPet-2.3.8.jar；配套 LiUI 使用 0.9.0-dev8。
