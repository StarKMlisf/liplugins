# LiPet 0.27.4 CraftEngine 捕捉球与食物案例

日期：`2026-08-29`

版本：`0.27.4-SNAPSHOT`

## 新增默认案例

`capture.yml` 现在包含默认关闭的 CraftEngine 捕捉球案例：

```yaml
balls:
  craftengine_example:
    enabled: false
    material: "yourpack:pet_capture_ball"
    name: "<gradient:#69F0AE:#40C4FF><bold>灵契捕捉球</bold></gradient>"
    base-chance: 0.25
    low-health-bonus: 0.50
    maximum-chance: 0.75
```

`pet-types.yml` 的公共默认食物中增加 CraftEngine 案例，所有继承 `defaults` 的宠物都可以使用：

```yaml
defaults:
  growth:
    foods:
      craftengine_example:
        enabled: false
        item-id: "yourpack:pet_food"
        display-name: "灵契宠物粮"
        experience: 35
        healing: 8.0
        attribute-points: 0
        minimum-level: 1
        maximum-level: 0
```

使用时把 `yourpack:*` 改为 CraftEngine 中真实存在的完整 ID，再将对应 `enabled` 改为 `true`，最后执行 `/lipet reload`。

## 安全行为

- 关闭的捕捉球不会进入 `/lipet captureball` 的补全、识别或发放流程。
- 关闭的食物不会进入物品识别、扣除、喂养判定或宠物信息界面的食物列表。
- 关闭节点会在检查物品 ID 前被跳过，因此默认占位 ID 不要求服务器安装 CraftEngine。
- 至少要保留一个已启用的捕捉球，避免捕捉系统没有任何可用道具。
- 旧服升级只补缺失的 `enabled` 和案例节点；已有 Material、CE ID、数值及管理员注释不会被覆盖。
