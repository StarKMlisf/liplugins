# LiPet 2.3.11 · 闪光捕捉提示与发光药水

- 捕捉成功且宠物档案保存成功后，若为闪光宠物，向捕捉者额外发送渐变聊天提示和屏幕标题，标题默认停留 4 秒。
- 提示读取已保存的闪光标记，不再次抽取；普通捕捉不会弹出闪光提示。
- 闪光宠物召唤时添加持续的原版 GLOWING 发光药水，不显示药水粒子。已有闪光宠物收回再召唤也可获得效果。
- 原版实体支持描边；ModelEngine 模型的完整描边效果取决于模型引擎，未宣称已完成模型客户端验收。
- 闪光仍在捕捉成功时抽取，野外目标不会提前发光；本次不改变捕捉概率、闪光概率、品质或成长数值。
- 特性配置校验完成并成功加载后才替换抽取规则快照，避免加载失败后出现半更新状态。

## 配置

traits.yml 新增以下设置，旧服自动补齐，不覆盖已有概率或品质配置：

```yaml
shiny-display:
  glow: true
  capture-message: true
  capture-title: true
  title-ticks: 80
```

前三项为 true/false；title-ticks 为 1–1200 的整数，20 tick 约 1 秒。修改后执行 /lipet reload。提示开关对之后的捕获生效，发光开关需收回再召唤后生效；不会清除其他插件施加的药水。

messages.yml 新增 capture-shiny、capture-shiny-title、capture-shiny-subtitle，支持 MiniMessage 和 pet_name/quality/nature/shiny 等捕捉变量。
