# 配置说明

LiPet 将不同功能拆分到独立配置文件，便于维护和升级。

| 文件 | 用途 |
| --- | --- |
| `config.yml` | 存储、服务器 ID、依赖下载、内置货币 |
| `pet-types.yml` | 宠物实体、模型、属性、行为、成长、食物和背包 |
| `shop.yml` | 宠物商城与道具商城 |
| `gui.yml` | GUI 标题、槽位、图标和按钮 |
| `capture.yml` | 捕捉球、概率、仪式、音效、粒子和实体映射 |
| `skills.yml` | 技能书、技能等级和效果 |
| `messages.yml` | 玩家提示文本 |

## 宠物类型

```yaml
types:
  wolf:
    entity-type: "WOLF"
    display-name: "狼"
    enabled: true
    owner-limit: 1
    model:
      provider: "NATIVE"
      id: ""
```

- `entity-type` 必须是当前服务端存在的 Bukkit 实体类型。
- `model.provider` 支持 `NATIVE`、`MODEL_ENGINE`、`CRAFT_ENGINE`。
- `auto-register-vanilla: true` 可自动注册可生成的原版实体类型。

## 修改建议

- 先停服并备份，再批量调整宠物类型与存储设置。
- 文本使用 MiniMessage 格式。
- 背包大小必须为 0 或 9 的倍数，最大 54。
- 使用 `/lipet reload` 后检查控制台；涉及存储类型、驱动或服务端标识时应完整重启。

新版本会自动补齐缺少的默认节点，不覆盖管理员现有值。
