# 2026-10-11 · LiPet 2.3.7 · Paper 26.3 适配

## 更新内容

- 将 Paper 26.3 纳入已验证服务端范围，启动时不再出现未验证版本提示。
- 版本判断使用精确匹配，避免把 26.20 或预发布版本误认为已经验证的 26.2。
- Paper 与 Folia 分开记录验证范围；本次只升级 Paper，Folia 保持 1.21.11、26.1.2 和 26.2，不宣称 Folia 26.3 已验证。
- 保留 Java 21 编译下限与 `api-version: '1.21.11'`，无需为同一个插件单独制作旧版 Jar。Paper 26.3 测试运行使用 Java 25。
- 保留和平世界名单、模型骑乘和下马净空逻辑；不更改管理员配置、数据库或 CE/模型资源。

## 实测范围

本次使用官方 Paper `26.3-169-46d4834`（下载渠道标记 BETA）和 JDK 25.0.3。901 项单元测试全部通过，隔离 Paper 26.3 共 49 项运行检查通过：

- 模型生成、实际 ModelEngine 座位绑定、和平世界免伤与禁止伤害、手动技能保护、MM 直接定时机制及元技能拦截、热重载恢复。
- 不安装 ModelEngine/MythicMobs 时，原版宠物正常召唤、受伤、重载和升级；伤势不会被错误恢复。
- 注入一次数据库保存故障，确认死亡状态重试保存、死亡扣级只执行一次、不重复生成宠物；再次启动后从 SQLite 读回正确状态。

模型测试使用本机已有的 `ModelEngine R4.1.1-UME.2` 和 `MythicMobs 5.13.1-community.1`。这两项仅作为本次测试依赖，不包含在 LiPet 交付包中；升级 Paper 时，服务器上的第三方插件也需要使用对应支持 26.3 的版本。服务端与模拟连接验证不代替客户实际客户端的模型观感和资源包验收。

## 升级步骤

1. 正常停服并备份服务器目录与数据库，再升级 Paper 26.3；世界升级后不要直接用旧服务端打开。
2. 移出旧 LiPet Jar，仅放入 `LiPet-2.3.7.jar`。保留现有 `plugins/LiPet` 配置和数据库。
3. 使用 Java 25 启动，确认日志显示 Paper 26.3 和 `Enabling LiPet v2.3.7`。

本次 LiPet 更新无需重新分发 CE 或模型资源包；第三方模型引擎自身的资源包升级要求另行遵循其说明。客户问题模型不进入公开页面或交付包。
