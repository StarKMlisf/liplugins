# LiPet 0.29.12 · CraftEngine 捕捉球 PAPI 变量

发布日期：2026-09-27；版本：`0.29.12-SNAPSHOT`。

## 新增内容

- PlaceholderAPI 新增捕捉系统开关、已启用捕捉球数量和捕捉球 ID 列表。
- 可按 `capture.yml -> balls` 下的球 ID 读取名称、纯文本名称、完整物品 ID、命名空间、物品路径及是否为 CraftEngine 自定义物品。
- 基础概率、低血量加成和最高概率同时提供 `0-1` 配置原值与 `0.0-100.0` 显示百分比。
- 捕捉球 ID 可以包含下划线或短横线；解析时不会把 ID 中的下划线误当成变量分隔符。
- 不新增配置节点，不覆盖管理员现有 `capture.yml`、CE 物品 ID、概率、名称或 Lore。

## 常用示例

```text
%lipet_capture_enabled%
%lipet_capture_ball_ids%
%lipet_capture_ball_craftengine_example_item_id%
%lipet_capture_ball_craftengine_example_plain_name%
%lipet_capture_ball_craftengine_example_is_craftengine%
%lipet_capture_ball_craftengine_example_base_chance_percent%
%lipet_capture_ball_craftengine_example_maximum_chance_percent%
```

如果实际球 ID 是 `my_ce_ball`，就把示例中的 `craftengine_example` 整段替换成 `my_ce_ball`。物品 ID 会保持 `namespace:item_id` 格式，便于 CraftEngine、HUD、菜单或计分板直接读取。

## 返回规则

- `capture_enabled` 返回 `true` 或 `false`。
- `capture_ball_ids` 使用英文逗号连接全部已启用球 ID。
- `<id>_enabled` 在捕捉系统开启且该球已启用时返回 `true`，否则返回 `false`。
- 球不存在时，其余球属性返回空文本，避免把原始占位符显示给玩家。
- `name` 保留 MiniMessage 标签，`plain_name` 去掉颜色与格式标签。
- `_chance` / `_bonus` 返回 `0-1` 原值；对应 `_percent` 返回 `0.0-100.0`，不自动追加百分号。

替换 Jar 后必须完整重启服务器；`/lipet reload` 只能重载配置，不能替换已经载入的 Java 代码。
