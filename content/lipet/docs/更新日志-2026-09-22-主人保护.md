# LiPet 0.29.3 · 主人保护

- 主人保护独立于主动索敌开关：拦截原版或其他机制将宠物主人设置为仇恨目标。
- 在伤害事件 LOWEST 和 HIGHEST 两个阶段检查来源，命中主人时同时取消事件并将伤害归零，防止中间监听器重新放行伤害。
- 除宠物本体与投射物外，识别药水云、唤魔尖牙、来源明确的 TNT 和 DamageSource 的直接/间接实体。
- 保留普通怪物伤害及对其他目标的正常战斗。无需修改原有配置、宠物档案、模型或主动索敌范围。

## 更新

正常停止服务器，备份并移出旧 LiPet Jar，再放入 `plugins/LiPet-0.29.3-SNAPSHOT.jar` 后启动。启动日志应显示 `Enabling LiPet v0.29.3-SNAPSHOT`。不要只执行 `/lipet reload` 或使用热卸载工具。

## 边界

保护依赖可识别的活动宠物伤害来源。其他插件直接修改玩家生命值、不提供施法者的自定义伤害，或违反约定在 MONITOR 阶段改写事件，需单独对接；不宣称仅凭本次保护就兼容所有第三方伤害实现。
