# 安装与更新

> 本页从 LiPet `0.26.19-SNAPSHOT` 完整 Wiki 同步整理；需要连续查阅全部功能时，请返回 [LiPet 完整 Wiki](../home/)。

## 2. 安装

1. 将 `LiPet-0.26.19-SNAPSHOT.jar` 放入服务器 `plugins/` 目录。
2. 启动服务器一次，让插件生成默认配置。
3. 停服，编辑 `plugins/LiPet/` 下的配置文件。
4. 再次启动服务器。
5. 执行 `/lipet status` 检查状态。

需要使用 CraftEngine 自定义物品时，安装 CraftEngine 26.8.1 后可执行 `/lipet status <CE物品ID>` 验证生成与反向识别链路；未安装 CraftEngine 时原版物品功能仍可使用。

单服推荐 SQLite。群组服推荐 MySQL，并按需开启 Redis 同步。

## 22. 升级建议

升级前：

1. 停服。
2. 备份 `plugins/LiPet/`。
3. 备份 SQLite 或 MySQL 数据。
4. 替换 Jar。
5. 启动服务器。
6. 执行 `/lipet status`。
7. 检查控制台是否有 LiPet 警告或错误。

LiPet 会补全新增配置节点，但不会覆盖已有自定义配置值。

## 23. 构建

普通通用包：

```text
mvn clean package
```

Paper 26.2 编译检查：

```text
mvn -Ppaper-26.2 clean package
```

输出：

```text
target/LiPet-0.26.19-SNAPSHOT.jar
```
