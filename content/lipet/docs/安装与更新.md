# 安装与更新

## 运行环境

- Paper / Folia `1.21.11`、`26.1.2`
- Paper `26.2`
- 建议使用 Java 25；插件 Jar 使用 Java 21 字节码构建

Vault、PlaceholderAPI、ModelEngine 为软依赖，未安装时只跳过对应功能。数据库驱动由运行时依赖管理器按需下载，不打入成品 Jar。

## 首次安装

1. 将 LiPet Jar 放入服务器 `plugins/`。
2. 启动一次，让插件生成 `plugins/LiPet/` 配置。
3. 停服并编辑配置文件。
4. 再次完整启动服务器。
5. 执行 `/lipet status` 检查存储、服务端标识和可选依赖状态。

单服推荐 SQLite；群组服必须使用 MySQL，并为每个子服设置不同的 `server.id`。

## 更新步骤

1. 停服。
2. 备份整个 `plugins/LiPet/`。
3. 单独备份 SQLite 文件或 MySQL 数据库。
4. 替换 Jar 后完整启动，不建议用热加载插件。
5. 执行 `/lipet status`，检查控制台最早出现的 LiPet 警告和错误。

LiPet 会补全新版本增加的配置节点，但不会覆盖已有自定义值。
