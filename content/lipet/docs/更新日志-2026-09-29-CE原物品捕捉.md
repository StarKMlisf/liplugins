# LiPet 2.0.1 · CE 原物品与配方捕捉

修复 CE 配方合成的原始物品不能捕捉、必须先由 LiPet 指令发放的问题。现在按 `capture.yml -> balls.<球种>.material` 的完整 CE ID 识别，CE 配方、CE 指令和其他正常获取来源都能直接使用。

- 保留旧 LiPet 标记球兼容；未知、停用或损坏标记不回退到其他球种。
- 同底材原版物品不匹配，重复 CE ID 对应多个启用球种时拒绝原始 CE 物品并输出配置警告。
- 扣除前核验当前主手，显式扣一个；取消仪式、失败不消耗、保存失败退款原物品快照，保留 CE 组件、名称、Lore 和模型。
- 退款只允许认领一次，保留 Paper/Folia 的玩家区域、离线掉落与实体退休调度。
- 附可选的 CE 合成示例 `lipet:basic_capture_ball`，保留已有配置、宠物档案与 2.0 的 100 技能系统。

配置方法见 [CE 配方捕捉球](CE配方捕捉球.md)。更新 Jar 需要正常重启并核对实际加载版本；`/lipet reload` 仅重载配置，不能替换运行中的代码。
