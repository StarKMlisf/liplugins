# 成长与喂养

LiPet 的成长由等级、经验、基础属性和衍生战斗属性组成。宠物可以通过喂食和参与战斗获取经验。

## 基础属性

- 力量：提高攻击伤害。
- 体质：提高生命值与恢复能力。
- 防御：提高伤害减免。
- 敏捷：提高移动速度，并影响闪避等衍生属性。

升级后会获得自由属性点，玩家可在宠物 GUI 中分配。最大等级、升级经验和每级属性点由 `pet-types.yml` 的 `growth` 节点控制：

```yaml
growth:
  maximum-level: 50
  base-experience: 100
  experience-per-level: 25
  attribute-points-per-level: 3
```

## 喂食

管理员可为不同宠物类型配置允许的食物：

```yaml
foods:
  COOKED_BEEF:
    display-name: "熟牛肉"
    experience: 20
    healing: 6.0
    attribute-points: 0
    minimum-level: 1
    maximum-level: 0
```

玩家手持食物右键自己的宠物即可喂食。不符合等级要求，或没有产生回血、经验、属性点效果时，物品不会被消耗；数据保存失败时也会退还食物。

## 技能书

默认技能包括 `power`、`vitality` 和 `agility`。玩家手持技能书右键已召唤的自有宠物即可学习；技能达到最高等级后不再消耗技能书。
