# LiPet 0.29.1 · 主动索敌

此前战斗目标只来自主人攻击或受击事件，空闲时不会主动寻找附近敌对生物。0.29.1 新增独立主动索敌服务，在宠物空闲时选择附近最近的可见敌对生物，并交由现有战斗导航与伤害事件处理。

## 配置

`pet-types.yml` 的公共配置自动补入以下缺失项，不覆盖管理员已有值或注释：

```yaml
defaults:
  behavior:
    auto-attack:
      # true 开启主动索敌；false 保留原有主人攻击/受击触发的助战。
      enabled: true
      # 主人和宠物周围的共同扫描范围，1–16 格，默认 8 格。
      radius: 8.0
```

可以在独立宠物的 `types.<类型ID>.behavior.auto-attack` 使用相同节点覆盖公共设置。修改配置后执行 `/lipet reload` 生效。关闭扫描不会中断已经存在的助战目标；需要立即停战时可让宠物坐下或召回。

## 行为与安全边界

- 默认攻击 Bukkit `Enemy` 类别的敌对生物，包括符合此载体类别的 MM 生物；不根据模型外观或名称判断阵营。用中立载体制作的自定义怪仍沿用主人攻击/受击助战。
- 排除玩家、LiPet 宠物、已驯服生物、带 NPC 元数据的实体、无敌或被牵引生物；不主动挑衅末影人、普通猪灵和僵尸猪灵。
- 目标必须存活、处于视线内，并同时位于主人及宠物的扫描范围。
- 坐下、骑乘、牵引或返回主人时不主动索敌。已有战斗目标不被扫描反复替换，主人走远仍优先跟随。
- Folia 下先检查区域所有权，再读取候选目标状态；不强行访问或加载其他区域目标。
- 伤害仍通过 Bukkit 伤害事件处理，不绕过其他插件的伤害取消。

## 更新方式

备份插件数据和旧 Jar，在维护窗口正常停止 Minecraft 服务端后替换为 `LiPet-0.29.1-SNAPSHOT.jar`，确保仅保留一个 LiPet Jar，再正常启动。不要用 PlugManX 或服务端 `/reload` 更新 Jar。无须关闭电脑。

本次不改变 Parro 模型、类型 ID、品质或等级存档。客户完整包仍需自行安装 MythicMobs 与 ModelEngine，并加载本服务器生成的模型资源包。
