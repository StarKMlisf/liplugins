# LiPet 0.29.0 · 品质、性格与闪光

养成扩展第二批：为新捕捉的宠物增加可见品质、性格和闪光特性。保留第一批的骑乘自动迈步、朝向、命名校验和多行名牌。

## 捕捉与存档

- 新增 `plugins/LiPet/traits.yml`，首次启动自动生成，`/lipet reload` 可重载。
- 新捕捉在生成档案前分别抽取品质、性格和闪光，连同名称及倍率一次写入数据库。
- 已有宠物、商城购买和指令创建保持普通、平衡、非闪光，倍率均为 1，不降低旧属性。
- 召唤、召回、改名、升级、加点、死亡扣级与重新读取存档都沿用已保存的特性；不会重抽。
- 更改抽取配置只影响之后创建的捕捉宠物。已保存的特性名称与倍率不会追随配置改变。
- SQLite 和 MySQL 自动增加可空的 `traits` 列，原有外观独立保留；旧记录空值读取为中性特性。
- 修复 SQLite 空死亡时间被其他字段读取干扰而错误恢复为 1970 年时间的问题。

## 默认数值

| 品质 | 权重 | 升级成长倍率 |
| --- | ---: | ---: |
| 普通 | 70 | 1.0 |
| 优秀 | 20 | 1.1 |
| 稀有 | 8 | 1.2 |
| 史诗 | 1.8 | 1.35 |
| 传说 | 0.2 | 1.5 |

品质权重按总和计算概率，设为 0 的项目不会抽到。品质成长仅乘每级增加的生命与攻击，不乘基础生命、基础攻击或玩家加点收益。

性格默认包括平衡、勇猛、坚韧、灵巧，可独立设置生命、攻击、减伤、步行速度的倍率。性格不会把力量点变成敏捷点，也不会改变暴击率、回血速度、升级经验或骑乘速度。骑乘速度仍由骑乘配置控制。

默认闪光概率为 `0.001`（0.1%），对上述四项实际属性额外乘 `1.2`。闪光以界面及名牌变量文字标识，不替换模型、材质，也不强制给实体添加发光轮廓。

生命公式：`(基础生命 + (等级 - 1) × 每级生命 × 品质成长 + 体质点 × 每点生命) × 性格生命 × 闪光倍率`。

攻击同理。减伤不超过宠物类型的减伤上限，步行属性不超过 1.0；实体生命仍受服务端属性上限约束。技能加成继续在特性基础上叠加。

## 显示与自定义

仓库和信息界面的宠物图标自动追加特性说明，原有自定义 lore 不被替换。新节点：

```yaml
# gui.yml：是否追加特性说明，true/false。
traits-display:
  enabled: true
  # 可自行修改 MiniMessage 模板；不需要追加时关闭 enabled。
  lore:
    - "<gold>品质：</gold><quality> <aqua>性格：</aqua><nature>"
    - "<yellow><shiny></yellow> <gray>成长 ×<growth_multiplier></gray>"
```

自定义名牌可在宠物类型的 `nameplate.lines` 中加入：

```yaml
# 放在 types.你的宠物ID 下，保留你原有的其他配置。
nameplate:
  # 1–8 行 MiniMessage；旧模板不会自动被替换。
  lines:
    - "<pet_name>"
    - "<gold><quality></gold> <aqua><nature></aqua> <yellow><shiny></yellow>"
    - "<gray>主人：<owner_name> · Lv.<level></gray>"
```

GUI 与名牌支持 `<quality>`、`<quality_id>`、`<nature>`、`<nature_id>`、`<shiny>`、`<growth_multiplier>`。

PlaceholderAPI 对应：`%lipet_active_quality%`、`%lipet_active_quality_id%`、`%lipet_active_nature%`、`%lipet_active_nature_id%`、`%lipet_active_shiny%`、`%lipet_active_growth_multiplier%`。没有召唤宠物时返回空文本。

`messages.yml` 新增中性名称、闪光标签及捕捉特性提示，全部支持自定义。品质与性格列表中的名称使用 1–32 字纯文本，不接受颜色代码或换行；颜色写在显示模板中。
