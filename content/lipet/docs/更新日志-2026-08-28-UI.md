# LiPet UI 更新日志 · 2026-08-28

适用版本：`0.26.13-SNAPSHOT`

本次更新为全部 LiPet UI 补齐统一点击反馈，并让一个自定义功能按钮能够同时占用多个槽位。

## 1. 全 UI 点击音效

以下界面全部使用 `gui.yml` 的 `sounds.click`：

- 宠物中心主菜单
- 宠物商城与宠物道具商城
- 宠物仓库
- 宠物属性与加点界面
- 宠物管理界面
- 放生确认界面
- 每只宠物的独立背包

配置示例：

```yaml
sounds:
  # 是否启用打开、点击和关闭三类 GUI 音效。
  enabled: true
  click:
    # 点击任意 LiPet 菜单或宠物背包时播放的 Bukkit 音效键。
    sound: "minecraft:ui.button.click"
    # 音量，取值范围 0-10。
    volume: 0.7
    # 音调，取值范围 0.5-2.0。
    pitch: 1.25
```

点击菜单按钮、填充区域、空槽或宠物背包物品时都会得到反馈；点击菜单外部不会播放。

## 2. 功能按钮多槽位

所有内置按钮、`custom-items`、属性按钮、导航按钮与信息卡片都支持：

```yaml
main:
  buttons:
    shop:
      enabled: true
      # 旧版单槽位，slots 为空时继续使用。
      slot: 11
      # 非空时覆盖 slot，同一个图标和动作会复制到全部槽位。
      slots: [10, 11, 12]
      material: "EMERALD"
      name: "<green><bold>宠物商城</bold></green>"
      action: "nav:shop"
```

规则：

- `slots: []`：继续使用 `slot`，完全兼容旧配置。
- `slots: [10, 11, 12]`：三个槽位显示相同按钮并执行相同动作。
- 重复槽位会按原顺序自动去重。
- 任意槽位小于 0 或超出当前 GUI 行数时，配置加载会给出明确中文错误。
- 自定义过的 `slot`、`slots` 和注释不会在升级时被覆盖。
