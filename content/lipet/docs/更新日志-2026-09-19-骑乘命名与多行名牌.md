# LiPet 0.28.0 · 第一批：骑乘、命名与多行名牌

本版先交付高优先级的骑乘和命名规则，同时补齐完整名牌排版。品质、性格、闪光、材料进化和探索派遣尚未上线，不要把后续规划当作本版功能。

## 原版骑乘

在 `plugins/LiPet/pet-types.yml` 的 `riding` 下设置；单宠物文件可在 `types.<宠物ID>.riding.native` 覆盖。与 `behavior` 同级，不修改原有骑乘速度、跳跃和解锁等级。

```yaml
# 骑乘配置；保留本节点原有其他字段。
riding:
  # 原版驾驶设置；ModelEngine 虚拟驾驶座不使用这组参数。
  native:
    # 迈步高度，范围 0-2 方块；1 可自然跨上完整一格台阶，0 不自动迈步。
    step-height: 1.0
    # LOOK 跟随玩家视角；MOVEMENT 面向水平移动方向，静止时保持原朝向。
    facing: LOOK
```

移动按键始终参考玩家视角。MOVEMENT 模式倒退时宠物转身，侧移时朝向侧面；仅改变显示朝向，不翻转玩家按键。飞行骑乘不改迈步属性。

原版实体只在骑乘期间使用临时迈步高度，下马、任务结束后在实体所属区域恢复；快速换乘时旧恢复任务不覆盖新任务，第三方修改过的值优先保留。ModelEngine 保留自己的座位、控制器、速度和朝向行为，LiPet 不用这组参数抢写模型移动。

## 命名规则

新文件 `plugins/LiPet/naming.yml` 首次加载自动生成，支持 `/lipet reload`。

```yaml
# 去除颜色格式后的最少字符数；整数 1-64，不得大于 max-length。
min-length: 1
# 去除颜色格式后的最多字符数；整数 1-64，默认 16 维持旧规则。
max-length: 16
# 可见文字白名单正则；空字符串不限制，示例允许各语言字母、数字、下划线和空格。
allowed-regex: '^[\p{L}\p{N}_ ]+$'
# 去色后包含即拒绝，不区分大小写；[] 关闭禁用词规则。以下只是示例。
banned-words: ['示例禁用词']
```

颜色和渐变代码不计入可见长度，中文及表情按 Unicode 字符计数。禁止控制字符、换行、不可见格式字符和非安全 MiniMessage 标签；为了兼容现有 MySQL 名称字段，含格式的原始输入最长 128 个 UTF-16 单元。超长渐变标签也可能触发此保护。

新提交的聊天改名、带名字的创建和发放使用同一规则，改名业务保存前再次校验。已有名字保持原样，不自动清洗或重命名。

## 自定义完整名牌

全局 `nameplate.lines` 或单宠 `types.<宠物ID>.nameplate.lines` 可编辑第一行、删除主人行、增加等级行。修改实际加载的宠物目录文件后执行 `/lipet reload`；更新包或 Downloads 内的副本不会自动加载。

```yaml
# 示例宠物映射；把 long_1 改成已有宠物 ID，不要另存一份重复定义同 ID 的文件。
types:
  long_1:
    # 单宠名牌设置，与 behavior/model/display-name 同级。
    nameplate:
      # true 显示 TextDisplay 名牌；false 保持已有原版名称显示逻辑。
      enabled: true
      # 1-8 行、每行最多 512 字符；支持 MiniMessage 和三个组件占位符。
      # <pet_name> 使用宠物已保存的名字（保留颜色），<owner_name> 为主人，<level> 为等级。
      # [] 恢复旧版“宠物名称 + owner-line”双行；省略则继承上层 lines。
      lines:
        - '<gold><pet_name></gold>'
        - '<gray>等级：</gray><green><level></green>'
        - '<gray>主人：</gray><white><owner_name></white>'
```

填写非空 `lines` 后，`owner-line` 不再自动添加。要只显示一行就填写一个列表项；不要用空列表关闭名牌。高度、透明度、背景和骑乘隐藏设置仍照旧生效。占位符使用组件插入，避免把主人名字或已保存的文字再次当作 MiniMessage 指令解析。

## 更新方式

无需删除配置或迁移宠物数据库。正常停服后备份旧 Jar，只保留一个 LiPet Jar，再完整启动；不要使用 PlugManX 热替换。首次加载仅补缺少的配置键，不覆盖管理员已有值。

如果 F:\26.2 正在运行，本版只交付到待更新目录，不中断服务器。龙配置修正版一并附在更新包，尚未自动写入正式服宠物目录。
