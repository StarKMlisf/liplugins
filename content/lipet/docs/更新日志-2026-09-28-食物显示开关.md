# 0.29.15 宠物食物信息显示开关

## 新增功能

- `gui.yml -> info.foods-display.enabled` 控制宠物信息界面是否显示包含 `<foods>` 的整行介绍。
- 每条食物新增 `show-in-pet-info`，可只隐藏某一种食物，不影响其他食物。
- 有食物但全部设为隐藏时，`<foods>` 显示为“未公开”；没有配置任何食物时仍显示“未配置”。

## 配置案例

隐藏整个食物介绍行：

```yaml
info:
  foods-display:
    # false 只隐藏信息界面的介绍行，不影响喂食。
    enabled: false
```

只隐藏某一种食物：

```yaml
growth:
  foods:
    ROTTEN_FLESH:
      enabled: true
      display-name: "腐肉"
      # false 只从 <foods> 列表隐藏，食物仍可正常使用。
      show-in-pet-info: false
      experience: 4
      healing: 2.0
      attribute-points: 0
      minimum-level: 1
      maximum-level: 0
```

## 升级行为

- 旧版完整食物规则会自动补充 `show-in-pet-info: true` 和中文注释。
- 已经配置的 `show-in-pet-info`、物品 ID、显示名称、奖励数值和管理员注释不会被覆盖。
- 只有 `enabled: false` 的继承覆盖节点不会被强行写入显示开关，继续继承公共配置。
- 更新 Jar 后需要正常完整重启，并在控制台确认加载 `LiPet v0.29.15-SNAPSHOT`。
