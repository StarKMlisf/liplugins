# LiPet 0.26.21 鹦鹉名牌跟随修复

日期：2026-08-29

版本：`0.26.21-SNAPSHOT`

## 问题表现

鹦鹉等飞行宠物触发安全回传后，宠物实体已经出现在新位置，但由 TextDisplay 生成的“宠物名称 / 主人”双行名牌仍可能停留在传送前的位置，看起来像名称和宠物完全分离。

## 根因

双行名牌作为宠物实体的乘客显示。旧逻辑直接调用异步传送载体；实体传送过程中乘客关系可能被弹出或未及时同步到客户端，旧 TextDisplay 因此留在原地。

## 修复

- 宠物安全回传前主动移除当前双行名牌。
- 异步传送成功后，在宠物当前实体区域立即重新生成并挂载名牌。
- 传送返回失败或调用直接抛出异常时同样恢复名牌，避免无名牌或孤立文字。
- 区块恢复、骑乘隐藏、死亡、收回和放生的原有名牌流程保持不变。

## 验证

- 新增 `PetTeleportCoordinatorTest`，覆盖“先移除、再传送、最后恢复”的顺序。
- 覆盖传送调用直接失败时仍恢复名牌的回归场景。
- Paper 26.2 Profile 共 119 项自动测试通过，无失败、无跳过。
- 成品已在 Paper 26.2 Build 111 + PlayerPoints 3.3.5 完成加载、挂钩、`/lipet status` 和安全关闭验证，LiPet 日志无报错。
- 测试服没有在线玩家，本轮未进行客户端鹦鹉移动画面复测；请在正式换包后实机确认一次名牌视觉效果。
