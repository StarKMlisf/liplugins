# 命令与权限

主命令为 `/lipet`。

## 玩家指令

| 指令 | 权限 |
| --- | --- |
| `/lipet` | `lipet.command.use` |
| `/lipet menu` | `lipet.command.menu` |
| `/lipet shop` | `lipet.command.shop` |
| `/lipet itemshop` | `lipet.command.itemshop` |
| `/lipet warehouse` | `lipet.command.warehouse` |
| `/lipet balance` | `lipet.command.balance` |
| `/lipet call <名称>` | `lipet.command.call` |
| `/lipet store` | `lipet.command.store` |
| `/lipet sit` | `lipet.command.sit` |
| `/lipet mount` | `lipet.command.mount` |
| `/lipet inventory [名称]` | `lipet.command.inventory` |
| `/lipet rename [名称]` | `lipet.command.rename` |
| `/lipet release [名称]` | `lipet.command.release` |
| `/lipet info <名称>` | `lipet.command.info` |
| `/lipet help [页码]` | `lipet.command.help` |

以上权限默认开放给玩家；捕捉球另需 `lipet.capture`。

## 管理员指令

| 指令 | 权限 |
| --- | --- |
| `/lipet create <类型> <名称>` | `lipet.command.create` |
| `/lipet list` | `lipet.command.list` |
| `/lipet captureball <类型> [数量] [玩家]` | `lipet.command.captureball` |
| `/lipet skillbook <技能> [数量] [玩家]` | `lipet.command.skillbook` |
| `/lipet signalstick [数量] [玩家]` | `lipet.command.signalstick` |
| `/lipet status` | `lipet.command.status` |
| `/lipet reload` | `lipet.command.reload` |

除 `list` 外，管理指令权限默认仅 OP。`lipet.admin` 是管理员总权限。全部子命令均提供参数补全。
