# LiPet 0.26.26 管理菜单返回修复

日期：2026-08-29

版本：`0.26.26-SNAPSHOT`

## 修复内容

- 从宠物管理界面点击“完整属性”或“成长与加点”后，属性面板的返回按钮改为“返回管理界面”。
- 点击返回会重新打开同一只宠物的管理页，不需要关闭菜单后再次潜行右键宠物。
- 从宠物仓库或指令直接打开属性面板时，返回按钮仍为“返回宠物仓库”，原有操作路径不变。
- 属性加点成功后刷新面板时继续保留打开来源，避免刷新一次后返回路径再次退化为仓库。

## 配置

`gui.yml` 新增以下可完整自定义的导航按钮：

```yaml
info:
  navigation:
    manage:
      # 从宠物管理界面进入属性面板时返回同一只宠物的管理界面。
      enabled: true
      slot: 49
      slots: []
      material: "CHEST"
      name: "<aqua>返回管理界面</aqua>"
      lore:
        - "<dark_gray>◆ 界面导航</dark_gray>"
        - "<gray>返回 <white><pet_name></white> 的管理界面</gray>"
        - ""
        - "<aqua>➥ 点击返回管理界面</aqua>"
      action: "manage-return:<entity_id>"
```

旧服启动或执行 `/lipet reload` 时只补充缺失节点和中文注释，不覆盖服主自定义的名称、Lore、材质、槽位或动作。
