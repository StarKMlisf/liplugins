# 0.29.16 宠物信息食物展示优化

## 优化内容

- 单种食物显示开关统一为 `show-in-pet-info`，名称明确表示只影响宠物信息界面。
- 兼容 0.29.15 的 `show-in-info`；升级时复制原布尔值，不会把管理员的 `false` 改回 `true`。
- 没有任何允许公开的食物时，默认直接移除包含 `<foods>` 的整行介绍。
- 新增 `<foods_visible>` 和 `<foods_count>` 界面变量，方便自定义菜单判断和显示。
- 食物显示格式、分隔符和空内容文字全部支持配置与 MiniMessage。

## 单种食物配置

```yaml
growth:
  foods:
    ROTTEN_FLESH:
      enabled: true
      display-name: "腐肉"
      # false 只隐藏宠物信息界面中的这一项，仍可正常喂食。
      show-in-pet-info: false
      experience: 4
      healing: 2.0
      attribute-points: 0
      minimum-level: 1
      maximum-level: 0
```

## 信息界面排版

```yaml
info:
  foods-display:
    # false 隐藏所有包含 <foods> 的介绍行。
    enabled: true
    # 没有任何可显示食物时，直接移除整行。
    hide-line-when-empty: true
    # 可用 food_name、experience、healing、attribute_points、minimum_level、maximum_level。
    item-format: "<food_name><gray>(+<experience>经验)</gray>"
    separator: "<dark_gray>、</dark_gray>"
    # 仅在 hide-line-when-empty=false 时使用。
    empty-text: "未配置"
```

## 行为边界

- 所有显示开关只影响宠物信息界面的 Lore。
- 不影响食物识别、物品扣除、喂养、经验、治疗、属性点或等级限制。
- 修改配置后可执行 `/lipet reload`；替换到 `0.29.16-SNAPSHOT` Jar 时仍需完整重启一次。
