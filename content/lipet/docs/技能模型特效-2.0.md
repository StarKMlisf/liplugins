# LiPet 2.0 技能模型与特效

100 个内置技能都配置了粒子形状、颜色、音效和表现时长。自动释放与手动释放共用同一套表现。每次成功释放首先显示原生粒子并播放音效；ModelEngine 或 CraftEngine 缺失、模型 ID 错误不会取消这一层表现，也不改变技能伤害和冷却。

## 六种原生粒子形状

| `visual.shape` | 可见运动 |
| --- | --- |
| `RING` | 逐渐扩张、轻微上升的光环 |
| `HELIX` | 围绕施法位置旋转、向上推进的双圈螺旋 |
| `BURST` | 向外扩张的球形爆发 |
| `BEAM` | 向施法瞬间的目标位置推进的螺旋光束；无目标时向前形成短光束 |
| `STAR` | 旋转并扩张的五角星 |
| `WAVE` | 向外扩张、上下起伏的波纹 |

`DUST` 使用 `visual.color` 的 RGB 颜色。火焰等没有颜色参数的粒子会混合彩色节点，保留配置颜色。未知粒子或需要不支持的数据类型的粒子退回彩色尘埃；未知音效退回紫水晶音效。正常配置重载还会事先验证粒子、色值和音效名称，拒绝错误的新配置。

资源包自定义 `namespace:sound.key` 使用 Bukkit 字符串音效接口播放，并叠加一声原生提示音；玩家没有下载资源包时仍能听到释放反馈。

表现以释放时的位置为中心，光束目标使用当时的坐标快照；这不会追踪、攻击或读取其他 Folia 区域内的实体。

## 原版或 CraftEngine 物品模型

编辑 `plugins/LiPet/pet-skills.yml` 中对应技能的 `visual` 节点。下面仅展示该节点，替换已有节点时保留技能其余数值：

```yaml
visual:
  # 粒子名称；可用 DUST 或 Bukkit 无附加数据的粒子。
  particle: DUST
  # 形状；可选 RING、HELIX、BURST、BEAM、STAR、WAVE。
  shape: HELIX
  # RGB 颜色；必须为 # 后接 6 位十六进制字符。
  color: '#A866FF'
  # 音效；Bukkit 大写名称或 minecraft:sound.key。
  sound: BLOCK_AMETHYST_BLOCK_CHIME
  # 展示物品；可用 minecraft:amethyst_shard、AMETHYST_SHARD 或已安装 CE 物品 ID。
  model-item: minecraft:amethyst_shard
  # ModelEngine 蓝图 ID；空字符串关闭这一可选模型。
  model-engine-id: ''
  # ModelEngine 动画名；空字符串仅展示模型。
  animation: ''
  # 表现寿命；8～60 tick，20 tick 约为 1 秒。
  duration-ticks: 24
  # 模型大小倍率；范围 0.1～4。
  scale: 1.0
```

CE 模型直接填写物品真实 ID，例如 `my_pack:skill_orb`，不额外包一层 `ce:` 前缀。需要服务器已经安装 CraftEngine、注册该物品，并让客户端接受对应资源包。

物品模型通过临时 `ItemDisplay` 展示，具有旋转、浮动和缩放动画。展示实体不会掉落物品或向玩家发放物品，表现结束时移除。

## ModelEngine 模型与动画

把 `model-engine-id` 改为服务器已经导入的 ModelEngine 蓝图 ID，把 `animation` 改为该蓝图真实存在的动画名。两者都来自管理员提供的模型资源，LiPet 不附带商业模型或假定存在的技能模型。

模型挂载在 LiPet 为本次技能单独创建的、不可碰撞且不可伤害的临时标记盔甲架上。不会替换、卸载或改动宠物自身的 ModelEngine/MythicMobs 外观。支持模型缩放与 `playAnimation` 播放，技能模型不覆盖碰撞箱、不保存到磁盘。动画名不存在时，保留模型和粒子并限频提示。

同时填写两种模型时优先使用 ModelEngine；ModelEngine 缺失或载体创建失败时可回退到物品模型。蓝图挂载时失败会清理载体并保留粒子。模型、物品或依赖故障的中文控制台提示最多每 30 秒一次，不输出堆栈。

## 预算与回收

- 每次表现每帧固定最多 18 个粒子，动画每 4 tick 更新一次，最长 60 tick；特效半径限制在 0.6～4 格，光束最长约 12 格。伤害判定范围仍使用技能自己的数值。
- 每只宠物至多一个持续表现，全服至多 32 个持续表现。超过持续表现预算的成功释放仍有首帧粒子和音效。
- 每 2 tick 检查宠物活动状态、死亡、跨世界及远距离传送。技能结束、宠物召回或死亡、配置重载时取消表现任务并在临时实体所属区域清理。
- 正常停服时取消任务；临时 Bukkit 实体与 ModelEngine 容器均不持久化。Folia 的关闭线程若不拥有实体区域，不会越区强行操作实体，剩余非持久化载体随服务器退出释放。服务器运行期间强制热卸载插件不能保证其他已停调度区域中的载体立即消失；正式更新使用完整停服再启动。

配置与服务器启动检查不能代替真实客户端验收。接入自定义资源包后，应在客户端检查模型贴图、动画长度、缩放、声音和粒子密度；粒子显示还受玩家客户端粒子设置影响。
