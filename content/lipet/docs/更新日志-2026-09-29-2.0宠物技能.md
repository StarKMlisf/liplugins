# LiPet 2.0.0 · 百种宠物技能

新增独立的原生主动技能系统：内置 100 个技能，每只宠物默认拥有 3 个技能槽，战斗自动释放，也可以通过指令手动释放。每个技能都预置粒子、RGB 配色、动态轨迹和音效，不安装 CraftEngine、ModelEngine 或 MythicMobs 也可以使用默认技能特效。

## 技能与表现

- 10 个主题，每个主题包含攻击、范围伤害、治疗、再生、加速、抗性、减速、虚弱、持续毒伤、击退，共 100 个技能定义。不同主题使用不同数值、冷却和视觉配色；这是 10 种效果机制的 100 个配置技能。
- 环形、螺旋、爆发、光束、星阵、波浪六种动态轨迹，持续时间和大小可配置；粒子与音效始终作为默认表现。
- 可选原版或 CraftEngine 物品模型，以及 ModelEngine 模型和动画。模型未安装、ID 错误或接口不兼容时降级为粒子和音效。
- 100 个技能名称、说明、数值、冷却和模型字段见 [宠物技能目录](宠物技能目录-2.0.md)，模型接入见 [技能模型特效](技能模型特效-2.0.md)。

## 玩家指令

| 指令 | 用途 |
| --- | --- |
| `/lipet skills` | 查看当前已召唤宠物的三个技能、完整 CD 和剩余 CD |
| `/lipet skills cast 1` | 手动释放第一槽；第二、三槽使用 `2`、`3` |
| `/lipet skills list [页码]` | 每页查看 10 个已启用技能 |
| `/lipet skills info <技能ID>` | 查看指定技能说明、CD 与施法距离 |

权限 `lipet.command.skills` 默认授予玩家；控制台可查看目录和详情，施法仅限宠物主人。所有参数提供 Tab 补全。攻击技能使用宠物当前战斗目标，治疗和自身增益可以手动在无目标时释放。

## 三槽与冷却

新文件 `plugins/LiPet/pet-skills.yml` 按物种分配三个默认技能，自定义宠物使用三槽后备组合。`loadouts.type-overrides` 可按完整宠物类型 ID 指定三个不同技能，无需改数据库，旧宠物召唤后也会获得默认三槽。该版本不增加玩家自由换槽或随机学习机制；旧 `skills.yml` 被动技能书继续保留。

自动释放只在战斗目标有效时轮换三个槽位，不持续在空闲状态刷特效。坐下、骑乘、牵引、返回主人、主人离线或跨区域时不施法。恢复与增益没有实际用途时不占用 CD。

每个技能有独立 CD，并有公共施法间隔。自动与手动共用冷却，按宠物数据库 UUID 记录；召回、重召和 `/lipet reload` 不清除未到期 CD。冷却保存在本次服务器运行内存中，完整重启后重置。

## 保护与性能

- 技能不攻击主人、其他玩家、其他 LiPet 宠物、已驯服生物、NPC 或盔甲架。伤害和控制遵守区域所有权、世界、距离、视线及领地规则。
- 原生伤害保留宠物来源，保护插件取消后不记为成功。持续毒伤每秒重新检查会话和保护规则，不使用丢失来源的原版中毒伤害。
- 每次释放都有首帧粒子和音效；最多同时保留 32 组持续动画，超出预算时只播放首帧。每只宠物保留一组持续动画，最长 3 秒。
- 召回、死亡、跨世界、动画结束和配置重载会回收临时模型；正常停服使用非持久化载体避免保存残留。不要使用 PlugManX 等方式热卸载。

## 升级

正常停止服务端，备份原 Jar、LiPet 配置和数据库，只保留 `LiPet-2.0.0.jar`，再完整启动。检查启动日志 `Enabling LiPet v2.0.0`。首次启动自动生成 `pet-skills.yml`，旧配置和消息仅补缺失项，不覆盖已有食物、捕捉球、支付 ID、价格或语言。

技能数值与特效修改可以 `/lipet reload`；替换 Jar 必须完整重启。模型资源包仍需玩家接收对应 CE/ModelEngine 资源包，插件没有附带 100 份外部模型资产。
