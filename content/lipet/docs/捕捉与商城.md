# 捕捉与商城

LiPet 提供两种主要获取方式：捕捉野生生物和从宠物商城购买。

## 捕捉宠物

管理员使用以下指令发放捕捉球：

```text
/lipet captureball <类型> [数量] [玩家]
```

玩家手持捕捉球右键目标生物后，会按 `capture.yml` 启动捕捉仪式并计算结果。仪式持续时间、脉冲间隔、粒子、音效、实体映射和捕捉概率均可配置。

无效的 Sound 或 Particle 会回退到安全默认值，不会因此禁用插件。同一种宠物默认只能拥有一只，已有对应类型时不能重复捕捉或购买。

## 宠物商城

使用 `/lipet shop` 打开宠物商城。单个商品可设置宠物类型、显示名、价格、货币和额外权限：

```yaml
entries:
  wolf:
    enabled: true
    pet-type: "wolf"
    pet-name: "<gradient:#B0BEC5:#FFFFFF>小狼</gradient>"
    currency: "INTERNAL"
    price: 250.0
    permission: ""
```

货币支持：

- `INTERNAL`：LiPet 内置宠物币。
- `VAULT`：由 Vault 连接服务器经济插件。

## 道具商城

使用 `/lipet itemshop` 打开道具商城。管理员可在 `shop.yml` 的 `item-entries` 中出售宠物食物、技能材料或其他服务器道具。
