# LiPet 0.26.16 骑乘与交互更新

适用版本：`0.26.16-SNAPSHOT`

## 骑乘显示监听

- 新增专门的实体挂载与离开监听，不再依赖某一个右键或指令入口主动刷新。
- 玩家骑上宠物时立即隐藏双行 TextDisplay 名牌，下坐骑后自动恢复。
- `pet-types.yml` 新增 `riding.hide-boss-bar-while-ridden`，默认 `true`；凋零、末影龙等 Boss 宠物骑乘时隐藏血条，下坐骑后恢复骑乘前状态。
- 原有 `nameplate.hide-while-ridden` 继续单独控制名牌，两个选项均可热重载且带完整中文注释。

## 末影龙交互

- 末影龙的头、身体、翅膀等交互目标会统一解析回带 LiPet 标记的龙本体。
- 空手右键末影龙可以正常进入骑乘。
- 潜行并空手右键末影龙可以正常打开宠物管理界面。
- 信号棒右键末影龙身体部件也会被识别为当前宠物。

## 指令与语言

- `/lipet give`、`/lipet take` 等玩家参数的 Tab 补全只显示在线玩家和 `-all`，不再把离线玩家名字铺满补全列表。
- 离线玩家名称和 UUID 仍可手工输入，离线发放/收走能力没有删除。
- 已有宠物时再次执行召唤，提示会显示 `<active_pet>` 当前宠物和 `<pet_name>` 目标宠物，并引导先使用 `/lipet store`。
- 仅迁移插件曾发布的两条旧默认召唤冲突文本；服主自定义消息不会被覆盖。
- 新增 `/lipet delete [宠物名称]`、`lipet.command.delete`、中文帮助和独立结果消息；不填写名称时删除当前活动宠物。该操作永久删除数据库、背包、会话和实体数据，无法恢复。

## 升级

1. 停止服务器。
2. 备份 `plugins/LiPet/`。
3. 替换为 `LiPet-0.26.16-SNAPSHOT.jar`。
4. 完整启动服务器，不使用 `/reload` 替代重启。
5. 检查 `pet-types.yml` 是否自动补入 `riding.hide-boss-bar-while-ridden: true`。
6. 分别骑乘凋零和末影龙，确认骑上后名牌与 Boss 血条隐藏、下坐骑后恢复；再对末影龙测试空手右键和潜行右键。
