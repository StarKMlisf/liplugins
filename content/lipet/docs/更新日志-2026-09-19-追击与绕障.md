# LiPet 0.29.2 · 追击与绕障

此版本保留 0.29.1 的主动索敌，修复追击期间停顿的两种情况，并增加卡住目标恢复。

- 目标虽然在 3 格内，但被墙挡住时继续尝试原生寻路绕障，不再原地停止等待视线恢复。仍然不允许隔墙造成兜底近战伤害。
- 战斗中的返回距离与空闲跟随距离分开：战斗返回距离为 `min(teleport-distance, max(follow-distance, auto-attack.radius + stop-distance))`。默认 Parro 参数下为 11 格，空闲时仍按 5 格开始跟随。主人走远会脱战返回，返回期间不重新抢目标。
- 追击期间连续约 4 秒没有移动超过 0.5 格，放弃当前目标，并在主动索敌时跳过该目标 5 秒，避免不可达目标一直占用宠物。其他可见敌对目标仍可选取；玩家明确指挥攻击不受主动扫描冷却限制。

本次不增加需要手动填写的新配置，沿用 `behavior.auto-attack.enabled/radius`，不修改已有宠物数据或模型。

## 确认更新真正加载

把新 Jar 放在服务器根目录或只执行 `/lipet reload`，不会更新正在运行的 Java 代码。请在维护窗口正常停止 Minecraft 服务端，备份并移出旧 LiPet Jar，放入 `plugins/LiPet-0.29.2-SNAPSHOT.jar` 后重新启动，确保 `plugins` 和 `plugins/update` 没有冲突的旧包。

启动日志应显示 `Enabling LiPet v0.29.2-SNAPSHOT`。不要使用 PlugManX 或服务端 `/reload` 热卸载插件，无需关闭电脑。

主动索敌默认只选择可见敌对生物，不主动攻击玩家、其他 LiPet 宠物、驯服生物、NPC、部分中立生物。MM 生物使用中立载体时仍需主人指挥；目标受到领地或其他插件保护时，LiPet 不绕过伤害取消。
