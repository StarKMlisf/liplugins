# LiPet 2.3.10 · 仓库独立宠物图标

仓库支持按宠物类型分别配置原版或 CraftEngine 物品图标，不再要求所有宠物使用同一个图标。

在现有 gui.yml 的 warehouse 节点内添加 pet-icons。不要新建第二个 warehouse 节点，也不要整份覆盖旧配置：

```yaml
warehouse:
  pet-icons:
    slime: "SLIME_BALL"
    wolf: "BONE"
    dragon: "xiaoyu:pet_dragon_icon"
```

- 左侧填写宠物定义中的正式类型 ID，不是昵称或宠物 UUID；旧存档类型别名会先解析为正式 ID。同类型宠物使用相同图标。
- 右侧支持 Bukkit 原版材质、minecraft 命名空间物品或 CE 完整物品 ID。示例 ID 只是示范，需换成服务器已注册的 CE 物品，且玩家须加载对应资源包。
- 未配置的类型继续使用 warehouse.pet-item。默认 pet-icons: {} 不改变旧服外观。
- 图标保留原来的名称、属性说明、数量、提示设置及点击操作；自定义图标不继承通用 custom-model-data/item-model，以免覆盖 CE 物品的模型。
- CE 不可用或 ID 不存在时，沿用屏障图标与配置中的中文提示；不阻断其他宠物展示。
- 拒绝空气、空字符串和非法格式，错误包含具体配置路径。修改后执行 /lipet reload 并重新打开仓库。

升级：正常停服备份，移出旧 LiPet Jar，仅放入 LiPet-2.3.10.jar，保留原配置和数据库。启动确认 Enabling LiPet v2.3.10。新版默认配置包含完整中文说明，无需更换现有 CE 或模型资源包，也不附送示例 CE 物品。
