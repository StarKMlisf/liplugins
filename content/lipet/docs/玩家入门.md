# 玩家入门

LiPet 把宠物的获取、养成和管理集中在 `/lipet` 菜单中。第一次进入服务器时，可以先打开宠物商城或使用捕捉球获得宠物。

## 基本流程

1. 使用 `/lipet shop` 购买宠物，或用捕捉球右键符合条件的野生生物。
2. 在 `/lipet warehouse` 找到已拥有的宠物。
3. 使用 `/lipet call <宠物名称>` 召唤宠物。
4. 喂食、参与战斗并分配升级获得的属性点。
5. 离线或换服前使用 `/lipet store` 收回宠物。

## 常用入口

| 操作 | 指令 |
| --- | --- |
| 宠物中心 | `/lipet` 或 `/lipet menu` |
| 宠物商城 | `/lipet shop` |
| 道具商城 | `/lipet itemshop` |
| 宠物仓库 | `/lipet warehouse` |
| 查看余额 | `/lipet balance` |
| 查看属性 | `/lipet info <宠物名称>` |

## 日常管理

- `/lipet sit`：让当前宠物坐下或恢复跟随。
- `/lipet mount`：骑乘当前宠物。
- `/lipet inventory [宠物名称]`：打开宠物独立背包。
- `/lipet rename [宠物名称]`：进入聊天改名流程，输入 `取消` 或 `cancel` 可退出。
- `/lipet release [宠物名称]`：永久放生，操作前请确认。

宠物名称、类型、等级、经验与当前状态也可通过 PlaceholderAPI 显示在菜单、计分板或聊天格式中。
