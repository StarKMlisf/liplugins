# LiPet 2.0 宠物主动技能目录

内置 100 项原生主动技能，分为 10 个元素主题、10 类效果。每只宠物默认 3 个不同技能，战斗自动轮换，也支持玩家手动指令。每项技能有独立冷却，并受到默认 1.5 秒公共冷却约束。

每项默认技能均配置粒子、RGB 配色、形状、音效。无需 MythicMobs、资源包或模型插件即可显示基础特效。支持附加原版物品、CraftEngine 物品模型，以及已安装 ModelEngine 的真实蓝图/动画；未配置模型时仍显示基础特效。

配置文件：`plugins/LiPet/pet-skills.yml`。`loadouts.type-overrides` 按完整宠物类型 ID 覆盖；`loadouts.species` 适用于原版类型和 `vanilla_` 前缀类型；其余类型使用 `loadouts.fallback`。三槽顺序即槽位 1/2/3。禁用某项技能后，先用 fallback、再按技能目录顺序补足 3 个不重复技能；少于 3 个启用技能会拒绝整次配置加载。

`visual.model-item` 可填 `minecraft:amethyst_shard`、`AMETHYST_SHARD` 或实际 CraftEngine `命名空间:物品ID`；`visual.model-engine-id` 填已安装的蓝图 ID，`visual.animation` 填该模型已有动画名。模型相关字段默认留空。

表中伤害和治疗均以生命值点计（2 点 = 1 颗心）；持续时间以秒列出（20 tick = 1 秒）；药水效果等级按 I/II/III/IV 显示；毒伤由带宠物来源的每秒伤害脉冲实现，强度取 power，并在目标失效、保护取消或重载后终止。加速、抵抗、再生与治疗作用于宠物自身；伤害及负面状态作用于合法战斗目标。每项具体目标保护和伤害规则由技能引擎统一执行。
