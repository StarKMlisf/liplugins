# 常见问题

## 支持 Paper 26.1.2 吗？

支持。通用 Jar 使用 Java 21 字节码并保留较低的 `api-version`，可在 Paper/Folia 1.21.11、Paper/Folia 26.1.2 和 Paper 26.2 使用；运行环境建议 Java 25。

## 重启后宠物不见了怎么办？

确认 `storage.type` 为 `SQLITE` 或 `MYSQL`，检查启动日志中的数据库错误。旧版 `MEMORY` 存储会迁移为 SQLite，生产环境请备份实际数据库。

## 可以在多个子服共用数据吗？

可以使用 MySQL。所有子服设置相同 `server.group`，但必须使用不同的 `server.id`。Redis 是同步预留项，不能代替 MySQL。

## 为什么不能再次购买或捕捉同类型宠物？

同一种宠物默认只允许拥有一只。已有该类型时，商城和捕捉都会拒绝重复获得。

## 宠物背包能设置任意大小吗？

不能。设置为 `0` 可禁用，否则必须是 9 的倍数且最大 54。

## 没安装 Vault 或 PlaceholderAPI 会禁用插件吗？

不会。它们是软依赖，只会停用对应的 Vault 货币或变量功能。使用 `VAULT` 商品前必须安装 Vault 和可用的经济插件。

## 可以用插件管理器热重载吗？

不建议。升级 Jar、切换存储类型或修改运行时依赖后请完整重启服务器。
