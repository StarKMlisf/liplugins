# 跟随、骑乘与战斗

## 跟随与坐下

宠物召唤后默认跟随主人。使用 `/lipet sit` 或信号棒可在“坐下”和“跟随”之间切换。

LiPet 在每次召唤时恢复原版 AI、Mob 感知和站立状态；只有玩家主动设置为坐下时才暂停 AI。重新切换为跟随后会立即恢复。

## 骑乘

可以通过以下方式骑乘自己的已召唤宠物：

- 空手右键宠物。
- 使用 `/lipet mount`。
- 使用信号棒的骑乘模式。

管理员可在 `pet-types.yml` 调整骑乘速度和跳跃力度：

```yaml
behavior:
  riding-speed: 0.35
  jump-velocity: 0.5
```

## 战斗行为

具备原版攻击寻路的实体由原版 AI 控制。缺少原版攻击 AI 的被动生物使用 LiPet 的辅助追击与近战逻辑，避免出现无法接近目标的情况。

战斗可为宠物提供经验。力量、体质、防御和敏捷会继续影响伤害、生命、减伤、暴击、闪避、击退抗性、吸血与恢复等衍生属性。

宠物死亡后进入配置的冷却状态，不能立即重新召唤。疣猪兽、猪灵等跨维度僵尸化实体以及怕阳光的宠物会受到额外保护。
