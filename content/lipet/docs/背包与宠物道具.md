# 背包与宠物道具

## 独立背包

每只宠物都有独立背包，使用以下指令打开：

```text
/lipet inventory [宠物名称]
```

背包在关闭 GUI 时保存到 SQLite 或 MySQL，删除宠物时会同步清理背包数据。

配置规则：

- `inventory.size: 0` 表示禁用背包。
- 大小必须是 9 的倍数。
- 最大为 54 格。

服务器崩溃时，最后一次尚未关闭的界面可能来不及保存，因此生产服仍应定期备份数据库。

## 宠物信号棒

管理员发放：

```text
/lipet signalstick [数量] [玩家]
```

- 右键：执行当前模式。
- 潜行 + 右键：切换模式。
- 支持坐下/跟随、收回、骑乘和打开背包。

信号棒使用 PDC 标记识别，不依赖物品名称。不要用铁砧或其他插件复制显示名来伪造。

## 技能书

管理员发放：

```text
/lipet skillbook <技能> [数量] [玩家]
```

玩家手持技能书右键自己的已召唤宠物即可学习。技能配置位于 `skills.yml`。
