# LIEMC 兑换、回收与 EMC 经济

## EMC 是什么

EMC 是 LIEMC 用来衡量资源价值的单位。玩家可以出售物品获得 EMC，再用 EMC 兑换已经解锁的物品。它强调资源循环，而不是直接开放一张无限购买清单。

## 完成第一次兑换

1. 执行 `/emc convert` 打开回收界面。
2. 放入服务器已配置价值的物品。
3. 确认转换，获得 EMC 并解锁该物品。
4. 执行 `/emc` 打开商店。
5. 找到已解锁物品并选择兑换数量。

默认开启“先解锁再兑换”。如果物品仍显示未解锁，先实际出售一次该物品。

## 一键出售

`/emc sellall` 会扫描玩家背包，只处理存在 EMC 配置的物品。执行前建议确认背包中没有准备保留的高价值资源。

## 余额与转账

| 操作 | 指令 |
| --- | --- |
| 查看自己的余额 | `/emc balance` |
| 查看他人余额（需要管理权限） | `/emc balance <玩家>` |
| 向在线玩家转账 | `/emc pay <玩家> <数量>` |

转账前检查玩家名和数量。是否允许小数、余额显示方式和实际经济来源由服务器配置决定。

## 经济来源

服主可以在三种提供者之间选择：

- `internal`：LIEMC 自己保存 EMC，最适合独立资源经济。
- `vault`：使用 Vault 对接的服务器金币。
- `playerpoints`：使用 PlayerPoints 点券。

玩家看到的菜单流程不变，但余额来源由服主决定。详细节点见[配置说明](./配置说明.md)。

## 交易失败时

- 检查物品是否配置 EMC 价值。
- 检查是否已经解锁。
- 检查余额是否足够。
- 检查背包是否有空间。
- 如果使用 Vault 或 PlayerPoints，检查对应经济插件是否正常加载。
