# LIEMC build.108 更新说明

版本：`0.1.0+build.108`，日期：2026-10-03。

- 修复 `/emc addheld` 为未自定义名称的原版物品写入 `Stone` 等英文材质名的问题。
- 原版物品没有显式 `displayName` 或 `itemName` 时，配置中的 `name` 保持为空，由客户端按玩家自己的语言显示原版名称。
- 原版物品存在显式自定义名时仍会保留，不改变管理员或物品作者设定的名称。
- CraftEngine 条目的 `name` 固定留空，以 CraftEngine 每次创建物品时提供的最新名称为唯一来源，避免旧名称覆盖更新后的名称。
- 跨服同步数据缺少 `name` 时默认使用空名称，不再回退为英文材质名。

## 历史条目处理

build.108 不会自动清空历史条目中已经保存的英文名称，以免覆盖管理员刻意配置的英文显示名。

如需让旧条目改为按客户端语言显示，请手持没有显式自定义名称的对应原版物品，使用原 ID、正确 EMC 价格以及正确的解锁成本、取出数量等选项重新执行 `/emc addheld`。使用 MySQL 跨服时，还需确认更新已正确写入共享数据库并同步到其他子服。不要只清空本地配置中的 `name`，否则后续数据库同步可能重新覆盖本地修改。CraftEngine 历史条目也应使用当前 CE 物品和原 ID 重新执行命令，确保名称继续以 CraftEngine 当前创建结果为准。

升级时请停服替换 JAR，并保留数据库与现有配置。完成后检查新上架的无自定义名原版物品能否随客户端语言显示，同时确认显式自定义名与 CraftEngine 物品名称仍正确。
