# LIEMC 命令与权限

## 玩家命令

| 指令 | 说明 |
| --- | --- |
| `/emc`、`/liemc` | 打开 EMC 商店 |
| `/emc convert` | 打开物品回收界面 |
| `/emc search <关键词>` | 搜索商品 |
| `/emc sellall` | 出售背包内全部可转换物品 |
| `/emc balance` | 查看余额 |
| `/emc pay <玩家> <数量>` | 向玩家转账 |
| `/emc autorefill [on|off]` | 查询、开启或关闭自动补充 |

## 管理员命令

| 指令 | 说明 |
| --- | --- |
| `/emc reload` | 重载配置并拉取跨服商品 |
| `/emc give <玩家> <数量>` | 发放 EMC |
| `/emc giveall <数量>` | 给全部在线玩家发放 EMC |
| `/emc balance <玩家>` | 查询指定玩家余额 |
| `/emc unlockall [玩家]` | 解锁全部商品 |
| `/emc stats` | 查看物品统计 |
| `/emc addheld <id> <emc> [unlockCost] [withdrawAmount]` | 将主手物品加入或更新到商店 |
| `/emc removeitem <id>` | 下架商品并写入同步记录 |
| `/emc sortitems` | 整理商品分类顺序 |

`/emc addhand` 是 `addheld` 的别名，`/emc delitem` 是 `removeitem` 的别名。全部子命令支持 Tab 补全。

## 权限

| 权限 | 默认 | 说明 |
| --- | --- | --- |
| `liemc.use` | 所有人 | 使用基础 EMC 功能 |
| `liemc.admin` | OP | 使用管理命令，并继承基础权限 |

## 上架建议

上架前确认主手物品正确，再使用不重复的稳定 ID。跨服环境中优先使用命令上架，避免各子服手动配置产生不同版本。
