# LIEMC 功能清单

## 玩家能力

| 模块 | 能做什么 | 入口 |
| --- | --- | --- |
| EMC 商店 | 使用 EMC 兑换已经解锁的资源 | `/emc` |
| 物品回收 | 把支持的物品转换成 EMC，并完成首次解锁 | `/emc convert` |
| 一键出售 | 出售背包里全部可转换物品 | `/emc sellall` |
| 搜索 | 按关键词查找商店物品 | `/emc search <关键词>` |
| 收藏 | 保存常用商品，并从收藏页快速兑换 | 商店内 Shift+点击 |
| 自动补充 | 手中方块用完后自动消耗 EMC 补充 | `/emc autorefill on` |
| 转账 | 在玩家之间转移 EMC | `/emc pay <玩家> <数量>` |

收藏只改变查找入口，不会自动解锁物品，也不会绕过兑换限制。

## 管理能力

- 为单个玩家或全服发放 EMC。
- 查询余额、物品统计并批量解锁。
- 将主手物品连同名称、Lore 和模型信息加入商店。
- 删除商店物品并同步下架记录。
- 使用 SQLite 运行单服，或使用 MySQL 共享玩家与商店数据。
- 选择内置 EMC、Vault 或 PlayerPoints 作为经济来源。
- 通过 PlaceholderAPI 在菜单、计分板和聊天中显示数据。

## 推荐阅读顺序

1. 玩家先读[兑换、回收与 EMC 经济](./兑换与回收.md)。
2. 再了解[解锁、搜索、收藏与自动补充](./解锁搜索与自动补充.md)。
3. 服主按[安装与更新](./安装与更新.md)完成部署。
4. 上线前对照[测试与故障排查](./测试与故障排查.md)逐项检查。

## 当前边界

- 手动修改现有商品价值时，应确认其他子服的配置也已同步。
- 自动补充只处理已经配置 EMC 价值的物品，创造模式不会触发。
- Vault、PlayerPoints 和 PlaceholderAPI 都是可选依赖；没有对应插件时不会获得相关功能。
