# LIEMC 测试与故障排查

## 上线前测试

1. `/emc` 能打开商店。
2. `/emc convert` 能识别已配置物品。
3. 出售后余额增加且物品完成解锁。
4. 已解锁物品可以兑换，未解锁物品会被拦截。
5. 搜索和收藏不会绕过限制。
6. 自动补充只在余额足够、物品已配置时触发。
7. 重启后余额、解锁和收藏仍存在。
8. 群组服在另一子服重复验证共享数据。

## 菜单打不开

- 执行 `/plugins` 确认 LIEMC 已启用。
- 检查 Java、服务端版本和启动日志。
- 检查配置 YAML 是否解析失败。
- 确认玩家拥有 `liemc.use`。

## 物品不能出售或兑换

- 物品 ID 或材质没有配置。
- 自定义物品的模型、PDC 或匹配信息不同。
- 物品尚未解锁。
- 余额不足或背包已满。
- 外部经济提供者未正常加载。

## MySQL 不同步

- 确认子服连接同一个数据库。
- 检查账号权限、数据库名和网络端口。
- 确认使用命令上架或下架。
- 在其他子服执行 `/emc reload`。
- 查看控制台是否有连接池或 SQL 错误。

## 性能判断

先区分数据库连接失败、菜单操作错误和服务器整体卡顿。不要仅凭同一时间出现的警告就把全部延迟归因于 LIEMC；应结合时间戳、线程栈和可复现操作判断。
