# LIEMC 解锁、搜索、收藏与自动补充

## 解锁规则

默认配置为：

```yml
unlock:
  require-before-withdraw: true
```

玩家第一次出售某个物品后，才可以持续兑换该物品。这样能保留生存服的探索顺序，避免新玩家直接购买全部资源。

管理员可以使用 `/emc unlockall [玩家]` 为指定玩家或自己解锁全部商品。

## 搜索

执行：

```text
/emc search <关键词>
```

搜索结果仍遵守解锁和余额检查。找不到物品时，应尝试更短的名称，并确认该物品已经加入商店配置。

## 收藏

- 在商店中 Shift+点击商品可收藏或取消收藏。
- 收藏页用于集中展示常用资源。
- 收藏不会改变商品价格、解锁状态或购买限制。

## 自动补充

```text
/emc autorefill on
/emc autorefill off
```

开启后，当玩家手中配置过的物品消耗完时，插件会尝试扣除 EMC 并补充一组。适合建筑、空岛和需要连续放置方块的玩法。

不会触发的情况：

- 玩家处于创造模式。
- 物品没有 EMC 配置。
- 余额不足。
- 自动补充已经关闭。

## 服主建议

- 生存服建议保留先解锁后兑换。
- 建筑服可以降低常用方块价格，并引导玩家开启自动补充。
- 不要把稀有活动物品与普通量产资源设置成接近的价值。
- 修改大批商品前先备份配置和数据库。
