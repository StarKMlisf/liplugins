# LIEMC 配置说明

LIEMC 的业务规则与商品位于 `config.yml`，菜单标题、槽位、按钮和样式位于 `gui.yml`。菜单字段与实例详见[自定义 GUI 完整教程](./自定义GUI教程.md)。

## 存储

```yml
storage:
  type: "mysql"
  mysql:
    host: "127.0.0.1"
    port: 3306
    database: "liemc"
    username: "root"
    password: "change-me"
    use-ssl: false
    pool-size: 10
```

单服可使用 SQLite；MySQL 适合多子服共享。正式服不要沿用示例密码。

## 经济来源

```yml
currency:
  provider: "internal"
```

可选值为 `internal`、`vault`、`playerpoints`。选择外部提供者前，确认对应插件已正常加载。

## 解锁

出售权限折扣配置位于 `sell-pricing`，默认关闭，不影响原有经济。完整示例、倍率优先级和权限授权见[出售权限折扣与倍率](./出售权限倍率.md)。

```yml
unlock:
  require-before-withdraw: true
```

开启后，玩家必须先出售一次物品才能兑换。关闭会改变服务器资源成长节奏，修改前应先评估经济影响。

## 商品条目

```yml
- id: "grass_block"
  material: "GRASS_BLOCK"
  emc: 1
  unlock-cost: 0
  withdraw-amount: 64
```

自定义物品建议通过 `/emc addheld` 生成条目，以保留名称、Lore 和模型信息。商品 ID 应保持稳定，数据库与收藏记录都会依赖它。

## 全局商品 Lore

所有未单独填写非空 `lore` 的商品都会继承 `item-display.default-lore`。修改一次并执行 `/emc reload`，即可统一更新全部继承该模板的商品。

```yml
item-display:
  default-lore:
    - ""
    - "&7价格：&e{emc} 点 EMC"
    - "&7状态：&f{favorite}"
    - ""
    - '&a左键获取：&f{left_amount} 个\n&6右键获取：&f{right_amount} 个'
    - "&dShift+点击：&f{favorite_action}"
```

- `- ""` 或只含空格的列表项会保留为一行空白分隔，不再被过滤。
- 同一列表项中的 `\n` 会拆成多行；示例使用 YAML 单引号，确保反斜杠按原样交给插件。
- 可用变量包括 `{emc}`、`{left_amount}`、`{right_amount}`、`{withdraw_amount}`、`{favorite}`、`{favorite_action}` 与 `{craftengine_item}`。
- build.107 新增 `{sell_emc}`（当前玩家出售一个的报价）、`{sell_multiplier}`、`{sell_percent}`、`{sell_permission}`；`{emc}` 仍是购买原价。
- 单个商品的 `description-lore` 会显示在全局模板之前，并继续跟随全局模板更新。
- 单个商品配置任意非空 `lore` 时，会完整覆盖全局模板；`lore: []` 或省略该字段则继续继承。
- `default-lore: []` 表示所有继承项均不显示默认商品说明。

## PlaceholderAPI

安装 PlaceholderAPI 后可以在外部界面显示 LIEMC 数据。实际变量以插件当前注册列表和 `/papi parse` 测试结果为准。

## 修改流程

1. 备份配置。
2. 修改 YAML，保持空格缩进。
3. 执行 `/emc reload`。
4. 检查控制台错误。
5. 重新打开菜单验证价格、解锁和购买数量。
