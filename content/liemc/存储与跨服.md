# LIEMC 存储与跨服

## 共享范围

多服连接同一个 MySQL 时可以共享：

| 数据 | 是否共享 |
| --- | --- |
| EMC 余额 | 是 |
| 已解锁物品 | 是 |
| 收藏列表 | 是 |
| 自动补充开关 | 是 |
| 命令上架和下架记录 | 是 |
| 语言、菜单布局 | 否 |

## 上架同步流程

1. A 服使用 `/emc addheld example_block 100`。
2. A 服立即写入本地配置和数据库商店表。
3. B 服执行 `/emc reload` 或重启。
4. B 服拉取变更并显示同一商品。

下架时使用 `/emc removeitem <id>`，确保删除动作也写入跨服记录。

## 配置一致性

所有子服应保持一致：

- 插件版本。
- 商品 ID 与分类约定。
- 经济来源。
- 解锁规则。
- 菜单与语言文件。

手动改动只存在本地的文件不会自动变成完整的跨服配置发布系统。

## 数据库安全

- 使用单独数据库账号，只授予需要的表权限。
- 不要把密码提交到公开仓库或截图。
- 更新前备份数据库。
- 测试服使用独立数据库。
- 连接失败时先修复网络和权限，不要反复切换存储类型覆盖数据。

## 切服验证

在两个子服分别测试余额、解锁、收藏和上架同步。只有四项都符合预期，才能认为跨服部署完成。
