# 安装与自动恢复

## 环境

使用标准 Bukkit API，已在 Paper 26.1.2 build 53 / Java 25.0.4 验证；插件字节码为 Java 21，但服务器仍须使用满足核心要求的 Java。**不支持 Folia**，其他核心版本未在本次测试中验证。

无需 CraftEngine、Vault、PlaceholderAPI 或 PlayerIntensify 前置。MiniMessage 运行库首次启动自动下载，需要正常网络。

## 安装与升级

1. 先备份玩家物品与服务器数据，停服。
2. 移除 PlayerIntensify Jar，替换旧版 LiWeaponReset 为 1.0.3，不保留两个版本同时加载。
3. 自定义装备服如需人工核对，启动前在配置设置 `auto-restore-enabled: false`；首次安装可先在无人登录的测试服生成配置。
4. 启动检查 LiWeaponReset 加载日志，在测试环境执行 `wr validate`。
5. 确认回归材质原版数值符合需求后，再允许玩家使用。

升级保留已有配置值，仅补缺失项和中文注释。由旧版本升级且没有自动开关时，会补为默认 true。

## 自动检测条件

每 20 tick 在 Bukkit 主线程检查所有在线玩家主手，正常 TPS 下约 1 秒；服务器卡顿时可能更慢。无须玩家执行指令或持有管理权限。

- 主手只有一件物品，材质匹配 weapon-pattern。
- 存在 `playerintensify:handy_data_level` 标记。
- 没有本插件已处理事务标记或撤销后自动豁免标记。
- PlayerIntensify 当前未启用，自动恢复开关为 true。

不会扫描整个背包、箱子或副手。切槽、交换、拾取、其他插件写入主手，均在后续检测时检查实际主手物品。符合条件时先保存备份，再修改并提示；保存失败不写回，每位玩家 30 秒后重试。
