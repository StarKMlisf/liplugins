# 指令与备份撤销

主指令 `/weaponreset`，别名 `/wr`；支持 Tab 补全。所有子指令权限为 `liweaponreset.admin`，默认 OP。自动检测本身不需要权限。

| 指令 | 用途 |
|---|---|
| /wr inspect | 查看主手攻击属性及米饭标记 |
| /wr preview | 预览当前和回归后属性，不修改装备 |
| /wr confirm | 确认有效预览，先备份再修改 |
| /wr undo | 撤销一次匹配的回归记录 |
| /wr reload | 重载配置，取消旧预览 |
| /wr validate | 执行隔离物品自检 |

控制台可以重载、自检和查看帮助，不能执行玩家手持物品操作。

## 手动流程

先将自动恢复关闭并重载，避免预览前已被自动处理。主手拿一件武器，执行 inspect、preview，确认目标后在默认 60 秒内 confirm。切换快捷栏、物品变化、退出、重载或超时后须重新预览。

## 备份与撤销

每次自动或手动回归前，在 `plugins/LiWeaponReset/backups/` 写独立 UUID.yml，包含玩家 UUID、修改前后物品和撤销状态。

撤销必须由原玩家持有完全匹配的回归后物品执行。改名、磨损、附魔等变化会使精确匹配失败，原备份仍保留供管理员核对。普通玩家需管理员临时授予管理权限后自行撤销；把武器交给 OP 不能冒用原玩家备份。

记录只能消费一次，重建服务后仍可撤销，不能重复领取物品。撤销恢复业务数据，并增加持久化自动豁免标记：换手或重启后也不会再次自动恢复。需要重新回归时，用手动 preview 和 confirm 解除豁免。

不要删除 backups 后仍期待 undo 可用。磁盘备份和背包写回不是跨系统原子事务，异常断电仍需核对原始备份。
