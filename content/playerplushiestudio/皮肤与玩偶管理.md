# 皮肤与玩偶管理

## 自定义皮肤

在玩家详细配置中选择本地 64×64 PNG 皮肤，然后点击“自定义生成该玩家”。本地皮肤会持久用于该玩家，适合网络皮肤源不可用或需要指定外观的情况。

模型展示窗口支持拖动旋转、滚轮缩放与复位视角。预览与正式生成共用 classic/slim 手臂 UV 配置，支持头部第二层开关。手持物预览用于示意位置，最终效果仍需在游戏中核对。

## 手持物

- 物品 ID 可以填写 `minecraft:paper` 或 CraftEngine 自定义 ID，例如 `custom:magic_wand`。
- 原版物品简写会自动补全 `minecraft:`。
- 可设置左右手、XYZ 偏移、XYZ 旋转、大小、展示模式和数量。
- XYZ 是相对手掌偏移，保持 `0 / 0 / 0` 可使用自动贴合手掌的位置。
- 不需要手持物时，可以使用列表中的批量关闭手持物功能。

## 只更新一名玩家

选择目标玩家并使用指定玩家生成或更新功能。工坊保留其他玩家已经生成的玩偶，适合只替换某名玩家的皮肤或调整手持物。

## 移除一个玩偶

选择玩家后点击“移除该玩偶”，或使用左侧“移除指定玩偶”。操作会删除该玩家的 CE 物品、分类条目、模型、贴图与玩家配置，保留其他玩家和皮肤缓存。

工坊会在服务器根目录的 player_plushie_backups 中创建恢复备份，并把移除的玩家记入 excluded_players.txt。后续扫描不会自动重建；手动新增并保存同名玩家可恢复生成资格。完成后执行 `/ce reload all`。
