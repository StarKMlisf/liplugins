# 玩家玩偶工坊

玩家玩偶工坊 1.6.0 是 Windows 图形化 CraftEngine 玩家玩偶生成工具，内置生成核心 2.4.6。选择服务器目录后，可以识别玩家、获取或导入皮肤，生成对应的玩偶物品、模型与贴图。

## 可以做什么

- 扫描 usercache.json、whitelist.json 和 ops.json，区分已生成、新玩家与待修复模型。
- 识别并生成新玩家，或只更新指定玩家，保留其他玩家玩偶。
- 导入本地 64×64 PNG 皮肤，预览模型并旋转、缩放视角。
- 编辑左右手、原版或 CraftEngine 手持物、相对手掌偏移、旋转、大小和展示模式。
- 自定义 MiniMessage 名称与 Lore，管理皮肤来源、代理与缓存。
- 移除单个玩偶并自动备份，避免后续扫描自动重建。
- 批量任务显示部分完成与失败原因，通过 RUN_RESULT.json 记录结果。

工坊在 Windows 上运行，生成内容由服务器中的 CraftEngine 加载。Minecraft、Paper 或 Folia 的实际适配范围取决于所安装的 CraftEngine 版本与生成内容；本页不代表所有服务端版本和游戏内视觉均已验证。
