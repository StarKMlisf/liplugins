# 快速开始

## 准备

使用 Windows x64，并准备已安装 CraftEngine 的 Minecraft 服务器目录。工坊需要能访问服务器文件；选择包含 plugins 文件夹的服务器根目录。

## 生成第一批玩偶

1. 双击玩家玩偶工坊 EXE。Windows Server 或单文件版无法启动时，完整解压 x64 兼容版，再运行其中的 EXE。
2. 在工坊主页选择服务器根目录。
3. 点击“一键识别玩家状态”，查看已生成、新玩家与待修复旧模型。
4. 按需编辑玩家皮肤、手持物及名称。
5. 点击“识别并生成新玩家”。需要重建所有玩家时使用“生成全部玩家”。
6. 查看生成日志与失败玩家提示，确认任务是否全部完成。
7. 在服务器执行 `/ce reload all`，并按服务器现有 CraftEngine 流程让客户端使用更新后的资源包。

## 首次部署与升级

首次载入服务器目录会部署生成核心，并保留已有 config.txt、players.txt 和 tools/lore_template.yml。升级前保留服务器内容与配置备份。

旧版手持物绝对坐标会迁移为相对手掌偏移：旧默认值归零，自定义位置保持原有实际落点。升级时还会一次性恢复头部第二层默认值，请核对预览是否符合需要。
