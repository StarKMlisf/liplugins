# 兼容与排错

## Windows 环境

项目声明面向 Windows 10 22H2、Windows 11 和 Windows Server 2022 21H2 的 x64 环境。32 位 Windows 无法运行。不需要另装 Python 或 VC++ 运行库。

遇到“此应用无法在你的电脑上运行”或单文件版无法启动时，使用 x64 兼容版，完整解压后运行。兼容版必须保留整个文件夹；不要只复制 EXE，也不要在压缩软件或聊天软件内直接运行。文件属性中若有“解除锁定”，应用后重试。

## 玩家皮肤失败

批量任务允许部分完成：成功玩家正常生成，失败玩家在列表中显示原因。先检查日志和 RUN_RESULT.json，再检查网络、代理、皮肤来源或改用本地 64×64 PNG。

第三方皮肤源返回 403、521 等主机级错误时会自动熔断，避免后续玩家重复等待。LittleSkin 名称查询未命中会继续尝试 usercache UUID；离线 UUID 不会直接当作已验证的 Mojang UUID 使用。

## 模型或手臂异常

点击“一键识别玩家状态”，把待修复旧模型加入生成队列。旧错误手臂 UV 模型可被识别，即使玩家已不在服务器缓存中，仍能从现有输出恢复到列表。

生成后检查 CraftEngine 加载日志，执行 `/ce reload all`，确认客户端使用了更新后的资源包。预览正常不等于客户端已载入最新模型。

## 服务器兼容范围

工坊属于 Windows 工具，不作为 Bukkit 插件放进 plugins 文件夹。生成内容需要由 CraftEngine 加载，服务端 Java 要求由对应核心与 CraftEngine 决定。当前导航整理依据项目 1.6.0 说明，未新增 Paper/Folia 实服或 Minecraft 客户端测试。
