# LiEnhance 1.3.0 装备强化

LiEnhance 是强制依赖 CraftEngine 的装备强化插件，不是独立的 LiWeaponReset 武器回归工具。

## 功能

- 武器、防具、盾牌和工具强化，实际属性与强化预览统一计算。
- 单属性强化书、掉级与销毁保护券，失败规则可配置。
- 强化概率药水：默认饮用后 600 秒增加 10 个百分点。
- 指定方块献祭台：Y/N 确认、按等级判定成功率与奖励、公屏公告、雷击武器消失。
- 渐变 Lore、符号/文字/CE 图片名称后缀、1～1000 级徽章。
- 成功强化上升粒子、脚下魂环、文字分类属性图鉴。
- 最高等级配置支持 1～10000，`applylevel` 按指定数量追加等级。

**献祭确认后，成功或失败都会永久消耗武器；只有成功获得概率奖励。**

## 运行与验证

强制前置 CraftEngine 26.8.1 或更高兼容版本，必须开启 CE 属性系统。金币消耗可选 Vault 与经济插件，变量扩展可选 PlaceholderAPI。

1.3.0 完成 1697 项自测、无 Vault 测试、Jar 依赖检查、Paper 26.1.2 隔离流程测试和 Folia 26.2 启动/CE 联动检查。测试环境 Java 25；并非对所有新版本核心的承诺。

真实客户端视觉、多区域 Folia 玩家操作及自定义 CE 图片仍需服主验收。本站只提供介绍与文档，不提供插件 Jar、源代码或资源包下载。
