# 配置、指令与升级

## 常用指令

| 指令 | 用途 | 权限 |
| --- | --- | --- |
| `/enhance givepotion 玩家 [数量]` | 发放 1～36 瓶药水，默认 1 | `lienhance.admin.givepotion` |
| `/enhance altar add` | 注册准星 5 格内方块 | `lienhance.admin.altar` |
| `/enhance altar remove` | 移除准星方块的注册 | `lienhance.admin.altar` |
| `/enhance buff` | 查询临时加成 | `lienhance.use` |
| `/enhance guide [档案ID]` | 文字属性图鉴 | `lienhance.use` |
| `/enhance setlevel 玩家 等级` | 设置主手装备绝对等级 | `lienhance.admin.setlevel` |
| `/enhance applylevel 玩家 增加级数` | 当前等级增加正整数级，超上限整次拒绝 | `lienhance.admin.applylevel` |
| `/enhance reload` | 重载配置 | `lienhance.admin.reload` |

饮用权限 `lienhance.potion.use`、献祭权限 `lienhance.sacrifice` 默认所有玩家拥有；管理权限默认 OP，并包含在 `lienhance.admin.*`。指令带参数补全。

献祭台按精确坐标存于 `altars.yml`，不是所有相同材质方块都能献祭。支持原版或 CE 实体方块，不包含展示实体家具。默认不注册任何献祭台，也不自动发放药水。

## rituals.yml

```yaml
potion:
  # 是否允许饮用，true/false。
  enabled: true
  # 0~1，0.10 为增加 10 个百分点。
  bonus: 0.10
  # 整数 1~86400 秒。
  duration-seconds: 600
sacrifice:
  # 是否允许献祭，true/false。
  enabled: true
  # 确认时限与奖励期限，整数 1~86400 秒。
  confirm-seconds: 30
  duration-seconds: 600
  # 是否广播结果，true/false。
  broadcast: true
  # 允许献祭的装备档案 ID。
  weapon-profiles: [weapon, spear, trident, mace, ranged]
  # 按不超过武器等级的最高门槛取规则；概率范围均为 0~1。
  tiers:
    1: {success: 0.50, bonus: 0.01}
    10: {success: 0.60, bonus: 0.03}
    50: {success: 0.70, bonus: 0.05}
    100: {success: 0.80, bonus: 0.10}
    500: {success: 0.90, bonus: 0.15}
    1000: {success: 0.95, bonus: 0.20}
success-particles:
  # 是否播放强化成功上升粒子，true/false。
  enabled: true
name-suffix:
  # 支持 MiniMessage、文字与符号；level 为等级，badge 为默认徽章。
  template: ' <gold>✦ +<level> ✦</gold> <badge>'
  # 可填 CE 位图图片 ID；支持 {level}，空字符串禁用。
  ce-image: ''
```

使用自定义 CE 图片时，在模板中加入 `<ce_image>`，将 `ce-image` 设置为如 `my_pack:badge_{level}`。它是**CE 位图图片 ID，不是物品 ID**，取第一行第一格；不存在时回退默认等级图标。`<badge>` 使用已有等级字体设置。

`messages.yml` 管理提示、公告与 Lore；仅旧默认 Lore 自动升级，管理员自定义内容保留。首次升级备份为 `messages-before-1.3.0.yml`，不会覆盖物品原有 Lore。

## 等级突破与升级

`config.yml` 的 `system.max-level` 支持 1～10000，默认仍为 100。`system.breakthrough.auto-extend: true` 自动补齐 101 级起缺失的强化规则；`attribute-growth: hold` 保持属性末值，`last-step` 按最后两项非负差值继续成长。显式配置优先，CE 自身属性上限仍有效。

徽章资源覆盖 1～1000，超过 1000 使用数字后缀。升级 Jar 必须完整停服替换并启动；`/enhance reload` 不能替换已加载的 Java 代码。1.3.0 不要求更换已有 1.2.8 资源包；从更早版本升级千级徽章时，需要 `/ce reload pack` 并让玩家接受新版资源包。
