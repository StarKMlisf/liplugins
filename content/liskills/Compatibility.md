# Paper、Folia、Shiroha 与插件联动

LiSkills **1.13.0** 保留 Paper 26.1.2 / Java 25 基准，并新增 Folia 26.2 的实体与区域调度适配。业务使用 Bukkit API，服务端特定调度和临时属性通过独立兼容层接入。

Shiroha 26.2 以提供相同公开调度和归属接口为兼容目标。当前未取得用户所用的同一构建 Jar，不能仅凭版本名或 Folia 检查宣称该 Shiroha 构建已实测。部署时应使用实际构建，在复制的世界与配置中验收。

## Folia 行为边界

| 场景 | 处理方式 |
| --- | --- |
| HUD、魔力、属性、主动窗口 | 跟随玩家实体任务，不由全局任务直接操作所有玩家 |
| 投射物和持续效果 | 使用事件归属与目标任务；远端射手信息使用快照 |
| 伐木、地形开拓、补种 | 在所属玩家或方块区域执行；未拥有区域不读状态、不强加载、不跨区破坏 |
| 范围被动 | 只读取当前线程实际拥有的目标；不安全的附加效果会跳过 |
| 近期技能经验 HUD | 按玩家独立合并和到期，不被其他区域消费；卡顿区域仍需等待自身恢复 |
| 离线、移除与关闭 | 取消自有任务；退休回调只清理缓存，不操作世界 |

这意味着跨区域扩散可能提前结束，需要双方实时状态的额外战斗效果可能跳过。原生伤害和服务器基础行为仍由服务端处理，不会把全部技能整体关闭。

Folia 路径使用公开临时属性接口，避免本次成长加成持久写入玩家 NBT。缺少必需接口时中文提示并安全停止，不回退为可能残留的永久加成。旧版崩溃留下的离线数据仍需单独处理，见[安全卸载](HUD-Uninstall.md)。

## 可选联动

| 插件 | LiSkills 的接入范围 |
| --- | --- |
| LiRealEnchant2 | 通过公开预检、成功及二次伤害接口去重；同一工具避让重复连锁、补种和二次增伤 |
| CustomCrops | 成熟收获、真实产出与状态变化确认后奖励一次农耕经验 |
| CustomFishing | 最终成功结果奖励一次经验，排除附带原版事件；自定义鱼获不复制 |
| PlaceholderAPI | 读取已加载技能、魔力、属性和被动快照 |
| Vault + 经济实现 | 可选职业收入与奖励付款 |

现有桥接以 LiRealEnchant dev201、CustomCrops 3.6.54、CustomFishing 2.3.26 的公开入口为实现参考。这个版本列表不等于上述插件所有 Folia 构建和组合均已验收；外部插件本身也必须支持所在核心。

关闭自定义内容经验桥接后，仍保留必要的受管方块/鱼钩避让。第三方 API 失配时安全停止对应桥接并提示，不争夺其产物或计时器。商业插件不随 LiSkills 分发。

CustomFishing 旧快速咬钩效果在正常会话结束时按所属玩家撤回；若 Folia 停用阶段区域任务已停止，当前鱼钩的临时倍率可能持续到该次抛竿结束，不写入角色永久数据。

## 部署前验收

在复制的测试服检查启动、菜单、HUD 开关与重连、自然采集、防刷、主动能力、权限和禁用世界。再逐项加入领地、附魔、作物、钓鱼和经济插件，记录具体操作和完整异常。

不要修改线程检查或仅更改 `folia-supported` 声明强行通过加载。发生归属错误时，提供核心完整版本、实际 LiSkills Jar 版本、相关依赖和异常位置。

本版未声明基岩专项适配，未把自动化检查当真人 HUD 视觉，也未宣称长期多人负载、所有保护组合、全部数据库与商业依赖都已在本轮复测。当前页面说明实现与边界，不复制旧版测试数字。
