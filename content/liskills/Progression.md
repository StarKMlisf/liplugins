# 成长、被动、属性与主动能力

技能从 1 级开始。默认从升到 2 级开始得到成长属性，五项被动在 2 至 6 级依次解锁，之后每 5 个技能等级提升一阶。具体解锁、数值、间隔和上限可由管理员修改。

旧高等级玩家会按保留的等级立即计算当前被动和属性。升级没有清档，不等于服务器战斗强度完全不变；正式启用前应核对平衡配置。

## 九项属性

| 属性 ID | 中文含义 |
| --- | --- |
| `strength` | 力量，转换为伤害增幅 |
| `health` | 生命，增加最大生命 |
| `regeneration` | 再生，影响回血和魔力恢复 |
| `luck` | 幸运，影响各类采集幸运 |
| `wisdom` | 智慧，影响原版经验、魔力上限与铁砧费用 |
| `toughness` | 韧性，按递减收益公式减伤 |
| `crit_chance` | 技能暴击几率 |
| `crit_damage` | 技能暴击伤害 |
| `speed` | 移动速度 |

`stats.yml` 定义属性与实际效果换算，`balance.yml` 再限制生存服的有效强度。升级生命不会自动补满当前血量；技能暴击与原版跳跃暴击是独立机制。

## 主动能力怎么触发

八项工具与战斗主动为丰收补种、连锁伐木、快速挖掘、锐钩、地形开拓、逐箭蓄力射击、伤害吸收与闪电之刃。另保留敏捷、炼金、附魔的三项药水主动，以及已有配置中的旧主动类型。

通常可使用菜单、`/lsk cast <技能ID>` 或对应工具潜行右键。锐钩需要真实挂钩目标；逐箭蓄力可左键弓切换状态；伤害吸收默认左键盾准备，再由下一次有效受击启动。具体动作以服务器配置为准。

需要同时满足技能启用、等级、工具、权限、世界、模式、魔力及冷却条件。补种和连锁破坏仍接受原生保护检查，并受数量与处理预算限制；Folia 不会为继续扩散而读取未拥有的区域。

## 默认生存强度

`balance.yml` 默认开启。常规持续主动最长 20 秒、冷却至少 120 秒、最高 10 阶；瞬发和开关能力不套用持续窗口显示。生命成长默认最多增加 10 点生命，即 5 颗心；第三方独立属性仍然保留。

闪电之刃默认只增加攻速，最多 50%；逐箭伤害增幅最多 25%；锐钩最多 5 点基础伤害，默认不攻击玩家。改变某一个原始配置值后，最终结果仍可能受平衡上限约束。
