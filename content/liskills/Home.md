# LiSkills 使用文档

本导航只提供插件介绍与使用说明，不提供 LiSkills Jar、安装包或源码下载。

LiSkills **1.13.0** 是面向 Paper 26.1.2 / Java 25 的中文技能插件，本版新增 Folia 26.2 区域线程适配。日常挖矿、种植、战斗、钓鱼与制作都能积累独立技能经验，解锁被动、成长属性和主动能力。

内置 **15 职业技能、70 项被动、9 项属性、19 种特性**，并提供生命、魔力与近期技能经验 HUD。无需资源包，也不要求安装其他 HUD 插件。Shiroha 26.2 以相同公开接口为兼容目标，尚未取得用户所用的同一构建进行验证，详见[兼容性说明](Compatibility.md)。

## 玩家从这里开始

1. 输入 `/lsk` 打开技能总览，点击技能查看进度、能力和经验来源。
2. 输入 `/lsk abilities mining` 查看挖矿能力，`/lsk attributes` 查看角色属性。
3. 使用对应工具的潜行右键、菜单按钮或 `/lsk cast mining` 施放已解锁主动；魔力、冷却及实际触发条件仍然生效。
4. 输入 `/lsk hud` 切换个人 HUD。生命数字以生命点计，2 点等于一颗心。

默认可以自由练习全部技能。这里的“职业技能”是独立成长分类；选职赚钱是另外一个可选模块，默认关闭，不选职业不会默认阻止成长。

## 管理员先确认的边界

升级只补缺失配置及必要注释，保留管理员已有值。默认配置示例用于对照，不能直接覆盖正式服配置。全部配置验证通过后才发布新快照；更换 Jar、存储后端或卸载需要完整停服。

删除 Jar 前请先备份并正常停服。LiSkills 只清理自己的成长属性，保留基础血量和其他插件的加成；崩溃后尚未再次上线的历史玩家可能残留旧版属性，不能保证删掉插件后自动修复所有离线存档。

自动化检查、协议玩家和服务端探针不能代替真人客户端视觉、长期多人负载与本服全部插件组合的验收。本 Wiki 不沿用旧版测试数字作为当前版本证明。
