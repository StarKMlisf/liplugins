# 配置文件与平衡

配置位于 `plugins/LiSkills/`。所有默认 YAML 带中文注释，说明用途和取值范围。修改后先执行 `/lsk validate`，再执行 `/lsk reload`；全部配置成功解析和验证后才发布新快照，任何错误都保留上一份有效运行配置。

## 文件索引

| 文件 | 主要内容 |
| --- | --- |
| `config.yml` | 总倍率、世界、魔力、HUD、采集队列、反馈、联动 |
| `skills.yml` | 15 技能及自定义技能、等级、基础曲线、材质与生物经验 |
| `abilities.yml` | 被动解锁、数值、阶级与主动成长 |
| `stats.yml` | 九属性、成长映射、19 种特性换算 |
| `balance.yml` | 有效数值倍率、属性与能力上限 |
| `mana_abilities.yml` | 八项主动的专有行为及安全限制 |
| `sources.yml` | 采集、移动、鱼获、炼金、交易与来源归属 |
| `xp_requirements.yml` | 可选公式及逐等级需求覆盖 |
| `loot.yml` | 钓鱼与挖掘的稀有、史诗宝藏池 |
| `items.yml` | 装备匹配、槽位、加成、经验与技能门槛 |
| `jobs.yml` | 可选职业选择与 Vault 收入 |
| `rewards.yml` | 自定义升级物品、金币与控制台命令奖励 |
| `leaderboards.yml` | 缓存刷新、榜单容量与分页 |
| `storage.yml` | YAML、SQLite、MySQL 及关闭等待时间 |
| `messages.yml` | MiniMessage 提示和 HUD 文本 |
| `menu.yml` | 菜单布局、图标、名称、说明及音效 |

不要用默认配置示例覆盖现有配置。升级会补缺失节点及注释；需要停用内置项时使用其开关或有效的零值，直接删掉默认节点可能在下次加载时被补回。

## 怎样调整经验

原版矿物基础经验在 `skills.yml -> skills.mining.blocks`。例如修改现有 `DIAMOND_ORE` 和 `DEEPSLATE_DIAMOND_ORE` 数值，0 表示禁用该材质来源。人工放置与最终破坏验证独立存在，提高经验不能绕过防刷。

全局自然经验倍率位于 `config.yml -> xp-multiplier`，有效范围 0–100，0 暂停自然经验。特殊来源单位和间隔在 `sources.yml`，不要误把原版经验珠当成技能经验。

自定义作物和渔获按 ID 的经验映射位于 `config.yml -> compatibility.customcrops.crop-xp` 与 `compatibility.customfishing.loot-xp`。默认经验设为 0 可只允许显式列出的 ID。

## 怎样调整强度

`balance.yml` 在原始技能、被动、属性配置之上计算有效值，不会重写管理员输入。菜单显示有效结果。主动持续时间、冷却、阶级、生命、暴击和采集幸运可能受这里的上限约束。

默认生命成长最多增加 5 颗心，常规主动最长 20 秒、冷却至少 120 秒、最高 10 阶。已有第三方独立修饰符仍然保留，不能把该上限理解为玩家的全部血量上限。

## 自定义经验曲线

`xp_requirements.yml` 默认关闭，保留现有 `base-xp/growth-xp` 节奏。开启后使用只接受数字、变量、括号、四则运算和幂的表达式，不执行脚本。`level` 是目标等级。

~~~yaml
# 是否启用本文件曲线；true/false。开启前备份当前技能档案。
enabled: true
# 未单独配置的技能使用的完整默认曲线。
default:
  # 允许level/base/multiplier、数字、括号和+ - * / ^；level是目标等级。
  expression: 'multiplier * (level - 2) ^ 2 + base'
  # 起始经验参数；0～1000000000，最终升级需求必须大于0。
  base: 100.0
  # 增长倍率；0～1000000000。
  multiplier: 100.0
  # 精确目标等级需求；覆盖表达式，目标等级2～1000。
  levels:
    # 升到10级需要的经验；1～1000000000000。
    '10': 10000
# 每技能的完整覆盖；空映射使用上方默认配置。
skills: {}
~~~

更改曲线不清空等级和经验，但会影响下一次经验入账时的跨级结果。先备份，再在测试服核对低、中、高等级。

## 自定义技能和菜单

复制一份完整技能定义，使用唯一的小写 ID，补齐名称、图标、等级、经验、主动及来源字段；总技能数最多 64。菜单、权限和命令补全会跟随配置更新。缺字段时拒绝整次重载，不发布半个技能。

自定义方块来源仍走人工标记与最终取消检查，不自动继承农耕成熟作物例外。自定义生物来源也需真实死亡和合法生成来源。

界面文本统一使用 MiniMessage，如 `<gradient:#63e6be:#74c0fc>技能面板</gradient>`。HUD 标题颜色与 BossBar 条本身的原生颜色分开设置，详见[HUD 与安全卸载](HUD-Uninstall.md)。

## 必须停服的变更

更换 Jar、存储类型、连接或数据库文件名需要完整重启。重载时修改这些存储项会拒绝整次更新。配置版本变化会废弃等待中的旧采集、交易与施法凭据，避免把旧规则下的事件按新规则结算。
