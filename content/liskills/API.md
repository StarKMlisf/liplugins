# 开发者 API

LiSkills 提供自己的 Bukkit 服务接口 `LiSkillsApi`，其他插件通过 `Bukkit.getServicesManager()` 获取服务。没有注册服务时应停止对应功能，不假设插件必定存在。

API 涵盖技能定义与玩家进度、自然经验、管理经验和等级、属性与特性、魔力、主动状态及施放。具体接口签名以同版源码与开发包为准。

## 线程和生命周期

Paper 的写入与施法在游戏线程执行；Folia 必须在目标玩家所属实体线程执行。`getStats`、`getTraits`、`getMana`、`getAbility` 虽然是查询，也要求目标玩家在线、档案已加载且当前线程拥有该玩家；不能把它们当作任意异步线程可调用的快照接口。

`getSkills` 和 `getProgress` 可跨线程读取同步快照。其他接口在归属或档案条件不满足时返回 `false`、空映射或 `null`，不会自动替调用方排队。全局线程不是可以操作所有玩家的通行证，不能通过读取位置后随意排到附近方块线程来代替实体调度。

只读外部显示优先使用已发布快照。玩家离线、档案未加载或插件正在关闭时，应结束本次操作，不创建空档案替代真实数据。

自然经验先发布可取消的 `SkillExperiencePreGainEvent`，成功入账后发布只读 Gain 通知。同技能重入有防重保护；事件监听器不应在回调中不断给同技能追加经验。

## 自然经验和管理经验

自然经验入口应用倍率、能力、门槛、可取消预事件与奖励规则；调用方负责证明来源真实成功，API 不会替外部插件重新验证矿物、作物或交易。管理经验用于管理员或明确的管理操作，不按自然来源放大，也不生成职业收入。不要为了方便把后台修复伪装成自然采集。

经验事件不是物品掉落许可。需要发放矿物、作物或交易奖励时，应在你的插件确认最终事件与真实结果后调用，不能以取消前事件制造奖励。

## 构建与依赖

项目以 Java 25、标准 Bukkit/Paper 26.1.2 API 编译，外部 API 依赖统一放在 `lib/`，不合并进成品 Jar。Folia 调度和临时属性接口在独立兼容层中处理；服务器缺少必需能力时安全停止。

此接口不是其他技能插件的二进制替代层。既有扩展需要按 LiSkills API 重新接入，不能仅替换插件 Jar 就认定兼容。
