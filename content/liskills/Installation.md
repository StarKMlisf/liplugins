# 安装与升级

本文对应 LiSkills **1.13.0**，说明如何安装你已取得的插件 Jar。本导航不分发插件、安装包或源码；下列步骤不代表本站提供这些文件。

## 运行环境

| 项目 | 要求 |
| --- | --- |
| 普通服务端基准 | Paper 26.1.2 |
| 区域线程适配 | Folia 26.2，详见[兼容性说明](Compatibility.md) |
| Java | Java 25 |
| 资源包 | 不需要 |
| 必装前置插件 | 无 |
| 可选联动 | PlaceholderAPI、Vault 与经济实现、LiRealEnchant2、CustomCrops、CustomFishing |

Shiroha 26.2 的公开调度接口是适配目标，但同名版本不代表同一构建；目前不能把 Folia 验证替代为用户使用的 Shiroha 构建实测。外部插件也必须兼容所用服务端。

## 首次安装

1. 使用控制台 `stop` 正常停服，等待进程结束。
2. 将 `LiSkills-1.13.0.jar` 放入服务端的 `plugins/`，确保只存在一个 LiSkills Jar。
3. 用 Java 25 正常启动。首次运行会生成 `plugins/LiSkills/` 及中文配置。
4. 检查控制台是否显示插件启用成功，执行 `/lsk validate` 检查配置。
5. 玩家输入 `/lsk` 打开菜单，`/lsk hud on` 开启状态条；在测试区域验证一次自然采集和主动能力。
6. 审核 `balance.yml`、`jobs.yml`、`items.yml` 与 `rewards.yml` 后，再决定是否开放装备规则和经济奖励。

不要同时启用另一套会接管相同技能成长的旧插件。别名发生冲突时使用完整 `/liskills`。

## 从旧 LiSkills 升级

停服前备份整个插件目录、技能数据库或玩家文件，以及世界原生玩家数据。Paper 26.1.2 常用 `world/players/data/`，旧版本常用 `world/playerdata/`；以实际主世界目录为准。使用 SQL 时同时备份数据库。

停服后移走旧 Jar，只保留新版本。已有等级和经验不会因升级被清空；新增技能有独立进度，不会把原有敏捷、炼金或附魔经验自动拆分。旧版没有导入成功的技能，需要保留源备份重新核对，见[离线迁移](Migration.md)。

配置升级只补缺失节点及必要注释。只有完整匹配历史默认的模板才进行定向调整，自定义值、附加字段和注释保留；旧菜单只利用空闲位置补充技能，不覆盖管理员布局。默认文件只供对照。

升级完成后执行 `/lsk validate`，再检查总览中的 15 项技能、HUD、属性、实际采集及本服联动。

## 依赖下载

公共库不合并进插件 Jar。优先复用服务端提供的 Adventure/MiniMessage；缺失库由插件按固定版本下载并校验 SHA-256。SQL 驱动也按所选后端下载到 `plugins/LiSkills/lib/`，YAML 模式不下载 SQL 驱动。

缺库、下载失败或校验不符会给出中文说明并安全停止，不降级为新建空档案。插件不会擅自下载 Vault、PlaceholderAPI 或商业插件。网络受限时保留启动日志，在允许访问固定依赖源后重试。

## 哪些操作需要重启

普通文本、技能、HUD、数值配置可使用 `/lsk reload`。存储类型、连接信息和文件名变化需要完整停服，重载会拒绝这类变更。替换 Jar、卸载及恢复备份也必须停服。

不要使用服务器 `/reload` 或插件管理器热卸载。需要删除插件时按 [HUD 与安全卸载](HUD-Uninstall.md) 操作。
