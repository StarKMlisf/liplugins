# 🎨 LiSkin 1.9.6｜CraftEngine 3D 武器、时装与 NPC 试衣间

LiSkin 是一款基于 CraftEngine 的现代物品换肤插件，为服务器提供武器、工具、帽子、背包、羽翼等 3D 外观，并配有完整的皮肤商店、试穿、收藏、权限保护和跨服同步功能。

插件只修改物品的外观组件，不会替换原物品，也不会改变原物品的品质、属性、附魔、耐久和其他插件数据。

> 钻石剑应用皮肤后，移除皮肤依然是钻石剑，不会错误还原成铁剑。

## 🖥️ 综合皮肤菜单

玩家输入：

```text
/liskin
```

即可打开完整皮肤面板。

菜单内可以直接完成：

- 自动匹配当前主手物品
- 查看全部皮肤
- 查看已经拥有的皮肤
- 查看收藏皮肤
- 购买或免费解锁皮肤
- 应用皮肤
- 临时试穿
- 解锁手中的 CE 皮肤物品
- 移除当前皮肤
- 结束试穿
- 翻页与刷新匹配

操作方式：

```text
左键：购买或应用
右键：临时试穿
Shift + 点击：收藏或取消收藏
```

没有权限的皮肤不会被隐藏，而是以锁定状态显示，方便玩家知道服务器提供了哪些外观。

## 👁️ 试穿模式

玩家可以在购买前临时试穿皮肤。

```text
右键皮肤图标
/liskin preview <皮肤ID>
/liskin preview stop
```

试穿具有完整恢复保护：

- 时间结束自动恢复
- 主手物品发生变化自动恢复
- 移动物品自动恢复
- 玩家死亡或退出自动恢复
- 插件关闭自动恢复
- 不会解锁皮肤
- 不会扣除金币或点券

试穿时间和是否允许试穿未解锁皮肤均可在配置中调整。

## 🧍 常驻人偶试衣间

管理员使用 `/liskin fitting set a` 设置展示点，使用 `/liskin fitting set b` 设置观看点。A 点会生成常驻原生玩家人偶 NPC；玩家蹲下并用主手右键后，可从独立菜单一次浏览全部皮肤，不必逐个输入 ID。

选择服装后，玩家会在 B 点观看一个套用自身玩家皮肤、持续旋转的个人可见人偶。武器进入主手，装备进入对应槽位，背包和羽翼等展示模型同步跟随。试衣不购买、不解锁、不修改玩家物品，结束后会清理人偶并按配置返回原位置。

观看过程中再次蹲下并用主手右键任意位置，就能重新打开全部服装菜单并连续换装，不需要再次输入指令。

## 🔐 安全的物品还原

LiSkin 不会把原物品直接替换成皮肤来源物品。

插件只保存和修改必要的视觉组件：

- CustomModelData
- Item Model
- Equippable 外观
- LiSkin 自有 PDC 标记

不会修改：

- 原物品 Material
- 武器或装备品质
- 属性与伤害
- 附魔
- 耐久度
- 其他插件写入的 NBT/PDC

当玩家移除皮肤，或者无权限玩家拿到皮肤物品时，插件会恢复该物品应用皮肤前的真实外观。

## 💰 Vault 与 PlayerPoints

全服使用 PlayerPoints：

```yml
economy:
  default-provider: "PLAYERPOINTS"

  playerpoints:
    display-name: "点券"
```

单独指定某个皮肤使用点券：

```yml
skins:
  example_skin:
    currency: "PLAYERPOINTS"
    price: 500
```

支持的货币类型：

```text
DEFAULT
VAULT
PLAYERPOINTS
```

购买成功后菜单不会关闭，皮肤会立即变成“已拥有”状态。

## 🌐 跨服防刷保护

群组服可以让所有子服连接同一个 MySQL 数据库：

```yml
storage:
  type: "MYSQL"
  server-id: "survival-1"
  cache-refresh-seconds: 3
  purchase-lock-seconds: 30
```

跨服模式支持：

- 解锁数据同步
- 收藏数据同步
- 在线缓存自动刷新
- 购买事务锁
- 手持物品解锁事务锁
- 重复扣款保护
- 数据库提交失败自动退款
- 物品消耗失败自动返还
- 数据库不可用时阻止使用旧缓存绕过权限

每台子服必须配置不同的 `server-id`。

| `/liskin fitting stop` | 结束人偶试衣并返回 |
| `/liskin fitting set <a\|b>` | 管理员设置展示点和观看点 |

## 🔑 主要权限

```text
liskin.user
# 默认玩家权限组，包含菜单、解锁、应用、试穿、移除、商店和全部基础分类权限

liskin.use
# 允许使用 /liskin 主命令

liskin.menu
# 允许打开 LiSkin 综合皮肤菜单

liskin.unlock
# 允许使用手中的 CraftEngine 皮肤物品解锁对应皮肤

liskin.apply
# 允许把已经解锁的皮肤应用到兼容物品

liskin.preview
# 允许使用命令或菜单右键临时试穿皮肤

liskin.fitting
# 允许打开试衣菜单并观看旋转玩家人偶

liskin.admin.fitting
# 允许设置试衣间 A/B 点

liskin.remove
# 允许移除当前皮肤并恢复物品原始外观

liskin.shop
# 允许打开全部皮肤和商店视图

liskin.shop.buy
# 允许使用 Vault 金币或 PlayerPoints 点券购买皮肤

liskin.skin.use
# 允许持有并显示已经应用皮肤的物品；缺少时会自动还原外观

liskin.category.<分类>
# 允许使用指定分类的皮肤，例如 liskin.category.sword 或 liskin.category.helmet

liskin.admin.reload
# 允许使用 /liskin reload 重载插件配置

liskin.admin.unlock
# 允许管理员为指定玩家解锁皮肤

liskin.admin.lock
# 允许管理员移除指定玩家已经解锁的皮肤

liskin.admin.debug
# 允许使用 /liskin debug hand 查看主手物品的皮肤和组件信息
```

每个皮肤还可以在 `skins.yml` 中设置独立权限：

```yml
permission: "liskin.skin.example"
```

可配合 LuckPerms 管理玩家权限。

## 📥 安装方法

1. 安装 CraftEngine。
2. 将 `LiSkin-1.9.6.jar` 放入服务器 `plugins`。
3. 将完整的 `skins` 文件夹放入：

```text
plugins/CraftEngine/resources/skins
```

4. 完整重启服务器。
5. 玩家输入 `/liskin` 打开菜单。

如果以前安装过分开的旧资源目录，请先删除旧目录，避免 CraftEngine 重复注册同一物品。
