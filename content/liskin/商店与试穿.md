# 商店、试穿与试衣间

## 购买皮肤

使用 `/liskin` 或 `/liskin shop` 打开全部皮肤。购买成功后菜单不会关闭，条目会立即刷新为已拥有状态。

支持的货币：

- `VAULT`：Vault 连接的金币经济。
- `PLAYERPOINTS`：PlayerPoints 点券。
- `DEFAULT`：继承全局货币设置。

```yaml
economy:
  default-provider: "PLAYERPOINTS"
  playerpoints:
    display-name: "点券"
```

单个皮肤也可单独设置：

```yaml
skins:
  sakura_sword:
    currency: "PLAYERPOINTS"
    price: 500
```

PlayerPoints 价格必须是 0 到 2147483647 的整数；0 表示免费。

## 临时试穿

在菜单右键皮肤，或执行：

```text
/liskin preview <皮肤ID>
/liskin preview stop
```

试穿不会扣款或解锁。到期、切换物品、移动背包、死亡、退出或插件关闭时会恢复原外观。持续时间和是否允许试穿未解锁皮肤由 `config.yml` 的 `preview` 节点控制。

## 常驻 NPC 试衣间

服务器可以在 A 点生成常驻原生玩家人偶。玩家默认需要蹲下并用主手右键 NPC，随后会打开包含全部皮肤的独立分页菜单。也可以直接执行：

```text
/liskin fitting
/liskin fitting menu
```

选择皮肤后，玩家被传送到 B 点观看 A 点的人偶。试穿人偶会套用玩家自己的皮肤并持续旋转，所选武器、装备或背部展示模型会放到正确位置。这个菜单只负责试衣，不会购买、解锁或套用到玩家物品。

观看时要切换另一套皮肤，直接蹲下并用主手右键任意位置即可重新打开菜单；不需要再次输入 `/liskin fitting`。每次切换都会保留最初的返回位置，最后结束试衣时再统一送回。

管理员先设置两点：

```text
/liskin fitting set a
/liskin fitting set b
```

A 是人偶展示位置，B 是玩家观看位置与初始视角，两点必须在同一世界。试衣默认持续 30 秒；可用 `/liskin fitting stop` 提前结束并返回原位置。常驻 NPC 被移除后会自动生成回来。
