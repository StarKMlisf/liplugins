# 皮肤商店与试穿

## 购买皮肤

使用 `/liskin` 或 `/liskin shop` 打开全部皮肤。购买成功后菜单不会关闭，条目会立即刷新为已拥有状态。

支持的货币：

- `VAULT`：Vault 连接的金币经济。
- `PLAYERPOINTS`：PlayerPoints 点券。
- `DEFAULT`：继承全局货币设置。

```yaml
economy:
  default-provider: "PLAYERPOINTS"
  playerpoints:
    display-name: "点券"
```

单个皮肤也可单独设置：

```yaml
skins:
  sakura_sword:
    currency: "PLAYERPOINTS"
    price: 500
```

PlayerPoints 价格必须是 0 到 2147483647 的整数；0 表示免费。

## 临时试穿

在菜单右键皮肤，或执行：

```text
/liskin preview <皮肤ID>
/liskin preview stop
```

试穿不会扣款或解锁。到期、切换物品、移动背包、死亡、退出或插件关闭时会恢复原外观。持续时间和是否允许试穿未解锁皮肤由 `config.yml` 的 `preview` 节点控制。
