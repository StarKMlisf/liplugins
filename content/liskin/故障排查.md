# 故障排查

## 菜单有皮肤但模型不显示

1. 确认 CraftEngine `26.7.4` 已正常加载。
2. 确认 `plugins/CraftEngine/resources/skins` 已安装且没有重复旧资源目录。
3. 让客户端重新接收最新资源包。
4. 检查 `ce-item` 是否真实存在。
5. 检查 `item-model` 填的是物品模型 ID，而不是模型文件路径。

## 应用后材质或装备槽错误

- 用 `/liskin debug hand` 查看当前外观组件。
- 武器确认 `target-group` 与主手物品匹配。
- 头饰检查 `copy-equippable`、`equipment-model` 和 `equipment-slot: HEAD`。
- 不要继续使用已停用的 `craftengine-id` 或 `ce-identity`。

## 自动恢复原外观

检查玩家是否拥有 `liskin.skin.use`、对应 `liskin.category.<分类>`、皮肤独立权限，并确认解锁数据已经同步。

## 商店或跨服失败

- Vault 模式检查 Vault 与经济插件。
- PlayerPoints 模式检查依赖和整数价格。
- MySQL 模式检查连接、唯一 `server-id` 和最早的数据库错误。
- 更改 `storage.type` 后完整重启，不要仅重载。

## 试衣 NPC 没有生成或不能交互

1. 确认 LiSkin 版本为 1.9.5，并使用支持原生 `Mannequin` 的 Paper/Folia 26.1.2 或 26.2 兼容核心。
2. 分别执行 `/liskin fitting set a` 和 `/liskin fitting set b`，确认两点在同一世界。
3. 检查 `fitting-room.enabled` 与 `fitting-room.npc.enabled` 是否为 `true`。
4. 默认交互需要玩家拥有 `liskin.fitting`，蹲下并用主手右键 NPC；副手事件不会重复打开菜单。
5. 执行 `/liskin reload` 后检查控制台是否出现“常驻试衣 NPC 已生成”。

报告问题时附完整启动日志、Paper/CraftEngine/LiSkin 版本、Java 版本和相关皮肤配置。
