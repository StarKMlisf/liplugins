# 配置说明

皮肤条目位于 `skins.yml`。最小配置：

```yaml
skins:
  sakura_sword:
    name: "<pink>樱花剑</pink>"
    ce-item: "example:sakura_sword"
    target-group: "sword"
```

## 关键字段

- `ce-item`：用于解锁、菜单展示和创建外观来源的 CraftEngine 物品 ID。
- `item-model`：目标物品 `item_model` 组件的兜底 ID；填写生成后的物品模型 ID，不是模型文件路径。
- `target-group`：允许应用的目标物品分类。
- `copy-equippable`：是否同步穿戴外观组件，盔甲和头饰通常开启。
- `equipment-model`：装备模型/资产 ID；普通 3D 头饰可填 `none`。
- `equipment-slot`：强制装备槽，例如 `HEAD`。
- `display-entity`：为背包等只有 3D 物品模型的穿戴外观启用跟随 ItemDisplay。
- `permission`：皮肤独立权限，留空表示不额外限制。
- `currency`：`DEFAULT`、`VAULT` 或 `PLAYERPOINTS`。
- `price`：0 表示免费。

`craftengine-id` 和 `ce-identity` 已停用并会被忽略。它们可能导致 CraftEngine 按来源物品身份渲染，从而错误改变原物品材质。

## 试衣间配置

试衣间位置建议使用指令写入，不要手工填写坐标：

```yaml
fitting-room:
  enabled: true
  duration-seconds: 30
  allow-locked: true
  rotation-degrees-per-tick: 1.5
  lock-viewer-position: true
  return-player: true
  npc:
    enabled: true
    name: "<gradient:#66ccff:#cc99ff>皮肤试衣间</gradient>"
    name-visible: true
    skin-player: ""
    require-sneaking: true
```

- `duration-seconds`：单次人偶试衣持续 5–300 秒。
- `allow-locked`：是否允许试用尚未解锁、但玩家有权查看的皮肤。
- `rotation-degrees-per-tick`：人偶每刻旋转角度，范围 0.1–10.0。
- `lock-viewer-position`：试衣期间是否把玩家固定在 B 点。
- `return-player`：结束后是否送回开始试衣前的位置。
- `npc.enabled`：是否在 A 点生成常驻试衣 NPC。
- `npc.name`、`npc.name-visible`：NPC 名称和常显设置，名称支持 MiniMessage。
- `npc.skin-player`：NPC 使用的正版玩家皮肤名；留空使用默认人偶皮肤。
- `npc.require-sneaking`：是否必须蹲下并用主手右键 NPC 才打开菜单。

使用 `/liskin fitting set a` 保存展示点，使用 `/liskin fitting set b` 保存观看点和视角。A、B 必须位于同一世界。

## item-model 注意事项

应填写类似 `cutiecatpack:cute_pickaxe` 的物品模型 ID，不要填写 CE 配置中 `model: namespace:path/file` 形式的模型文件路径。若 CE 物品没有单独的 `item-model`，通常可直接使用 `ce-item`。
