# 命令与权限

## 玩家命令

| 命令 | 主要权限 |
| --- | --- |
| `/liskin`、`/liskin menu` | `liskin.use`、`liskin.menu` |
| `/liskin unlock` | `liskin.unlock` |
| `/liskin apply <ID>` | `liskin.apply` |
| `/liskin preview <ID>`、`preview stop` | `liskin.preview` |
| `/liskin fitting`、`fitting menu` | `liskin.fitting` |
| `/liskin fitting start <ID>`、`fitting stop` | `liskin.fitting` |
| `/liskin remove` | `liskin.remove` |
| `/liskin wardrobe` | 默认玩家权限组 |
| `/liskin shop` | `liskin.shop` |
| 商店购买 | `liskin.shop.buy` |

`liskin.user` 是默认玩家权限组，包含菜单、解锁、应用、试穿、移除、商店和基础分类权限。显示已换皮物品还需要 `liskin.skin.use`。

分类权限格式为 `liskin.category.<分类>`，例如 `liskin.category.sword`。皮肤还可在 `skins.yml` 使用 `permission` 设置独立权限。

## 管理命令

| 命令 | 权限 |
| --- | --- |
| `/liskin reload` | `liskin.admin.reload` |
| `/liskin debug hand` | `liskin.admin.debug` |
| `/liskin admin unlock <玩家> <ID>` | `liskin.admin.unlock` |
| `/liskin admin lock <玩家> <ID>` | `liskin.admin.lock` |
| `/liskin fitting set <a\|b>` | `liskin.admin.fitting` |

`/liskin fitting` 不带参数时也会打开全部服装试衣菜单。菜单只会开始人偶试穿，不会购买皮肤或改动玩家物品。所有子命令均提供 Tab 补全。LuckPerms 可用于管理权限，但不是插件必需依赖。
