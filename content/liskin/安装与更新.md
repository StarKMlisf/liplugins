# 安装与更新

## 运行环境

- Paper / Folia `26.1.2`、`26.2`
- Java 25
- CraftEngine `26.7.4` 为必需依赖
- Vault、PlayerPoints 按商店货币选择安装

## 安装

1. 安装并启动 CraftEngine。
2. 将发行包中的 `CraftEngine-resources/skins` 整体复制到 `plugins/CraftEngine/resources/skins`。
3. 将 LiSkin Jar 放入 `plugins/`。
4. 完整重启服务器，让 CraftEngine 重新生成并分发资源包。
5. 执行 `/liskin`，用一件测试物品验证解锁、应用和移除。
6. 需要试衣间时，依次执行 `/liskin fitting set a`、`/liskin fitting set b`，再蹲下右键 NPC 验证菜单和旋转人偶。

如果使用过分开的旧资源目录，应先备份并移除旧目录，避免 CraftEngine 重复注册同一物品。

## 更新

1. 停服并备份 `plugins/LiSkin/` 与 CraftEngine 资源目录。
2. 群组服另行备份 MySQL 数据库。
3. 替换 Jar 和配套资源。
4. 完整启动后检查 CraftEngine 与 LiSkin 的首次错误。
5. 测试 `/liskin debug hand`、应用、移除、主手试穿和 NPC 人偶试衣。

从旧版升级到 1.9.5 时，缺少的 `fitting-room`、NPC 和试衣菜单消息节点会自动补齐，不会覆盖管理员已经修改的配置值。首次启用常驻 NPC 前仍需设置 A、B 两点。

`storage.type` 变更必须完整重启，不能只执行 `/liskin reload`。
