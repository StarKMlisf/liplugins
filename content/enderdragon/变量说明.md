# EnderDragon PlaceholderAPI 变量

## 使用条件

安装 PlaceholderAPI 并确认 EnderDragon 扩展已注册。变量前缀为 `%ed_...%`。

## 龙状态

| 变量 | 说明 |
| --- | --- |
| `%ed_dragon_status%` | 玩家当前世界的龙状态 |
| `%ed_dragon_status_<世界名>%` | 指定世界的龙状态 |

返回文本可以在配置中调整，例如存活、死亡或复活中。

## 复活相关

插件提供“是否可以复活”、旧版世界倒计时、格式化倒计时和单龙复活信息类变量。变量名中包含世界或龙 ID 时，应保持与实际配置完全一致。

## 验证方法

```text
/papi parse me %ed_dragon_status%
```

先用 PAPI 命令确认原始返回，再放入计分板、TAB 或菜单插件。若原始解析正确而外部插件不显示，应检查外部插件的刷新频率和转义规则。

## 常见问题

- 原样显示变量：PlaceholderAPI 未安装、扩展未注册或变量拼写错误。
- 返回未知世界：世界名不一致。
- 单龙变量无数据：龙 ID 与 `setting/` 文件名不一致。
- 倒计时不刷新：外部显示插件缓存或刷新周期过长。

完整变量表仍可在[原始总览](./Home.md)中查阅。
