# EnderDragon 召唤与自动复活

## 三种召唤来源

```yml
summon:
  crystal-respawn:
    enabled: true
  command:
    enabled: true
  countdown:
    enabled: true
```

- 水晶复活：接管原版末影水晶流程。
- 指令召唤：允许管理员或有权限的玩家使用 `/ed respawn`、`/ed spawn`。
- 倒计时召唤：由击杀后倒计时、定点任务或单龙规则自动执行。

## 指令召唤

```text
/ed respawn
/ed respawn <世界名>
/ed spawn <龙ID>
/ed spawn <龙ID> <世界名>
```

玩家必须位于末地；控制台可以显式提供世界名。龙 ID 来自 `setting/` 下对应配置文件。

## 倒计时管理

```text
/ed respawn_cd get <世界名>
/ed respawn_cd set <世界名> <秒>
/ed respawn_cd start <世界名>
/ed respawn_cd remove <世界名>
/ed respawn_cd removeAll
```

设置时间不等于立即启动，修改后应再检查当前倒计时状态。

## 单龙复活

不同龙可以拥有独立复活规则，并通过 `/ed respawn_info <龙ID>` 查看。服主应避免让多个规则在同一末地同时触发。

## 防重复与卡住保护

召唤前会同时检查原版龙和插件记录的龙。原版复活流程长时间未生成龙时，插件会检测并重新提交水晶流程，而不是直接生成一条实体绕过末地战斗系统。

## 验证建议

每种启用的召唤方式都应单独测试一次，包括“已有龙时拒绝”“重启后倒计时恢复”和“错误世界不执行”。
