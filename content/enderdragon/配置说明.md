# EnderDragon 配置说明

## 文件结构

```text
plugins/EnderDragon/
├─ config.yml
├─ lang/
├─ setting/
├─ reward/
├─ gui/
├─ data.yml
└─ respawn_cd.yml
```

## `config.yml`

控制语言、伤害显示、龙配置列表、三类召唤入口、自动复活、龙蛋、黑名单世界、Placeholder 文本和可选依赖钩子。

## `setting/`

每个 YAML 文件对应一个龙 ID，例如 `default.yml` 或自定义中文 ID。常见内容包括名称、属性、BossBar、发光颜色、广播、奖励引用和独立复活规则。

文件名和引用 ID 必须一致。改名后要同步检查命令、奖励和复活配置。

## `reward/`

保存各龙奖励池。奖励可以发物品、执行后台命令，或同时执行。游戏内编辑前先备份对应文件。

## `gui/` 与 `lang/`

- `gui/`：奖励预览与编辑菜单。
- `lang/`：玩家消息和状态文本。

## 运行数据

- `data.yml` 保存插件运行状态。
- `respawn_cd.yml` 保存倒计时复活信息。

不要在服务器运行时随意删除这两个文件。修改静态配置后使用 `/ed reload`，更新插件版本后完整重启。

## 配置策略

先在测试末地验证单条龙，再逐步增加权重、奖励和自动复活。避免同时开启多个互相重叠的召唤计划。
