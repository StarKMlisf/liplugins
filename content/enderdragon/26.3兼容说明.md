# 26.3.0 · Paper / Folia 26.3

更新日期：2026-10-21。

> 历史记录：本页对应 26.3.0，不是当前 26.3.1 的新增玩法验收。当前版本直接验证范围见 [更新日志](更新日志.md)。

新增 Bukkit/Folia 调度桥接；龙任务绑定实体线程，目标玩家效果分别分派。Folia 彩色发光通过外置 PacketEvents 2.14.0 发包，避免服务端记分板 API。初次物品转换在启用阶段完成。已验证龙生成、自定义生命值与发光标志；颜色视觉和有玩家参与的战斗仍需客户端验收。

## 运行环境

- Java 25；Paper 26.3 build 210。
- Folia 26.3 build 5 为官方 ALPHA 构建，目录以“测试版”展示。
- 26.3 使用 PacketEvents 2.14.0、CraftEngine 26.9.2；只安装插件自身所需的前置。Vault、PlaceholderAPI 与经济插件按原配置保留。

## 验证范围

本次完成源码构建、现有测试及独立 Paper/Folia 测试服加载检查。对调度变更补做任务取消、全局回调、两个相隔 1024 格位置的实体缩放、末影龙生成与实体任务、LWE 填充扣料探针。探针测试不等同于所有菜单、战斗、经济、资源包和跨服玩法的完整玩家验收。

测试服未复制生产自定义资源，因此商店、棋盘与时装所需的 CraftEngine 模型须继续使用服主自己的资源包。未声称已验收客户端图形。

## 更新方式

完整停服后备份旧 Jar，以新版本替换同名插件，确保每个插件只保留一份 Jar。保留现有配置、语言、价格、数据库和世界。不要直接用 26.3 核心打开唯一一份旧世界；先复制测试。本页仅保留该历史构建的 26.3 说明。
