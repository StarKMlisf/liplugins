# EnderDragon 命令与权限

## 常用查询

| 指令 | 说明 | 权限 |
| --- | --- | --- |
| `/ed help` | 查看帮助 | 无特殊权限 |
| `/ed status [世界名]` | 查看龙状态 | `ed.status` |
| `/ed respawn_info <龙ID>` | 查看单龙复活信息 | `ed.respawn_info` |
| `/ed drop gui [龙ID]` | 预览奖励 | `ed.drop.gui` |

## 召唤与复活

| 指令 | 说明 |
| --- | --- |
| `/ed respawn [世界名]` | 随机选择龙并提交复活 |
| `/ed spawn <龙ID> [世界名]` | 召唤指定龙 |
| `/ed respawn_cd get <世界名>` | 查询倒计时 |
| `/ed respawn_cd set <世界名> <秒>` | 设置倒计时 |
| `/ed respawn_cd start <世界名>` | 启动倒计时 |
| `/ed respawn_cd remove <世界名>` | 删除指定倒计时 |
| `/ed respawn_cd removeAll` | 删除全部倒计时 |

以上管理操作需要 `ed.respawn` 或管理员总权限。

## 奖励与维护

| 指令 | 权限 |
| --- | --- |
| `/ed drop edit [龙ID]` | `ed.drop.edit` |
| `/ed drop add <龙ID> <概率>` | `ed.drop.edit` |
| `/ed drop remove <龙ID> <序号>` | `ed.drop.edit` |
| `/ed drop clear <龙ID>` | `ed.drop.edit` |
| `/ed reload` | `ed.reload` |
| `/ed reload script` | `ed.reload` |
| `/ed update` | `ed.update` |

## 权限汇总

`ed.admin` 默认给 OP，并包含 `ed.reload`、`ed.status`、`ed.respawn_info`、`ed.drop.edit`、`ed.respawn` 和 `ed.update`。普通奖励预览使用独立的 `ed.drop.gui`。
