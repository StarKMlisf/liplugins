# EnderDragon 战斗、伤害与奖励

## 战斗记录

插件会记录参与者及其伤害，用于决定击杀者、伤害排名和参与奖励。配置可以为不同龙设置不同名称、血量、护甲、韧性、BossBar 和发光颜色。

## 奖励类型

- 最后击杀者奖励。
- 伤害排名奖励。
- 按伤害记录发放的参与奖。
- 从参与者中抽取的随机奖励。
- 龙死亡位置的世界掉落。
- 后台命令奖励。

玩家离开末地后，只要仍在线，基于伤害记录的玩家类奖励仍可以发放。

## 命令变量

| 变量 | 含义 |
| --- | --- |
| `%player%`、`%player_name%`、`%name%` | 玩家名 |
| `%uuid%` | 玩家 UUID |
| `%dragon%` | 龙显示名 |
| `%dragon_id%` | 龙配置 ID |
| `%world%` | 世界名 |

推荐统一使用 `%player%`，减少维护时的混淆。

## 游戏内编辑

```text
/ed drop gui [龙ID]
/ed drop edit [龙ID]
/ed drop add <龙ID> <概率>
/ed drop remove <龙ID> <序号>
/ed drop clear <龙ID>
```

`drop add` 会读取管理员主手物品。修改正式服奖励池前先在预览 GUI 确认物品、数量和概率。

## 龙蛋

开启叠加后，如果原位置已经有龙蛋，插件会在配置的最大高度内向上寻找位置，避免后续击杀覆盖第一颗龙蛋。
