# EnderDragon 玩家指南

## 你会遇到什么

EnderDragon 会接管启用世界中的末影龙，并根据服务器配置改变名称、血量、护甲、BossBar、广播、奖励和复活规则。不同龙 ID 可以代表不同难度或奖励池。

## 查看状态

```text
/ed status
/ed respawn_info <龙ID>
```

`status` 用于查看当前末地是否存在龙；`respawn_info` 用于查看某条龙的独立复活信息。具体开放范围由权限决定。

## 参与战斗

- 伤害记录会用于排名奖和参与奖。
- 玩家死亡、回城或离开末地后，只要仍在线，已记录的玩家类奖励仍可正常发放。
- 掉落类奖励会出现在龙死亡位置，应及时拾取。
- 服务器可能为不同龙配置不同血量、技能表现和奖励。

## 召唤限制

玩家使用 `/ed respawn` 或 `/ed spawn <龙ID>` 时必须本人位于末地。控制台才可以指定目标世界。

如果当前世界已经存在原版龙或插件管理的龙，新召唤会被阻止，避免同一末地重复生成。

## 奖励预览

```text
/ed drop gui
/ed drop gui <龙ID>
```

该入口是否对普通玩家开放取决于 `ed.drop.gui` 权限。预览只显示奖励，不会直接领取。
