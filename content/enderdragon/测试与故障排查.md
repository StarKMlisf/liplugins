# EnderDragon 测试与故障排查

## 推荐回归流程

1. `/ed status` 确认末地当前状态。
2. `/ed spawn default` 召唤测试龙。
3. 检查名称、属性、BossBar、广播和发光效果。
4. 两名玩家造成伤害后击杀。
5. 核对击杀、排名、参与、掉落和命令奖励。
6. 检查龙蛋位置。
7. 设置短倒计时，验证自动复活和重启恢复。
8. 验证已有龙时所有召唤入口都会拒绝。

## 无法召唤

- 玩家不在末地。
- 当前世界已经存在原版龙或 ED 龙。
- 对应召唤方式被关闭。
- 龙 ID 没有加载。
- 世界或生成原因位于黑名单。

## 复活流程卡住

观察原版水晶动画和控制台日志。不要立刻再执行多次召唤；插件有后置检测和重提交流程，重复操作可能使判断更困难。

## 奖励未发放

- 检查玩家是否产生有效伤害记录。
- 检查奖励池是否启用物品或命令。
- 确认命令未带 `/`，变量可以解析。
- 检查玩家是否在线以及背包或掉落位置。

## 配置未生效

确认修改的是正在使用的龙 ID 和奖励文件，YAML 缩进正确，并执行 `/ed reload`。涉及版本、依赖或实体生命周期时完整重启。
