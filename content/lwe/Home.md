# LWE 小创世神

> 面向生存服务器的轻量选区施工工具：把大型操作拆成限速任务，并通过 LIEMC 在材料耗尽时自动补料。

当前文档对应：

| 组件 | 版本 |
| --- | --- |
| LWE 小创世神 | `0.1.0+build.15` |
| LIEMC | `0.1.0+build.95` 或更高 |
| Java | Java 21 |
| 服务端 | Bukkit / Paper 1.21.x |

## 核心能力

- 使用坐标指令，或进入选区模式后用任意镐子设置两个对角点。
- `/lwe fill` 只填充选区中的空气方块。
- `/lwe overlay` 替换选区中的非空气方块。
- `/lwe drain` 清除液体，启动时消耗一个海绵。
- `/lwe empty` 清空可处理方块，并消耗镐子耐久。
- 每 tick 按配置数量推进任务，避免一次处理完整选区造成瞬时卡顿。
- 检查最大操作距离和区块加载状态，任务支持暂停、恢复和取消。
- 建筑材料可依次从玩家背包、潜影盒和 LIEMC 自动补充取得。

## 三分钟开始施工

1. 服务器同时安装 LIEMC 与 LWE，完整重启。
2. 执行 `/lwe select`，拿任意镐子左键设置点 1、右键设置点 2。
3. 主手拿目标方块，执行 `/lwe fill` 或 `/lwe overlay`。
4. 使用 `/lwe pause`、`/lwe resume` 或 `/lwe cancel` 控制任务。
5. 需要 EMC 续料时先执行 `/emc autorefill on`。

## 材料规则

原版可放置方块都能作为施工模板。方块是否存在于 LIEMC，只决定它能否在材料耗尽时通过 EMC 购买，不是普通施工的使用门槛。

当 `resource.force_item_consume: true` 时，每成功放置一个方块都会实际消耗一个材料。插件按以下顺序查找：

1. 玩家背包中的同类方块；
2. 背包内潜影盒中的同类方块；
3. 已开启的 LIEMC 自动补充。

## 平台边界

当前任务循环使用 Bukkit 主线程调度器。虽然插件描述文件保留了 `folia-supported` 标记，但该标记只影响加载门槛，不能证明跨区域操作线程安全；正式部署请先使用 Paper/Bukkit 环境。Folia 支持需要后续完成区域调度迁移与实服验证。
