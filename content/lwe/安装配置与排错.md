# 安装、配置与故障排查

## 安装要求

| 项目 | 要求 |
| --- | --- |
| 服务端 | Bukkit / Paper 1.21.x |
| Java | Java 21 |
| 必需前置 | LIEMC `0.1.0+build.95` 或更高 |
| LWE | `0.1.0+build.15` |

安装步骤：

1. 将 LIEMC 与 LWE Jar 放入服务器 `plugins` 目录。
2. 完整启动服务器；LWE 会在 LIEMC 之后加载。
3. 确认控制台没有“未检测到 LIEMC”提示。
4. 执行 `/lwe list` 和 `/lwe check STONE`。
5. 小范围执行一次 `/lwe fill`，再测试材料耗尽后的 EMC 补料。

不要使用插件管理器热载入。升级两个插件后应完整重启，确保依赖关系和公开 API 都重新绑定。

## 配置参考

```yml
# LIEMC 配置相对于 plugins/LWE/ 的路径
liemc-config-path: "../LIEMC/config.yml"

server:
  # 选区离玩家允许的最大距离，最小 8
  max_operation_distance: 128
  # 每 tick 最多尝试处理的方块数，范围 1~20
  default_speed_multiplier: 5

tool:
  # 历史键名保留为 min_hoe_durability，实际用于清空操作的镐子最低剩余耐久
  min_hoe_durability: 10
  # 是否按原版耐久规则处理耐久附魔
  enable_unbreaking_enchant: true

resource:
  # 背包材料不足时，是否搜索潜影盒
  enable_shulker_box_refill: true
  # 是否真实消耗填充和覆盖材料
  force_item_consume: true

behavior:
  # 清空操作是否生成方块掉落物
  enable_block_drop: false
  # 是否显示选区粒子边界
  enable_selection_visual: true

task:
  # 暂停时是否保留任务队列
  keep_task_queue_on_pause: true
  # 因镐子耐久不足暂停后是否允许恢复
  enable_resume_after_low_durability: true
```

`messages` 下的全部提示均可在同一配置文件中修改。修改后执行 `/lwe reload`。

## Folia 说明

当前 LWE 的任务计时器直接使用 Bukkit 主线程调度器，尚未完成 Folia 区域线程迁移。`folia-supported: true` 只允许加载，不等于运行路径已安全适配。生产环境请先使用 Paper/Bukkit；不要仅凭加载成功判定 Folia 兼容。

## 常见问题

### LWE 启动后立即禁用

- 确认 `plugins` 中存在 LIEMC。
- 确认 LIEMC 已成功启用，而不是因数据库或依赖问题停用。
- 完整重启，不要分别热载入两个插件。

### 提示选区未就绪

- 两个点都必须设置。
- 两点必须属于同一个世界。
- 坐标选点命令必须完整提供 `x y z`。

### 提示距离过远或区块未加载

- 靠近选区后重试。
- 减小 `server.max_operation_distance` 不会加载区块，只会进一步限制距离。
- 大选区执行期间不要传送离开。

### 材料不足后任务暂停

- 确认背包或潜影盒中存在完全相同的方块。
- 需要 EMC 续料时开启 `/emc autorefill on` 并检查余额。
- 使用 LIEMC build.95 与 LWE build.15 或更高版本。

### `/lwe empty` 停止

- 主手必须是任意镐子。
- 检查镐子剩余耐久是否高于 `tool.min_hoe_durability`。
- 替换镐子后，根据配置执行 `/lwe resume`。
