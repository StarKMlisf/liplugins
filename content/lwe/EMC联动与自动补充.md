# EMC 联动与自动补充

LWE 必须在 LIEMC 已成功启用后加载。它会读取 LIEMC 的方块列表，并在施工材料不足时调用公开自动补充 API。

## 开启自动补充

玩家执行：

```text
/emc autorefill on
```

也可以在 EMC 菜单中点击自动补充开关。开关状态保存在 LIEMC 数据库中。

## 普通手持补充

当主手或副手物品实际消耗后，剩余数量达到 LIEMC 的 `auto-refill.trigger-threshold`，插件会补至该物品的 `withdraw-amount`。

只按实际补入数量扣除 EMC。例如当前剩余 2 个、目标数量为 64，则购买 62 个，而不是再次扣除整整 64 个的费用。

以下情况不会扣费：

- 交互被其他插件取消；
- 物品数量没有实际减少；
- 当前物品不在 LIEMC 列表；
- 玩家未开启自动补充；
- EMC 余额不足；
- 创造模式；
- 背包没有可放入材料的空间。

## LWE 施工补料

LWE 的任务材料耗尽后，会先尝试从背包和潜影盒中取出同类方块。仍然不足时，才请求 LIEMC 购买一组材料放入背包，然后继续消耗。

这个流程允许玩家主手继续拿施工工具，不再要求主手必须为空。对应修复需要：

```text
LIEMC-0.1.0+build.95.jar
LWE-0.1.0+build.15.jar
```

如果只更新 LWE、没有同步更新 LIEMC，公开自动补充 API 不存在，联动会回退到旧接口，旧版本的主手限制仍可能导致补料失败。

## 排查步骤

1. 执行 `/emc autorefill on`，确认提示“自动补充：开启”。
2. 执行 `/emc balance`，确认余额足够。
3. 使用 `/lwe hand` 或 `/lwe check <方块>` 确认目标是可用方块。
4. 确认目标方块存在于 LIEMC `items` 列表。
5. 确认服务器加载的是 LIEMC build.95 与 LWE build.15 或更高版本。
6. 查看控制台是否出现数据库连接或自动补充执行失败提示。
