# 命令与权限

主命令：`/lwe`

## 玩家命令

| 命令 | 说明 |
| --- | --- |
| `/lwe`、`/lwe list` | 查看可用原版方块与 LIEMC 方块统计 |
| `/lwe select` | 切换镐子快速选区模式 |
| `/lwe point 1 <x> <y> <z>` | 设置选区点 1 |
| `/lwe point 2 <x> <y> <z>` | 设置选区点 2 |
| `/lwe hand` | 检查主手方块 |
| `/lwe check <方块英文名>` | 检查指定原版方块 |
| `/lwe fill` | 使用主手方块填充空气 |
| `/lwe overlay` | 使用主手方块覆盖非空气方块 |
| `/lwe drain` | 消耗一个海绵并清除液体 |
| `/lwe empty` | 使用镐子清空可处理方块 |
| `/lwe pause` | 暂停当前任务 |
| `/lwe resume` | 恢复暂停任务 |
| `/lwe cancel` | 取消当前任务 |

## 管理员命令

| 命令 | 说明 |
| --- | --- |
| `/lwe reload` | 重载 LWE 配置并重新读取 LIEMC 方块列表 |

## 权限节点

| 权限 | 默认 | 说明 |
| --- | --- | --- |
| `lwe.use` | 所有玩家 | 使用选区、查询、施工和任务控制命令 |
| `lwe.admin` | OP | 使用 `/lwe reload` |

主命令、子命令、选区编号、坐标以及方块名称均提供 Tab 参数补全。
