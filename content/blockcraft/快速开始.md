# BlockCraft 快速开始

## 1. 搭建祭坛结构

1. 在世界内放置结构核心方块与八个基座。
2. 按 `structures.yml` 的偏移坐标摆好支持方块（如有）。
3. 使用 `/blockcraft debug` 检查结构是否识别通过。

## 2. 放置物品

- 手持配方中心物品（`altar-item`）右键中心；
- 手持基座物品一次可放入手上的全部同类；
- 左键/右键按插件行为将物品放到对应基座槽位；
- 多文件配方均可在 `plugins/BlockCraft/recipes` 下管理。

## 3. 开始合成

1. 物品放齐后空手右键中心尝试匹配配方；
2. 检查权限、费用与结构完整性；
3. 匹配后显示粒子和动画并开始计时；
4. 合成成功后产物会浮空展示在中心，潮信取回。

## 4. 常用参数

- `recipes/*.yml`：配方文件；
- `config.yml`：显示、粒子、音效与行为开关；
- `structures.yml`：核心/基座/支持方块坐标；
- `messages.yml`：所有中文提示语。
