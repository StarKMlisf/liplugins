# 安装与更新

## 运行环境

- Paper 26.2；
- Java 25；
- 软依赖按需：MMOItems、MythicLib、CraftEngine、CustomFishing、Vault、PlaceholderAPI。

## 安装步骤

1. 关闭服务器；
2. 上传 `BlockCraft-1.0.11.jar` 到 `plugins`；
3. 按需安装相关前置；
4. 启动并检查控制台 `BlockCraft 已启用`；
5. 首次启动后检查 `plugins/BlockCraft` 下配置文件是否完整生成。

## 更新建议

1. 先备份旧的 `plugins/BlockCraft`；
2. 替换新 Jar；
3. 重启后执行 `/blockcraft reload`；
4. 发现问题可先回退到备份版本。

## 兼容说明

BlockCraft 当前不支持 Folia 调度模型，请先使用 Paper 26.2。配置与配方自动回填时会保留服主自定义字段。
