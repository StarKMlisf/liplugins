# 物品放置与领取

## 放入规则

默认配置会一次放入玩家主手中的全部物品：

```yaml
interaction:
  insert-all: true
  insert-amount: 1
  allow-stacking: true
  max-stack-size: 64
  max-surrounding-slots: 8
```

- `insert-all: true`：尝试放入整组，受 `max-stack-size` 限制；
- `insert-all: false`：每次最多放入 `insert-amount`；
- `allow-stacking: true`：再次右键可叠加完全相同的物品；
- 不同物品不能放到已经占用的同一个基座或中心槽位。
- `max-surrounding-slots`：一座祭坛最多保存多少种独立环绕物品堆，范围 1-32。

这里的“完全相同”按真实 `ItemStack` 判断，自定义名称、Lore、附魔、MMOItems 随机数据、宝石和其他元数据都会参与判断。

## 基座操作

| 玩家操作 | 插件行为 |
| --- | --- |
| 手持物品右键空基座 | 放入物品 |
| 手持相同物品右键已占用基座 | 按设置叠加 |
| 手持不同物品右键已占用基座 | 拒绝放入 |
| 空手右键已占用基座 | 显示当前物品名称和取回提示 |
| 潜行 + 右键基座 | 取回该基座全部物品 |

## 祭坛中心操作

| 玩家操作 | 插件行为 |
| --- | --- |
| 手持物品右键核心 | 放入或叠加前置物 |
| 手持配方声明的环绕物右键核心 | `ADVANCED` 模式下放入环绕槽，在核心侧边旋转 |
| 空手右键核心 | 尝试匹配并开始合成 |
| 潜行 + 右键核心 | 依次优先领取待取成品、全部环绕物、前置物 |

祭坛上存在待领取成品时，不允许开始下一次合成。领取后，如果中心前置物仍有余量，会重新显示中心物品。

环绕槽不是任意物品展示位。插件只接收已启用 `ADVANCED` 配方的 `surroundings` 物品，并结合已经存在的环绕物缩小候选配方。祭坛中心物品不参与“是否允许进入环绕槽”的判断，因此中心即使暂时放错或放着其他材料，合法环绕材料仍能进入独立轨道；最终开始合成时，中心物品仍必须满足完整配方。

每次成功放入环绕材料都会提示该物品的真实名称、本次放入数量、当前堆叠数量和环绕物品种类数。MMOItems、CraftEngine 与 CustomFishing 的自定义名称会被保留。

## 数量大于配方需求

配方匹配采用“至少满足”规则。例如配方需要 16 个材料，但基座总计放了 24 个：

- 合成可以正常开始；
- 只扣除 16 个；
- 剩余 8 个保留在原基座；
- 材料可以分散到多个基座累计。

`allow-extra-materials: false` 只禁止出现配方中没有配置的其他材料种类，不会禁止同种材料数量超出需求。

`ADVANCED` 的环绕材料同样采用“至少满足”规则。比如要求 4 个但放入 6 个，结算只扣 4 个，剩余 2 个继续在祭坛周围旋转。

## 展示与持久化

方块上方的物品只是不可拾取的 `ItemDisplay` 视觉实体。真实物品保存在：

```text
plugins/BlockCraft/data.yml
```

这样可以保留完整自定义数据。不要通过杀死展示实体的方式取物品，应使用潜行右键。

## 背包已满

取回或领取时，插件会优先放入玩家背包。无法装下的物品会掉落在玩家脚下，不会静默删除。

## 合成锁定和保护

计时期间核心、全部环绕槽与全部基座会被锁定，不能放入或取回物品。默认还会：

- 禁止破坏正在合成的结构；
- 保护已存物品的祭坛免受爆炸影响；
- 阻止活塞移动已存物品的祭坛方块；
- 结构在空闲状态被拆除时返还内部物品；
- 启动时发现已保存结构损坏，会在原核心位置返还物品。

保护开关位于 `config.yml` 的 `protection` 节点。
