# 平台兼容性

## 当前支持平台

- Paper 26.2 / Folia 1.21.11
- Java 25

## 当前不支持平台

- 低于 Minecraft 1.21 的服务端版本

## 兼容性承诺

- 仍支持通过 `plugin.yml` 的软依赖按需启用 MMOItems / MythicLib / CraftEngine / CustomFishing / Vault / PlaceholderAPI
- 不强制要求任何外部经济与自定义物品前置
- 不会因某个前置缺失而影响原版物品配方运行
