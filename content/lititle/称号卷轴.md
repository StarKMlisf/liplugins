# 称号卷轴

称号卷轴是一件可发放、可交易、可绑定的实体物品。玩家右键后永久解锁指定称号；卷轴系统不包含随机奖池、抽取费用或保底机制。

## 管理员发放

```text
/lititle scroll give <玩家> <称号ID> [数量]
```

目标玩家必须在线。数量省略时按默认值发放。

## 玩家使用规则

- 右键卷轴后解锁对应称号。
- 已拥有该称号时不消耗卷轴。
- 权限不足、绑定对象不符或称号配置已删除时不消耗卷轴。
- 可配置解锁后自动佩戴和执行服务器指令。
- 默认可交易；开启绑定后只能由指定接收者使用。

## 配置入口

卷轴配置位于：

```text
plugins/LiTitle/scroll.yml
```

可调整材质、CustomModelData、名称、Lore、附魔光效、绑定方式、使用权限、背包已满处理、自动佩戴、解锁动作与全部提示文本。

背包已满时，服务器可以选择把未放入的卷轴掉落在玩家脚下，或只提示未成功发放的数量。修改后单独重载：

```text
/lititle reload scroll
```

## 配置与运营边界

卷轴只负责“指定称号 ID → 实体物品 → 右键解锁”的确定性流程。若服务器需要随机抽取、奖池权重、累计保底或付费抽奖，应由其他系统完成随机选择，再调用卷轴发放命令。

发放前确认称号 ID 已存在。删除称号配置前，应检查已经流通的卷轴；旧卷轴不会自动变成其他称号。
