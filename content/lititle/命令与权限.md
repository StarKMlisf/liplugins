# 命令、权限与占位符

主命令为 `/lititle`，别名 `/ltitle`。命令支持 Tab 补全，实际可见子命令受权限影响。

## 玩家命令

| 命令 | 权限 | 说明 |
| --- | --- | --- |
| `/lititle shop` | `lititle.use` | 打开称号商店 |
| `/lititle open` | `lititle.use` | 打开称号仓库 |
| `/lititle clear` | `lititle.use` | 卸下当前称号 |
| `/lititle stats` | `lititle.use` | 打开自动称号进度 GUI |
| `/lititle advance` | `lititle.use` | 打开称号进阶 GUI |
| `/lititle submit <称号ID>` | `lititle.use` | 上交物品解锁称号 |
| `/lititle chatcolor` | `lititle.chat.color` | 打开聊天颜色菜单 |
| `/lititle nickname <昵称\|clear>` | `lititle.nickname.self` | 设置或清除中文昵称 |
| `/lititle colornick <昵称\|clear>` | `lititle.nickname.color` | 设置或清除英文彩色昵称 |

## 管理员命令

| 命令 | 权限 | 说明 |
| --- | --- | --- |
| `/lititle reload [all\|lang\|titles\|shop\|scroll]` | `lititle.admin` | 重载配置 |
| `/lititle scroll give <玩家> <称号ID> [数量]` | `lititle.scroll.give` | 发放称号卷轴 |
| `/lititle give <玩家> <称号ID>` | `lititle.admin` | 发放称号 |
| `/lititle take <玩家> <称号ID>` | `lititle.admin` | 回收玩家称号 |
| `/lititle delete <称号ID>` | `lititle.admin` | 备份后删除称号配置 |
| `/lititle shop add <称号ID> [价格] [天数]` | `lititle.admin` | 上架称号 |
| `/lititle shop remove <称号ID>` | `lititle.admin` | 下架称号 |
| `/lititle ach complete <玩家> <成就ID>` | `lititle.admin` | 完成自定义成就 |
| `/lititle spy` | `lititle.chat.spy` | 开关私聊监听 |
| `/lititle mutechat <玩家> <秒数>` | `lititle.chat.mute` | 禁言玩家 |
| `/lititle muteall <on\|off>` | `lititle.chat.muteall` | 全员禁言 |

## 主要权限

| 权限 | 默认 | 用途 |
| --- | --- | --- |
| `lititle.use` | op | 基础菜单与称号功能 |
| `lititle.admin` | op | 管理命令 |
| `lititle.scroll.use` | true | 右键使用卷轴 |
| `lititle.scroll.give` | op | 发放卷轴 |
| `lititle.chat.local` | true | 本服频道 |
| `lititle.chat.global` | true | 全服频道 |
| `lititle.chat.admin` | op | 管理频道 |
| `lititle.chat.color` | op | 聊天颜色菜单 |
| `lititle.nickname.self` | op | 中文昵称 |
| `lititle.nickname.color` | op | 英文彩色昵称 |
| `lititle.rename.self` | op | 自定义称号，不是昵称 |

聊天管理还包含 `lititle.chat.spy`、`mute`、`muteall`、`atall` 以及各类 `bypass` 权限。

普通玩家基础授权示例：

```text
/lp group default permission set lititle.use true
/lp group default permission set lititle.chat.local true
/lp group default permission set lititle.chat.global true
```

## PlaceholderAPI

| 变量 | 内容 |
| --- | --- |
| `%lititle_name%` | 当前称号显示文本 |
| `%lititle_title%` | 当前称号显示文本 |
| `%lititle_prefix%` | 当前称号显示文本 |
| `%lititle_chat_name%` | 彩色英文昵称 → 中文昵称 → 原名 |
| `%lititle_nickname%` | 中文昵称 |
| `%lititle_colored_nickname%` | 英文彩色昵称 |

TAB 等外部展示优先使用 `%lititle_chat_name%`。
