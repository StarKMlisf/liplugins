# 配置文件参考

配置目录为 `plugins/LiTitle/`。建议修改前备份，保留 UTF-8 编码，并使用空格缩进。

## 文件一览

| 文件或目录 | 用途 |
| --- | --- |
| `config.yml` | 核心开关、存储、称号与基础行为 |
| `chat.yml` | 频道、格式、服务器名、聊天限制与跨服通信 |
| `lang.yml` | 玩家与管理员提示文本 |
| `auto_grant.yml` | 自动发放规则 |
| `scroll.yml` | 称号卷轴外观、绑定、使用和消息 |
| `titles.yml` | 集中式称号配置与兼容数据 |
| `titles/` | 推荐使用的独立称号文件目录 |
| `shop_titles/` | 商城条目、价格、期限和购买类型 |
| `gui/` | 商店、仓库、统计、进阶与聊天颜色菜单 |

## 存储

单服可使用 SQLite：

```yaml
storage:
  type: sqlite
  sqlite:
    file: "data.db"
```

群组服改用 MySQL，并在所有子服填入同一个数据库。数据库密码不要上传到公开仓库。完整说明见[存储与跨服](./存储与跨服.md)。

## 聊天

`chat.yml` 至少应确认：

```yaml
chat:
  enabled: true
  server-name: "生存服"
  default-channel: "global"
  global-prefix: "!"
  admin-prefix: "#"
```

群组服的每个子服应有不同 `server-name`。频道的发言权限、收听权限、范围和格式可分别设置。

## 称号与 GUI

推荐每个称号放在 `titles/<id>.yml`，每个商店条目放在 `shop_titles/<id>.yml`。这样便于版本控制、多人协作和定位错误。

GUI 文件包括：

- `main_menu_gui.yml`
- `shop_gui.yml`
- `warehouse_gui.yml`
- `statistic_title_gui.yml`
- `advance_title_gui.yml`
- `chat_color_gui.yml`

统计称号 GUI 支持 `%progress%`、`%progress_bar%`、`%requirement_lines%`、`%desc%` 等变量。

## 修改后如何生效

普通调整执行 `/lititle reload`。只调整语言、称号、商店或卷轴时可使用对应子参数。存储和连接配置应完整重启。

升级时插件不会整份覆盖已存在配置。若新版本添加节点，应使用插件迁移结果或对照新默认文件逐项合并，不能直接覆盖长期运营配置。
