# 玩家入门

LiTitle 的主要入口是 `/lititle`，简写为 `/ltitle`。服务器可能调整菜单名称、颜色、价格与权限，但基本操作保持一致。

## 第一次使用

| 操作 | 命令 |
| --- | --- |
| 打开称号商店 | `/lititle shop` |
| 打开已拥有称号仓库 | `/lititle open` |
| 卸下当前称号 | `/lititle clear` |
| 查看自动称号进度 | `/lititle stats` |
| 打开称号进阶菜单 | `/lititle advance` |
| 打开聊天颜色菜单 | `/lititle chatcolor` |

普通玩家通常需要 `lititle.use`。聊天频道和昵称可能还需要服务器单独授予对应权限。

## 获得与佩戴称号

称号可以来自商店购买、管理员发放、自动目标、进阶、称号卷轴或服务器自定义玩法。获得后打开 `/lititle open`，点击称号即可佩戴；输入 `/lititle clear` 可恢复未佩戴状态。

有期限的称号会在到期后失效。动态称号、HEX 颜色或渐变动画由服务器配置，玩家不需要安装客户端模组。

## 查看目标进度

输入 `/lititle stats` 可查看自动称号。页面会显示当前状态、总进度、进度条、前置称号和每项条件。

如果目标要求“上交物品”，满足其他条件后仍需执行：

```text
/lititle submit <称号ID>
```

插件只会在玩家主动提交时扣除物品，不会在背包达到数量后自动拿走。

## 设置昵称

中文昵称：

```text
/lititle nickname 云梦泽
/lititle nickname clear
```

英文彩色昵称：

```text
/lititle colornick &aSteve
/lititle colornick &#66CCFFAlex
/lititle colornick clear
```

英文彩色昵称不允许中文，只接受英文字母、数字、下划线和颜色代码。最终聊天名的优先级是“彩色英文昵称 → 中文昵称 → 原游戏名”。
