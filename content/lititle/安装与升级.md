# 安装与升级

## 版本与依赖

| 项目 | 当前要求 |
| --- | --- |
| LiTitle | `0.1.93` |
| Paper | `1.21.11` 至 `26.2` |
| Folia | `26.1.2` 至 `26.2` |
| 插件字节码 | Java 21 |
| 强制前置 | Vault |

可选依赖包括 PlaceholderAPI、PlayerPoints、AttributePlus、MySQL 与 Redis。使用 Vault 金币时还需安装支持 Vault 的经济插件。

## 首次安装

1. 完整关闭服务器。
2. 将 `lltitle-0.1.93-paper-1.21.11-to-26.2-java21.jar` 与 Vault 放入 `plugins/`。
3. 按需安装经济、PlaceholderAPI、PlayerPoints 等联动插件。
4. 启动服务器并检查后台是否正常启用 LiTitle。
5. 确认 `plugins/LiTitle/` 已生成配置。

首次启动会生成核心、聊天、语言、自动发放、卷轴、称号、商店与 GUI 配置。逐项用途见[配置文件参考](./配置文件参考.md)。

## 升级

1. 停服并备份整个 `plugins/LiTitle/`，数据库用户另行备份数据库。
2. 替换插件 Jar，不要先删除现有配置。
3. 启动后观察配置迁移与警告信息。
4. 对比新增节点，验证商店、仓库、自动称号、昵称和聊天频道。
5. 群组服逐台更新，并保证本地称号 YAML 一致。

LiTitle 会保留已经存在的自定义配置，不用新默认文件整份覆盖。如果某个旧配置确实需要重新生成，应先备份、只删除目标文件、启动生成后再手工合并自定义内容。

## 重载与重启

```text
/lititle reload
/lititle reload all
/lititle reload lang
/lititle reload titles
/lititle reload shop
/lititle reload scroll
```

日常文本或称号调整可以重载。切换存储类型、数据库连接、运行依赖或跨服架构后应完整重启，避免旧连接与缓存继续工作。

## 成品检查

当前构建产物：

```text
target/lltitle-0.1.93-paper-1.21.11-to-26.2-java21.jar
```

`plugin.yml` 应显示版本 `0.1.93` 与 `folia-supported: true`。这项声明不替代实服调度验证，Folia 仍只按上方明确范围部署。
