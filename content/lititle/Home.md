# LiTitle 文档首页

LiTitle `0.1.93` 把称号收集、称号商店、仓库、自动目标、卷轴、聊天颜色、昵称和跨服频道放在同一套系统里。本套文档分别面向玩家与服务器管理员。

## 玩家从这里开始

- [玩家入门](./玩家入门.md)：第一次打开菜单、佩戴称号和设置昵称。
- [称号商店与仓库](./称号商店与仓库.md)：购买、领取、佩戴和卸下称号。
- [自动称号与进阶](./自动称号与进阶.md)：查看目标进度、提交物品和进阶称号。
- [称号卷轴](./称号卷轴.md)：右键解锁、绑定与交易规则。
- [聊天频道与昵称](./聊天频道与昵称.md)：本服、全服、管理、私聊与昵称显示。

## 管理员从这里开始

- [安装与升级](./安装与升级.md)：版本、依赖、首次启动与升级步骤。
- [配置文件参考](./配置文件参考.md)：核心、聊天、语言、称号、卷轴与 GUI 文件。
- [命令与权限](./命令与权限.md)：完整命令、权限与 PlaceholderAPI 变量。
- [存储与跨服](./存储与跨服.md)：SQLite、MySQL、Redis 与 Velocity 部署。
- [常见问题](./常见问题.md)：称号、昵称、聊天颜色和跨服问题排查。

## 当前运行范围

| 项目 | 要求 |
| --- | --- |
| 插件版本 | `0.1.93` |
| Paper | `1.21.11` 至 `26.2` |
| Folia | `26.1.2` 至 `26.2` |
| 插件字节码 | Java 21 |
| 强制前置 | Vault |
| 可选联动 | PlaceholderAPI、PlayerPoints、AttributePlus、MySQL、Redis |
| 代理端 | 推荐 Velocity，不要求 BungeeCord |

> 服务端 Java 版本仍需满足所用服务端核心的要求。LiTitle 使用 Java 21 字节码不代表 Paper 26 可运行在 Java 21 上。

## 推荐阅读顺序

普通玩家依次阅读“玩家入门 → 商店与仓库 → 自动称号 → 聊天与昵称”。服主依次阅读“安装与升级 → 配置文件 → 命令与权限 → 存储与跨服”，再按服务器玩法配置称号。
