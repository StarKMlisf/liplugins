# 称号商店与仓库

商店负责获取称号，仓库负责查看并佩戴已经拥有的称号。服务器可为不同称号配置价格、有效期、显示文本、动态帧、属性与触发动作。

## 玩家操作

```text
/lititle shop
/lititle open
/lititle clear
```

购买成功后，称号会进入玩家仓库。打开仓库并点击称号即可佩戴；卸下不会删除所有权。

## 支持的购买方式

| 类型 | 用途 |
| --- | --- |
| `not` | 免费领取 |
| `vault` | 使用 Vault 金币 |
| `playerPoints` | 使用 PlayerPoints 点券 |
| `permission` | 通过权限判断获取资格 |
| `itemStack` | 使用指定物品购买 |

服务器可把有效天数设为 `0` 表示永久，也可设置为限时称号。具体价格与期限以服务器菜单显示为准。

## 管理员上架与下架

```text
/lititle shop add <称号ID> [价格] [天数]
/lititle shop remove <称号ID>
```

也可以编辑 `plugins/LiTitle/shop_titles/<称号ID>.yml`：

```yaml
enable: true
titleName: "VIP会员"
buyType: "vault"
amount: 1000
day: 0
itemStack: ""
isHide: false
description:
  - "&7VIP 专属称号"
  - "&e价格：1000 金币"
  - "&a购买后永久拥有"
```

修改后执行 `/lititle reload shop`。

## 创建一个基础称号

在 `plugins/LiTitle/titles/` 新建 `vip.yml`：

```yaml
id: "vip"
name: "VIP会员"
display: "&f[ &#FFD966V&#FFB347I&#FF8A3DP &f]"
dynamic:
  enable: false
  interval-ticks: 10
  frames: []
lore:
  - "&7VIP 专属称号"
icon:
  material: "NAME_TAG"
  custom-model-data: 0
permission: "vip.title"
achievements: []
advancements: []
statistics: []
kills: []
advance-from: []
cost:
  vault: 1000
  points: 0
actions:
  on-buy: []
  on-select: []
buffs: []
```

保存后执行 `/lititle reload titles`。管理员也可用 `/lititle give <玩家> vip` 直接发放。
