# 更新日志

## 2.1.0

- 为所有建造完成的棋盘新增 Bukkit 原生 `TextDisplay` 状态全息和 `Interaction` 右击区域，无需额外全息前置。
- 全息实时显示棋盘类型、空闲/等待/进行中/结束状态、`0/2`～`2/2` 玩家人数、双方名字和当前行动玩家。
- 玩家右击空闲棋盘全息会自动创建房间，右击 `1/2` 等待棋盘会直接加入并开始对局。
- 围棋和飞行棋显示“暂未开放自动对局”，不会错误建立不完整的自动房间。
- 全息不强制加载无人区块；棋盘区块重新加载后会自动恢复，并在重载、删除或停服时安全回收。
- 新增全息开关、刷新周期、高度、边缘偏移、点击区域和可视距离配置；旧配置只补全新增节点。
- 配置与消息结构升级到版本 5，帮助和 README 同步加入右击全息玩法。

## 2.0.0

- 将五子棋专用房间重构为多棋类房间，统一 `/cg create/join/leave/resign/list/status`。
- 新增完整中国象棋双人回合：车、马、象、仕、将、炮、兵规则，将帅照面、不能送将、将军、将死和困毙。
- 新增双人军棋回合：公路、铁路、工兵铁路转弯、阻挡、行营保护、大本营禁移、战斗、夺旗和无棋可走判胜。
- 自动房间开始时校准世界棋面，进行中阻止手动放置、快捷回收和原模组手持军棋比较。
- 象棋与军棋每步保存棋面、双方、回合和状态；重启后恢复 CE 棋子，结束后自动恢复初始棋面。
- 旧五子棋 `rooms.yml` 无 `type` 数据自动按 `gomoku` 迁移。
- 共用结束展示与离线判负设置迁移到 `games` 节点，保留旧管理员自定义值。
- 新增象棋马腿/炮架/过河兵/将帅照面和军棋铁路/行营/大本营/序列化规则自检。

## 1.2.1

- 修正自动摆放棋子的前后朝向：近侧棋子朝向创建者，远侧棋子朝向棋盘另一端玩家。
- 新增象棋将/帅与军棋双方军旗朝向自测。
- 文档明确当前军棋采用标准双人红黑双方，不需要第三名玩家；当前阶段为手动移动和自动比较棋子。

## 1.2.0

- 新建棋盘默认以准星目标方块为中心，不再把目标点当作棋盘角落；可在配置中切回旧行为。
- 新建中国象棋棋盘时自动摆放标准 32 枚开局棋子，并随玩家朝向正确旋转。
- 新建军棋棋盘时自动摆放双方各 25 枚棋子的合法预设阵型；军旗位于大本营、地雷位于后两排、行营保持为空。
- 新增 `/cg arena setup <名称>`，可给已有的空象棋或军棋棋盘分批补摆开局棋子。
- 自动建盘、开局摆棋与失败回滚共用每 tick 放置预算；棋子层非空时拒绝覆盖。
- CE 资源自检新增全部象棋和军棋开局方块，帮助、Tab 补全、权限说明和配置迁移同步更新。
- 新增目标点居中四向换算、象棋坐标、军棋数量/行营/大本营/地雷规则自测。

## 1.1.0

- 新增 `/cg arena create <名称> <类型> [尺寸]`，支持 gomoku、weiqi、xiangqi、junqi 和 flight。
- 按 Jissee/Chess 上游官方 NBT 结构还原 19×19 围棋、10×9 象棋、13×5 军棋和 31×31 飞行棋布局。
- 新增 CE 方块朝向随玩家方向旋转，飞行棋原版羊毛与 CE 连接方块混合分批放置。
- 新增棋盘类型、长宽持久化；旧 `size` 棋盘自动按五子棋迁移。
- 新增所有棋盘的区域保护、删除清理、类型列表、帮助和 Tab 补全。
- 资源自检扩展为检查所有自动棋盘所需 CE 方块。
- 新增官方布局尺寸、坐标唯一性、类型别名和朝向旋转自测。
