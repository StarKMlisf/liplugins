# 安装与更新

## 运行要求

- Java 25
- Paper `26.1.2`
- CraftEngine `26.7.4` 或兼容版本
- `Jissee-Chess-CE-1.0.3` 配套资源

Vault 和 PlaceholderAPI 为可选软依赖，当前不会强制安装。

## 安装

1. 解压 `Jissee-Chess-CE-1.0.3.zip`。
2. 将其中的 `resources/chess` 复制到 `plugins/CraftEngine/resources/chess`。
3. 将 JisseeChessGames Jar 放入 `plugins/`。
4. 完整重启服务器，不使用第三方热加载器。
5. 在控制台执行 `/cg validate`，检查五类棋盘、棋子和骰子所需 CE 方块。

## 更新

1. 停服并备份插件配置、`arenas.yml`、`rooms.yml` 和 CraftEngine 资源。
2. 替换 Jar 与配套资源。
3. 完整启动，先执行 `/cg validate`。
4. 用 `/cg arena list`、`/cg list` 检查棋盘与房间。
5. 在测试棋盘完成一次落子、重启与恢复验证。

升级只补充缺失配置节点，不覆盖管理员已有值。活动对局每次落子后保存，正常重启后会恢复棋面。
