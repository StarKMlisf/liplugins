# 配置、保护与持久化

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `config.yml` | 棋盘居中、开局棋子、自动房间、CE ID、保护、骰子和适配 |
| `messages.yml` | 所有玩家消息，支持 MiniMessage、RGB 和渐变 |
| `arenas.yml` | 已注册棋盘的位置、方向、类型和尺寸 |
| `rooms.yml` | 房间、双方 UUID、回合和每格棋子 |

插件升级只补齐缺失节点，不覆盖现有自定义值。

## 棋盘保护

自动棋盘区域会阻止普通玩家破坏、放置、爆炸和活塞影响。自动房间还会锁定棋子层，防止镐回收、手动放置或军棋比较干扰对局。

非五子棋棋盘在无房间时允许在棋子层手动放置匹配的 CE 棋子。管理员可用 `jisseechessgames.protection.bypass` 绕过玩家操作保护。

## 房间保存

活动对局在每次落子后写入 `rooms.yml`。正常停服和重启会恢复双方、回合和棋面；不要在服务器运行时手工编辑房间文件。

删除棋盘前先确认没有等待或进行中的房间。修改全息配置后可用 `/cg reload` 安全重建显示实体。
