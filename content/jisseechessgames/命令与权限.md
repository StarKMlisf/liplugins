# 命令与权限

主指令为 `/cg`，别名 `/qgame`。全部子命令都有 Tab 参数联想。

## 玩家与查询

| 指令 | 权限 |
| --- | --- |
| `/cg help` | `jisseechessgames.use` |
| `/cg create <房间> <棋盘>` | `jisseechessgames.play` |
| `/cg join <房间>` | `jisseechessgames.play` |
| `/cg leave`、`/cg resign` | `jisseechessgames.play` |
| `/cg list` | `jisseechessgames.use` |
| `/cg status [房间]` | `jisseechessgames.use` |
| `/cg dice` | `jisseechessgames.dice` |
| `/cg arena types`、`arena list` | `jisseechessgames.use` |

## 棋盘与管理

| 指令 | 权限 |
| --- | --- |
| `/cg arena create <名称> <类型> [尺寸]` | `jisseechessgames.arena.admin` |
| `/cg arena setup <名称>` | `jisseechessgames.arena.admin` |
| `/cg arena delete <名称>` | `jisseechessgames.arena.admin` |
| `/cg arena tp <名称>` | `jisseechessgames.arena.admin` |
| `/cg stop <房间>` | `jisseechessgames.admin` |
| `/cg reload` | `jisseechessgames.admin` |
| `/cg validate` | `jisseechessgames.admin` |

`jisseechessgames.protection.bypass` 允许管理员绕过棋盘区域的玩家破坏与放置保护，请只授予可信管理人员。
