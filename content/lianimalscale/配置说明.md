# LiAnimalScale 配置说明

## 默认结构

```yml
settings:
  target-distance: 12.0
  minimum-scale: 1.0
  maximum-scale: 16.0
  default-scale: 3.0

auto-scale:
  enabled: true
  apply-loaded-on-enable: true
  scale: 3.0
  list-mode: BLACKLIST
  entity-types: []
```

## 目标与范围

- `target-distance`：准星检测距离，范围 1–64 方块。
- `minimum-scale`：命令允许的最小倍率。
- `maximum-scale`：命令允许的最大倍率，不能小于最小值。
- `default-scale`：`set` 或 `applyloaded` 省略参数时使用。

倍率会自动限制在配置范围内。

## 自动处理

- `enabled`：是否处理之后生成的动物。
- `apply-loaded-on-enable`：启用时是否扫描全部已加载动物。
- `scale`：自动处理倍率。
- `list-mode`：`BLACKLIST` 或 `WHITELIST`。
- `entity-types`：Bukkit 实体类型名列表。

大型服务器可关闭启动扫描，避免一次处理大量已加载实体。

## 消息

`messages.yml` 保存玩家提示并支持 MiniMessage。修改后执行 `/animalscale reload`。消息重载不会改变任何实体倍率。

## 修改验证

先用单只动物测试最小、默认和最大倍率，再决定是否开启全服自动处理。
