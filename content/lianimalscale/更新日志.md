# 更新记录

## 1.1.0

- 基准版本下调至 Minecraft `1.21.11`，成品改为 Java 21 字节码。
- 同一个 Jar 支持 Paper、Folia、Luminol `1.21.11+`，并兼容 `26.1.2`。
- `plugin.yml` 的 `api-version` 调整为 `1.21.11`，保留 `folia-supported: true`。
- 新增 Luminol 平台名称识别，启动日志会显示 `Luminol (Folia)`。
- Maven 新增 `luminol-compat` 构建配置，可使用 Luminol 官方 1.21.11 API 编译整套源码。
- `lib/` 新增 Paper 与 Luminol 1.21.11 API 备份。
- Paper 1.21.11 实测自动 `3x`、批量 `4x`、配置热重载及服务器 reload。
- Folia 1.21.11 实测自动 `3x`、批量 `5x`、配置热重载及新类加载器单插件热加载。

## 1.0.1

- 正式声明并实现 Folia 26.1.2 支持。
- 新增统一 Paper/Folia 调度层。
- 单体动物操作通过 EntityScheduler 在目标实体所属区域执行。
- 批量扫描通过 GlobalRegionScheduler 收集实体，再逐个派发到实体区域。
- 新增 EntitiesLoadEvent 补处理，兼容 Folia 各区域的区块实体加载时序。
- 配置改为不可变快照，支持多区域线程并发读取。
- `/animalscale reload` 改为异步文件读取与安全回执。
- 插件停用时主动注销监听器、停止接收新任务并取消剩余任务。
- 增加 Paper build 74 与 Folia build 8 的属性默认值二进制兼容桥。
- Paper 服务器级热重载后可正常重新启用，无重复监听器或残留任务。
- Folia 已验证旧实例卸载、新类加载器载入的新实例热加载流程。
- 明确禁止在 Folia 使用其平台不支持的服务器级 `bukkit:reload`。

## 1.0.0

- 首个可用版本。
- 支持自动缩放、单体设置、恢复、查询及批量缩放动物。
- 提供完整中文配置、MiniMessage 消息、权限和 Tab 补全。
