# LiAnimalScale 故障排查

## 插件没有启用

- 检查 Java 与服务端版本。
- 查看启动日志中的 `plugin.yml`、类加载或属性错误。
- 确认 JAR 没有重复版本。

## 提示没有对准动物

- 靠近目标并把准星对准实体主体。
- 检查 `target-distance`。
- 墙壁会阻挡检测。
- 插件只处理动物范围，不处理玩家或任意怪物。

## 倍率被拒绝

输入值超出 `minimum-scale` 与 `maximum-scale`。同时不能超出 Minecraft 原生属性范围 0.0625–16。

## 关闭自动缩放后旧动物仍然很大

这是预期行为。关闭只停止之后的自动处理，已保存的原生属性仍在。使用 `reset` 或 `applyloaded` 主动恢复。

## 修改配置没有变化

执行 `/animalscale reload`，检查 YAML 和控制台。已经加载的旧实体不会因为重载自动重算。

## 启动时短暂卡顿

如果世界中已加载动物很多，关闭 `auto-scale.apply-loaded-on-enable`，再观察差异。诊断时区分一次性实体扫描与持续服务器卡顿。
