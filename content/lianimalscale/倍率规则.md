# LiAnimalScale 倍率与自动缩放规则

## 原生 SCALE 属性

LiAnimalScale 直接修改 Minecraft 的原生 `SCALE` 属性，不创建额外展示实体。模型、碰撞箱和交互范围会随原生属性一起变化。

## 倍率范围

Minecraft 属性可接受 `0.0625` 至 `16.0`。插件还会使用配置中的 `minimum-scale` 和 `maximum-scale` 限制管理命令。

- `1.0`：原生大小。
- 大于 `1.0`：放大。
- 小于 `1.0`：缩小，前提是最小倍率允许。

## 自动缩放

```yml
auto-scale:
  enabled: true
  apply-loaded-on-enable: true
  scale: 3.0
  list-mode: BLACKLIST
  entity-types: []
```

`enabled` 控制之后生成的动物；`apply-loaded-on-enable` 控制插件启动时是否扫描当前已加载实体。

## 白名单与黑名单

- `BLACKLIST`：列表里的动物不自动缩放。
- `WHITELIST`：只处理列表里的动物。

只处理牛：

```yml
auto-scale:
  list-mode: WHITELIST
  entity-types:
    - COW
```

实体类型使用 Bukkit `EntityType` 英文名，不区分大小写。

## 持久化

原生属性会随实体保存。区块重新加载或服务器重启后，已经保存的倍率仍可能保留。因此关闭功能不等于恢复历史实体。
