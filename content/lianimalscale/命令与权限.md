# LiAnimalScale 命令与权限

## 指令

| 指令 | 说明 |
| --- | --- |
| `/animalscale help` | 查看帮助 |
| `/animalscale get` | 查询准星目标的倍率 |
| `/animalscale set [倍率]` | 设置单只动物倍率 |
| `/animalscale reset` | 恢复单只动物默认倍率 |
| `/animalscale applyloaded [倍率]` | 批量修改当前已加载动物 |
| `/animalscale reload` | 重载配置和消息 |

别名：`/as`、`/animalgiant`、`/动物缩放`。子命令和倍率参数都有 Tab 补全，并按权限过滤。

## 权限

| 权限 | 默认 | 说明 |
| --- | --- | --- |
| `lianimalscale.command` | 所有人 | 使用主指令和帮助 |
| `lianimalscale.get` | 所有人 | 查询目标倍率 |
| `lianimalscale.set` | OP | 设置单体倍率 |
| `lianimalscale.reset` | OP | 恢复单体倍率 |
| `lianimalscale.applyloaded` | OP | 批量处理已加载动物 |
| `lianimalscale.reload` | OP | 重载配置 |
| `lianimalscale.admin` | OP | 包含全部权限 |

## 安全建议

不要把 `applyloaded` 直接开放给普通玩家。最大倍率 `16.0` 会显著改变碰撞和视野遮挡，应先在测试区验证。
