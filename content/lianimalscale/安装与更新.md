# LiAnimalScale 安装与更新

## 兼容范围

- Paper / Folia / Luminol
- Minecraft 1.21.11+，本站基准包含 26.1.2
- Java 21+
- 无强制前置插件

## 首次安装

1. 停止服务器。
2. 将 JAR 放入 `plugins/`。
3. 完整启动，等待 `config.yml` 和 `messages.yml` 生成。
4. 检查自动缩放是否应该默认开启。
5. 用一只测试动物执行 `/as get`、`/as set 2`、`/as reset`。

## 更新

1. 备份插件目录和测试世界。
2. 替换 JAR，保留现有配置。
3. 启动后检查新节点是否补全。
4. 验证新生成动物和已加载动物的行为。

## 热加载说明

插件提供自己的 `/animalscale reload` 用于配置重载。不要使用 PlugMan 等第三方工具替换版本更新；实体属性、监听器和调度器需要正常的停用与启用生命周期。

## 回退

如果需要移除插件，先决定是否保留动物当前倍率。要恢复已加载动物，可在停用前使用批量命令；未加载区块中的实体要等区块加载后再处理。
