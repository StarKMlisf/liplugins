# LiAnimalScale 玩家与管理操作

## 选择目标

把准星对准检测距离内的一只动物。墙壁等实体方块会阻挡检测，插件不会隔墙修改实体。

## 查询倍率

```text
/animalscale get
```

命令会显示当前倍率和该实体的原生默认倍率。主指令也可以使用 `/as`、`/animalgiant` 或 `/动物缩放`。

## 设置和恢复

```text
/animalscale set [倍率]
/animalscale reset
```

省略倍率时使用 `settings.default-scale`。`reset` 会恢复目标动物的原生默认倍率。

这些修改默认需要管理权限。普通玩家默认只能查看帮助和查询倍率。

## 批量处理

```text
/animalscale applyloaded [倍率]
```

该命令处理所有世界当前已经加载的动物，不受自动缩放白名单或黑名单限制。正式服执行前先估算实体数量，并在低峰期操作。

## 注意事项

- 重载配置不会自动恢复已经修改的动物。
- 关闭自动缩放只影响之后的自动处理，不会回滚旧实体。
- 需要恢复大量实体时，可以使用 `applyloaded 1`，但应先确认原生默认倍率是否统一为 1。
