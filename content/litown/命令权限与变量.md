# 管理命令、权限与变量

## 管理员命令

需要权限：`litown.admin.manage`

| 命令 | 说明 |
| --- | --- |
| `/litown admin list` | 查看全部小镇 |
| `/litown admin info <小镇ID>` | 查看指定小镇数据 |
| `/litown admin disband <小镇ID>` | 强制解散小镇 |
| `/litown admin addrep <小镇ID> <数量>` | 增加声望 |
| `/litown admin addmaterial <小镇ID> <数量>` | 增加材料点 |
| `/litown admin addexp <小镇ID> <数量>` | 增加小镇经验 |
| `/litown admin repair` | 修复孤儿成员、无效任务进度和冷却 |
| `/litown admin migrate sqlite` | 将 YAML 数据迁移到 SQLite |
| `/litown admin migrate mysql` | 将 YAML 数据迁移到 MySQL |
| `/litown admin backup sqlite` | 备份 SQLite 数据库 |
| `/litown reload` | 重载配置 |

## 权限节点

| 权限 | 默认 | 说明 |
| --- | --- | --- |
| `litown.command` | true | 允许使用 `/litown` |
| `litown.create` | true | 允许创建小镇 |
| `litown.admin.reload` | op | 允许重载插件 |
| `litown.admin.manage` | op | 允许使用管理员命令 |

旧版 `adventuretown.*` 权限仍可使用，建议权限组逐步改为 `litown.*`。

## 职位权限

职位配置文件：`roles.yml`

职位权限是小镇内部权限，不是 Bukkit 权限节点。

默认职位：

- `mayor`：镇长
- `deputy`：副镇长
- `captain`：远征队长
- `artisan`：工匠
- `adventurer`：冒险者
- `trainee`：见习者

常用职位权限：

| 权限 | 说明 |
| --- | --- |
| `invite` | 邀请成员 |
| `kick` | 踢出成员 |
| `set_home` | 设置小镇传送点 |
| `manage_roles` | 管理职位 |
| `edit_notice` | 编辑公告 |
| `use_home` | 使用小镇传送 |
| `accept_quest` | 接取委托 |
| `submit_quest` | 提交委托 |
| `start_raid` | 开启袭击 |
| `stop_raid` | 停止袭击 |
| `use_chat` | 使用小镇聊天 |
| `use_warehouse` | 使用共享仓库 |
| `withdraw_bank` | 从小镇金库取款 |
| `send_red_packet` | 发送镇民红包 |
| `challenge_competition` | 发起小镇竞赛 |
| `accept_competition` | 接受或退出小镇竞赛 |

## PlaceholderAPI

安装 PlaceholderAPI 后，插件会注册变量扩展。变量用于显示小镇、排行、任务、袭击、成就等信息。
新变量前缀为 `%litown_*%`，旧 `%adventuretown_*%` 前缀继续兼容。

入镇申请数量变量：

```text
%litown_pending_applications%
%litown_available_contribution%
```

具体变量请以当前服务器安装版本注册结果为准。
