# 存储、备份与故障排查

## 数据迁移

### YAML 迁移到 SQLite

```text
/litown admin migrate sqlite
```

迁移后将 `config.yml` 改为：

```yaml
storage:
  type: "sqlite"
```

然后重启服务器。

### YAML 迁移到 MySQL

先配置 MySQL 连接信息，然后执行：

```text
/litown admin migrate mysql
```

迁移后将 `config.yml` 改为：

```yaml
storage:
  type: "mysql"
```

然后重启服务器。

### SQLite 备份

```text
/litown admin backup sqlite
```

备份文件会生成到：

```text
plugins/LiTown/backups/
```

## 常见问题

### 为什么不能开启袭击？

常见原因：

- 玩家没有加入小镇。
- 小镇没有设置传送点。
- 小镇等级不足。
- 袭击正在冷却。
- 当前小镇已有进行中的袭击。
- `raids.yml` 没有配置波次。

### 袭击怪物为什么没有生成？

检查：

- 小镇是否执行过 `/litown sethome`。
- `spawn-min-radius` 和 `spawn-max-radius` 是否过小。
- 刷新范围是否在海面、树叶、封闭洞穴或保护区内。
- MythicMobs 怪物 ID 是否正确。
- `config.yml` 中 `raid.mythicmobs-enabled` 是否为 `true`。

### 任务为什么不能接？

检查：

- 玩家是否加入小镇。
- 职位是否有 `accept_quest` 权限。
- 是否已有进行中的委托。
- 是否处于提交或放弃冷却。
- 每日/周常任务池是否限制了当前可接任务。

### 经济没有扣费或奖励？

检查：

- 是否安装 Vault。
- 是否安装经济插件。
- Vault 是否能正确识别经济插件。

## 配置重载建议

可以使用：

```text
/litown reload
```

但以下变更建议重启服务器：

- 切换数据存储类型。
- 修改 MySQL 连接信息。
- 修改运行时依赖下载配置。
- 大规模调整任务或袭击配置。
