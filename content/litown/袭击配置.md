# 小镇袭击配置

## raids.yml 说明

袭击以小镇 `/litown sethome` 设置的位置为中心，怪物在小镇周围环形范围内刷新。

上一波怪物全部清完后，才会生成下一波。

## BossBar 进度条（1.1.2）

默认显示“袭击名｜第 2/3 波｜剩余 5 只”，每秒更新。进度条表示本波剩余怪物比例，只展示给同世界、袭击开始据点 96 格内的本镇在线成员。离开范围、停止、失败、胜利和重载时移除；重新进入范围会恢复显示。中途修改传送点不会移动本场袭击的据点。

以下配置位于 `raids.yml` 根级，与 `raids` 同级。升级时缺失配置及中文注释自动补齐，已有自定义值保留。

```yaml
# 袭击进度条配置，仅向符合条件的本镇成员展示。
progress-bar:
  # 是否开启；true 开启，false 关闭。
  enabled: true
  # 标题支持 MiniMessage、RGB 和旧 & 颜色，可填任意文本及下方占位符。
  title: "<red>{raid}</red> <gray>|</gray> <gold>第 {wave}/{max} 波</gold> <gray>|</gray> <yellow>剩余 {remaining} 只</yellow>"
  # 颜色：PINK、BLUE、RED、GREEN、YELLOW、PURPLE、WHITE；错误值回退 RED。
  color: RED
  # 样式：SOLID、SEGMENTED_6、SEGMENTED_10、SEGMENTED_12、SEGMENTED_20；错误值回退 SOLID。
  style: SOLID
  # 同世界内可见半径，0～4096 方块；0 表示同世界不限制距离。
  view-distance: 96.0
```

| 标题占位符 | 含义 |
| --- | --- |
| `{raid}` / `{town}` | 袭击名称 / 小镇名称 |
| `{wave}` / `{max}` | 当前波次 / 总波数 |
| `{remaining}` / `{wave_size}` | 本波剩余怪数 / 本波总怪数 |
| `{remaining_waves}` | 尚未开始的波数 |

## 波次、首领与奖励

示例：

```yaml
raids:
  goblin_raid:
    display-name: "荒野哥布林袭击"
    min-town-level: 1
    spawn-min-radius: 14
    spawn-max-radius: 28
    spawn-location-tries: 16
    mob-name: "&c荒野袭击者"
    fail-safety-penalty: 10
    fail-reputation-penalty: 1
    fail-money-penalty: 100.0
    wave-clear-check-seconds: 5
    wave-timeout-seconds: 300
    reward-town-exp: 30
    reward-reputation: 2
    reward-material-points: 20
    contribution-per-kill: 2
    contribution-per-100-damage: 1
    min-contribution-for-reward: 1
    reward-commands: []
    participant-reward-commands: []
    waves:
      1:
        entities:
          - "ZOMBIE:6"
          - "SKELETON:3"
        mythic-mobs: []
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `display-name` | 游戏内显示名称 |
| `min-town-level` | 开启所需小镇等级 |
| `spawn-min-radius` | 最小刷新半径 |
| `spawn-max-radius` | 最大刷新半径 |
| `spawn-location-tries` | 寻找安全刷新点的尝试次数 |
| `mob-name` | 袭击怪物显示名 |
| `fail-safety-penalty` | 失败扣安全度 |
| `fail-reputation-penalty` | 失败扣声望 |
| `fail-money-penalty` | 失败扣小镇资金 |
| `wave-clear-check-seconds` | 检查当前波次是否清完的间隔 |
| `wave-timeout-seconds` | 单波超时时间，`0` 表示不限制已生成怪物的战斗时间；未完成的生成等待最多 30 秒，若本项配置更短则取更短值 |
| `reward-town-exp` | 胜利奖励小镇经验 |
| `reward-reputation` | 胜利奖励声望 |
| `reward-material-points` | 胜利奖励材料点 |
| `contribution-per-kill` | 每击杀 1 只袭击怪给多少贡献 |
| `contribution-per-100-damage` | 每造成 100 点伤害给多少贡献 |
| `min-contribution-for-reward` | 获得参与奖励的最低贡献 |
| `reward-commands` | 小镇胜利后执行的控制台命令 |
| `participant-reward-commands` | 给参与玩家执行的控制台命令 |

### 原版怪物波次

```yaml
waves:
  1:
    entities:
      - "ZOMBIE:6"
      - "SKELETON:3"
```

格式：

```text
实体类型:数量
```

### MythicMobs 波次

需要安装 MythicMobs，并在 `config.yml` 中开启：

```yaml
raid:
  mythicmobs-enabled: true
```

配置示例：

```yaml
waves:
  1:
    mythic-mobs:
      - "GoblinWarrior:4"
      - "GoblinArcher:2"
```

格式：

```text
MythicMobID:数量
```

### Boss 波次

```yaml
waves:
  3:
    entities:
      - "HUSK:6"
    boss:
      enabled: true
      type: "ZOMBIE"
      mythic-mob: ""
      name: "&4哥布林头目"
      health: 120.0
      drops:
        - "IRON_INGOT:3"
```

如果 `mythic-mob` 不为空，会优先生成 MythicMobs Boss。

## 停止与清理

1.1.2 修复卡波、停止后续刷与重复结算。当前袭击结束后，旧定时任务不能再推进波次或给新袭击结算；停止、失败和插件重载会清理对应怪物与 BossBar。临时袭击怪不会自然消失，也不会写入世界存档。

停止袭击仍遵循服主配置的失败惩罚和冷却，不会自动清除冷却。更换插件 Jar 需完整停服、替换后再启动，不能只执行 `/litown reload`。
