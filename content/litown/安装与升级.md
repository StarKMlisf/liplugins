## 依赖

- Vault 与经济插件：使用金币扣费、奖励和红包时需要。
- PlaceholderAPI：可选，用于变量输出。
- MythicMobs：可选，仅在袭击配置使用对应自定义怪物时需要。
- MiniMessage 与 legacy serializer：由 Bukkit `libraries` 声明在启动时下载。
- SQLite / MySQL 驱动：按 `dependencies.yml` 下载到 `plugins/LiTown/lib/`，不打进插件 Jar。

Vault、PlaceholderAPI、MythicMobs 是独立插件，应按各自说明放入服务器 `plugins/` 目录。

## 首次安装

1. 将 `LiTown-1.1.1.jar` 放入服务器 `plugins/` 目录，并按玩法需要准备可选前置。
2. 完整启动服务器，检查日志确认加载版本和运行库状态。
3. 插件自动生成带中文注释的配置。调整配置后执行 `/litown reload`；更换存储后完整重启。
4. 创建测试小镇，设置 `/litown sethome`，检查菜单、经济和袭击配置后再供玩家使用。

## 从旧版升级

1. 停服，备份旧 Jar 和完整 `plugins/LiTown/` 数据目录；仍使用旧名称时同时备份 `plugins/AdventureTownGuild/`。
2. 移走 `plugins/` 内旧 LiTown / AdventureTownGuild Jar，放入新版，确保没有重复插件文件。
3. 保留已有配置和数据，完整启动。旧 AdventureTownGuild 目录中缺失的数据会复制到 LiTown，不删除旧目录。
4. 新增配置项和中文注释自动补齐，不覆盖已有菜单、价格、语言或自定义值。不要把默认配置目录直接覆盖到生产配置。
5. 查看日志确认加载 1.1.1，验证本服任务、经济和袭击。升级 Jar 需要完整重启，`/litown reload` 仅重载配置。
