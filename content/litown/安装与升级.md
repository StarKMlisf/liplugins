# 安装与升级

当前版本为 **LiTown 小镇公会 1.1.2**。本次直接验证环境是 Paper 26.2 build 134 和自编译 Folia 26.2 build 5，均使用 Java 25；Folia 验证限于袭击专项。插件使用 Bukkit 标准 API，编译字节码基线 Java 21，服务器使用的 Java 版本还需满足核心要求。

## 依赖

- Vault 与经济插件：使用金币扣费、奖励和红包时需要。
- PlaceholderAPI：可选，用于变量输出。
- MythicMobs：可选，仅在袭击配置使用对应自定义怪物时需要。
- MiniMessage 与 legacy serializer：由 Bukkit `libraries` 声明在启动时下载。
- SQLite / MySQL 驱动：按 `dependencies.yml` 下载到 `plugins/LiTown/lib/`，不打进插件 Jar。

Vault、PlaceholderAPI、MythicMobs 是独立插件，应按各自说明放入服务器 `plugins/` 目录。

## 首次安装

1. 将 `LiTown-1.1.2.jar` 放入服务器 `plugins/` 目录，并按玩法需要准备可选前置。
2. 完整启动服务器，检查日志确认加载版本和运行库状态。
3. 插件自动生成带中文注释的配置。调整配置后执行 `/litown reload`；更换存储后完整重启。
4. 创建测试小镇，设置 `/litown sethome`，检查菜单、经济和袭击配置后再供玩家使用。

## 从旧版升级

1. 停服，备份旧 Jar 和完整 `plugins/LiTown/` 数据目录；仍使用旧名称时同时备份 `plugins/AdventureTownGuild/`。
2. 移走 `plugins/` 内旧 LiTown / AdventureTownGuild Jar，放入新版，确保没有重复插件文件。
3. 保留已有配置和数据，完整启动。旧 AdventureTownGuild 目录中缺失的数据会复制到 LiTown，不删除旧目录。
4. 新增配置项和中文注释自动补齐，不覆盖已有菜单、价格、语言或自定义值。不要把默认配置目录直接覆盖到生产配置。
5. 查看日志确认加载 1.1.2，验证本服任务、经济和袭击。升级 Jar 需要完整重启，`/litown reload` 仅重载配置。

1.1.2 会在 `raids.yml` 补齐缺失的 `progress-bar` 配置及中文注释。保留已有袭击名称、奖励、怪物数量和其他自定义值，进度条配置见[袭击配置](袭击配置.md)。

## 本次验证

- 35 项 JUnit 测试通过，0 失败 / 错误，包含故意取消任务失败、旧回调重放、停止后新会话隔离和配置保留。
- 同一份 1.1.2 Jar 在 Paper 26.2 build 134 / Java 25 隔离服通过 82 项袭击检查。
- 自编译 Folia 26.2 build 5（`codex/folia-26.2`）/ Java 25 隔离服通过 93 项袭击专项检查。
- 覆盖真实三波实体与死亡事件、每场只结算一次、停止与插件重载后跨多个周期不续刷、BossBar 标题/数量/进度/清理，以及远区实体死亡和实际清理。
- 每个平台包含三波防守胜利和远区单波胜利两场成功袭击，因此奖励命令总计 2 次，每场仅 1 次。

玩家及 BossBar 收件人为模拟对象；本次没有真人客户端视觉验收、实际 Vault 经济插件结算、MythicMobs 实体或 MySQL 连接测试。Folia 结果仅限袭击专项，也不扩大为其他核心版本的实测证明。

历史 1.1.1 的 20 项 JUnit 和 Paper 26.2 的 521 项断言另见[更新日志](更新日志.md)，包含五类列表各 35 条记录的分页、真实库存扣物、离线申请审核与红包业务。该记录属于 1.1.1，不作为 1.1.2 的重复运行结果。
