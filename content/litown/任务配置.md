# 委托任务配置

## quests.yml 说明

任务类型：

- `KILL`：击杀任务。
- `GATHER`：采集任务。
- `EXPLORE`：探索任务。

示例：

```yaml
quests:
  slime_hunt:
    display-name: "清理史莱姆"
    type: "KILL"
    target: "SLIME"
    amount: 8
    reward-money: 120.0
    reward-exp: 5
    reward-items:
      - "BREAD:2"
    contribution: 10
    material-points: 5
    shared: false
    submit-cooldown-seconds: -1
    abandon-cooldown-seconds: -1
    reward-commands: []
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `display-name` | 游戏内显示名称，推荐中文 |
| `type` | 任务类型 |
| `target` | 目标实体、方块或探索坐标 |
| `amount` | 目标数量 |
| `reward-money` | 完成奖励金币 |
| `reward-exp` | 完成奖励玩家经验 |
| `reward-items` | 完成奖励物品，格式 `材料:数量` |
| `contribution` | 完成后给成员的贡献 |
| `material-points` | 完成后给小镇的材料点 |
| `shared` | 是否全小镇共享进度 |
| `submit-cooldown-seconds` | 提交后冷却，`-1` 表示使用默认配置 |
| `abandon-cooldown-seconds` | 放弃后冷却，`-1` 表示使用默认配置 |
| `reward-commands` | 完成后执行控制台命令 |

探索任务 `target` 格式：

```text
世界名;x;y;z;半径
```

例如：

```yaml
target: "world;0;64;0;20"
```
