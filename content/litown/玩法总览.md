# 小镇玩法与玩家命令

## 已包含功能

- 小镇创建、解散、转让。
- 成员邀请、踢出、离开、查看成员。
- 入镇申请、离线审核、申请过期清理和申请 GUI。
- 可配置物资贡献、贡献 GUI 和按贡献自动晋升职位。
- 小镇金库：资金捐入、余额查看、存款贡献奖励，以及可选的职位取款权限。
- 54 格小镇共享仓库，支持禁放材料、名称和 Lore 规则。
- 镇民随机红包，每人限领一次并按小镇隔离。
- 镇民个人友伤保护开关。
- 小镇竞赛：挑战、接受、限时击杀积分、冷却与获胜奖励。
- 贡献商店：可用贡献消费、小镇等级门槛、物品与命令奖励。
- 小镇公告和小镇日志。
- 小镇传送点 `/litown sethome`、传送 `/litown home`。
- 职位权限配置。
- 小镇聊天频道。
- 委托任务：击杀、采集、探索。
- 个人任务和共享小镇任务。
- 每日任务池、周常任务池。
- 任务提交冷却、放弃冷却。
- 小镇袭击，支持原版实体和 MythicMobs。
- 袭击按波次生成，上一波清完才生成下一波。
- 袭击怪物围绕小镇传送点刷新，不使用服务器出生点。
- GUI 菜单：小镇管理、成员、任务、袭击、金库、仓库、红包、PVP、竞赛、贡献商店、排行榜、成就和管理员入口；所有菜单标题与展示布局均可配置。
- 小镇排行榜缓存。
- 小镇总览 GUI：查看全部小镇，支持创建时间、等级、声望排序和分页。
- 成员总览 GUI：显示玩家皮肤头颅，支持加入时间、职位、贡献排序和分页。
- 小镇等级图标：不同等级可配置独立材质、名称、Lore 和资源包模型数据。
- 小镇成就。
- YAML、SQLite、MySQL 数据存储。
- YAML 迁移 SQLite / MySQL。
- SQLite 备份。
- 管理员数据修复。

## 不包含的功能

以下功能已经按当前设计删除或不再显示：

- 领地菜单。
- 外交系统。
- 领地争夺或建筑破坏型战争。`/litown competition` 仅为和平向积分竞赛。

## 常用玩家命令

| 命令 | 说明 |
| --- | --- |
| `/litown help` | 查看帮助 |
| `/litown gui` | 打开小镇 GUI 菜单 |
| `/litown create <名称>` | 创建小镇 |
| `/litown info` | 查看自己的小镇信息 |
| `/litown list` | 查看小镇列表 |
| `/litown invite <玩家>` | 邀请玩家加入小镇 |
| `/litown accept` | 接受小镇邀请 |
| `/litown apply <小镇名称>` | 提交入镇申请 |
| `/litown application list` | 查看待审核申请 |
| `/litown application accept <玩家>` | 同意入镇申请 |
| `/litown application deny <玩家>` | 拒绝入镇申请 |
| `/litown kick <玩家>` | 踢出成员 |
| `/litown leave` | 离开小镇 |
| `/litown disband` | 解散小镇 |
| `/litown transfer <玩家>` | 转让镇长 |
| `/litown members` | 查看成员 |
| `/litown gui towns [created\|level\|reputation] [页码]` | 打开小镇总览并选择排序方式 |
| `/litown gui members [joined\|role\|contribution] [页码]` | 打开成员总览并选择排序方式 |
| `/litown role <玩家> <职位>` | 设置成员职位 |
| `/litown notice <内容>` | 设置小镇公告 |
| `/litown log` | 查看小镇日志 |
| `/litown sethome` | 设置小镇传送点 |
| `/litown home` | 传送到小镇传送点 |
| `/litown chat <内容>` | 发送小镇聊天 |
| `/litown contribute` | 查看个人贡献 |
| `/litown contributiontop` | 查看贡献排行 |
| `/litown supply [项目] [组数]` | 打开物资贡献菜单或直接提交物资 |
| `/litown bank [balance\|deposit <金额>\|withdraw <金额>]` | 打开金库或存取资金 |
| `/litown warehouse` | 打开小镇共享仓库 |
| `/litown redpacket [list [页码]\|send <总金额> <份数>\|claim <ID>]` | 镇民红包 |
| `/litown pvp [menu\|status\|toggle]` | 个人镇民友伤设置 |
| `/litown competition [challenge <小镇>\|accept\|status\|surrender]` | 小镇积分竞赛 |
| `/litown shop [list [页码]\|preview <商品ID>\|buy <商品ID>]` | 贡献商店 |
| `/litown achievements` | 查看小镇成就 |

## 任务命令

| 命令 | 说明 |
| --- | --- |
| `/litown quest` | 查看可接委托 |
| `/litown quest accept <委托名>` | 接取委托 |
| `/litown quest info` | 查看当前委托进度 |
| `/litown quest submit` | 提交已完成委托 |
| `/litown quest abandon` | 放弃当前委托 |

任务 ID 可以在 `quests.yml` 中配置。菜单使用中文 `display-name` 展示；任务与袭击参数补全使用内部 ID，避免名称中的空格或颜色影响执行。

## 袭击命令

| 命令 | 说明 |
| --- | --- |
| `/litown raid list` | 查看可开启袭击 |
| `/litown raid info` | 查看当前袭击状态 |
| `/litown raid start <袭击名>` | 开启袭击 |
| `/litown raid stop` | 停止当前袭击 |

袭击需要小镇设置传送点：

```text
/litown sethome
```

怪物会围绕该传送点刷新。
