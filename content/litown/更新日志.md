# 更新日志

## 1.1.2：袭击流程修复与 BossBar（2026-11-03）

- 新增袭击 BossBar，每秒展示当前波次、总波数与剩余怪数；标题、颜色、样式和可见范围可配置，默认显示给据点 96 格内的同世界本镇成员。
- 停止、失败、胜利与重载先结束当前会话，再清理任务和怪物。取消任务失败、迟到回调或重复死亡事件不会续刷、干扰新袭击或重复结算。
- 死亡检查补漏，避免尸体阻塞下一波；生成未完成时等待结果，不提前判定清波。停止或等待超时会清理排队生成。
- 修正 Paper/Folia 调度识别与任务取消。Folia 袭击控制和奖励命令在全局调度执行，生成、检查和清理使用对应位置或实体的调度器。
- 修复清波后跨过超时检查边界仍被误判失败，以及重载后旧奖励回调继续执行的情况。
- 袭击临时怪物不自然消失，也不写入世界存档。远处怪物在停止和超时后实际清理。
- `raids.yml` 缺失的 `progress-bar` 配置及中文注释自动补齐，原有怪物、奖励、名称和玩家数据保留。

验证：35 项 JUnit 测试通过。同一份 1.1.2 Jar 在 Paper 26.2 build 134 / Java 25 隔离服通过 82 项检查，在自编译 Folia 26.2 build 5 / Java 25 隔离服通过 93 项袭击专项检查，覆盖完整三波死亡推进、旧回调重放、每场只结算一次、停止和重载后跨周期观察、远区实体死亡与物理清理，以及真实 Bukkit BossBar 状态。

玩家身份、在线状态与 BossBar 收件人为模拟对象；没有真人客户端视觉验收，也没有真实 Vault 或 MythicMobs 验收。Folia 结果不等同全插件所有功能均已验收。完整停服替换 Jar 后再启动，`/litown reload` 只重载配置。

## 1.1.1：任务、袭击、申请、红包分页与业务修复（2026-10-31）

新增分页入口（页码省略默认为 1，越界自动归一）：

| 命令 | 用途 |
| --- | --- |
| `/litown gui quests [页码]` | 任务 |
| `/litown gui raids [页码]` | 袭击 |
| `/litown gui applytowns [页码]` | 未入镇玩家选择申请小镇 |
| `/litown gui applications [页码]` | 审核申请，仍检查职位权限 |
| `/litown redpacket list [页码]` | 镇民红包 |

每页有页码、上一页/下一页。排序有稳定的 ID/UUID 次序；新增或删除数据后按最新列表计算页码。菜单操作后返回原页，最后一页被领空/审核空时自动退到有效页。按钮继续走原业务命令并重新检查权限与状态。红包已领取图标不再执行领取。任务和袭击补全使用无颜色、无空格的内部 ID，展示仍为中文名称。

任务与袭击展示分别拆到 QuestMenu、RaidMenu，分页与空态统一封装。导航在 `common.items.previous`、`next`、`page-info` 配置名称/材质/Lore，单菜单 `items` 可以覆盖。固定槽位从 0 开始，-1 隐藏；上一页默认 size-6，下一页 size-4，返回 size-5，关闭 size-1，页码默认 4。内容格排除操作/导航槽位。建议使用已验证的 27 或 54 格；较小布局需要服主自行安排足够内容格。27 格空态图标会放到内容区，不再被返回按钮覆盖。

实际修复：
- 采集和探索任务实时显示进度；采集提交只使用主背包，不扣装备/副手物品。
- 提交先结算任务状态再执行奖励钩子，防止重入重复领取；满背包奖励掉落到玩家位置，避免静默丢失。
- 无效任务类型/目标/数量跳过并中文提示，不让一个错误任务导致整个插件启动失败。
- 缺少可生成实体的袭击拒绝启动；运行时空波次不白送胜利；外镇玩家不计入参与奖励。
- 停止/失败时清理袭击实体；原版袭击怪不自然消失，发现外部移除则中止，避免卡波。
- 红包先按分向下规范再扣费与分配，保证金额一致；领取与失败回滚串行处理，领取记录返回不可变快照。
- 创建、公告编辑、职位与转让入口点击后提供对应参数指引；仍需通过指令输入名称/玩家/公告内容。日志入口可查询第 2 页。

验证：20 项 JUnit 测试通过；Paper 26.2 build 134 / Java 25 隔离服通过 521 项断言。五种列表各 35 条数据，54/27 格完整翻页、边界、空态、补全；真实 Bukkit 库存中的采集扣物与奖励、掉落物生成、离线审核、红包精确收付与重复拒绝、真实袭击实体生成/停止清理均覆盖。玩家与经济服务为模拟对象，没有真人客户端视觉验收、真实 Vault 经济插件结算或 MythicMobs 实体测试；不等同完整 Folia 兼容验收。

## 1.1.0：现有功能与菜单优化（2026-10-31）

- 主面板概览新增在线成员数、金库余额、个人可用/累计贡献。由独立的 TownDashboardMenu 负责展示。
- 贡献商店分页，商品数量不再被第一页容量截断；支持 `/litown shop list 2` 和参数补全。
- 商品显示等级不足、贡献不足、已关闭或可兑换状态；不能兑换的图标没有点击动作。
- 点击商品先打开确认页，取消返回原页；确认时重新校验等级、贡献和背包容量。
- 背包装不下时不扣贡献；兑换成功返回原来的商品页。直接使用 buy 命令仍表示立即兑换。
- 主面板、菜单物品、提示消息统一解析 MiniMessage，支持多色渐变、RGB 以及旧 & 颜色。Lore 空行保留。
- 菜单只执行内部动作标签，不再通过旧槽位、物品名称或 Lore 推断指令。
- 库存切换延迟至下一 tick；同 tick 重复点击合并，关闭或换页后的过期动作丢弃。数字键、丢弃键等不触发按钮。
- `slot: -1` 可以隐藏固定按钮。商店在 27 格布局中自动回退导航槽位，并从商品区域排除导航槽位。
- 修复累计贡献溢出。配置缺失项连同中文注释补齐，已有值与已有注释保留；配置语法错误不会被默认文件覆盖。

`menus.main.items.dashboard-status.lore` 设为 `[]` 可关闭附加概览。新商店配置位于 `menus.contribution-shop`，确认页位于 `menus.shop-confirm`。已有配置只迁移准确的旧默认兑换提示，不覆盖自定义提示。

验证：9 项 JUnit 回归测试通过；Paper 26.2 build 134 + Java 25 隔离服 25 项运行时断言通过，包含真实 Bukkit 库存和模拟 Player 调用。验证了运行库自动下载及加载。没有真人客户端视觉验收，没有新增 Folia 完整兼容性证明，也没有本次 MySQL 数据库连接测试。原有 Folia 标记与调度适配保持。

参考作者公开 GUI 文档：https://gyzer.gitbook.io/legendaryguild-english/configuration/gui-configuration/basics-fuction/sub-menus/guildmenu.yml 。此次聚焦已有功能，不包含神树、团购或增益系统。
