# 菜单与分页

## GUI 菜单

打开方式：

```text
/litown gui
```

默认主菜单为 54 格箱子界面，包含：

- 小镇总览
- 成员总览
- 公告
- 日志
- 传送
- 职位
- 贡献
- 帮助
- 委托任务
- 小镇袭击
- 可切换排序的小镇排行
- 成就
- 小镇金库
- 共享仓库
- 镇民红包
- 镇民友伤
- 小镇竞赛
- 贡献商店
- 管理员入口

菜单内不显示领地和外交入口。小镇竞赛不会修改领地或世界方块。

### 菜单完全自定义

所有 GUI 的显示配置集中在 `plugins/LiTown/menus.yml`。可修改：

- `title`：菜单标题，即玩家打开箱子后看到的菜单名字。
- `size`：菜单格数，取值为 `9`、`18`、`27`、`36`、`45` 或 `54`。
- `content-slots`：任务、小镇、成员、红包等动态条目的展示槽位和每页容量。
- `items.<按钮>.slot`：按钮槽位，从 `0` 开始计数；固定按钮设为 `-1` 可隐藏。
- `material`：Bukkit 物品材质；动态条目可填写 `DYNAMIC`，使用任务、物资或商品配置自身的材质。
- `name`、`lore`：物品名称和说明，支持 MiniMessage、多色渐变、RGB、旧 `&` 颜色代码及各菜单列出的占位符；Lore 空行会保留。
- `amount`：显示数量，取值 `1-64`。
- `custom-model-data`：资源包模型数据；`0` 表示不设置。
- `decoration`：可覆盖全局边框、强调色和分隔线开关与材质。
- `texts`：在线状态、排序名称、任务进度、袭击冷却等运行状态文字模板。

例如修改主菜单名称和任务按钮位置：

```yaml
menus:
  main:
    title: "&0云梦泽 - {town}"
    size: 54
    items:
      quests:
        slot: 20
        material: WRITABLE_BOOK
        name: "&a今日委托"
        lore:
          - "&7看看今天能帮镇里做些什么。"
        amount: 1
        custom-model-data: 0
```

按钮点击由插件内部动作标签识别，不依赖物品名称、Lore 或固定槽位，因此这些显示字段可以自由修改。旧版 `menus.yml` 会在启动或 `/litown reload` 时自动补全新增字段，不覆盖已经存在的自定义值。

小镇等级图标的主体材质、名称和 Lore 继续在 `config.yml` 的等级配置中管理；`menus.yml` 控制它在主菜单、小镇总览、申请和竞赛页面中的槽位及附加说明。共享仓库标题由 `menus.yml` 控制，仓库容量与禁放规则仍由 `warehouse.yml` 控制，仓库内部不会填充装饰物品。

### 小镇总览

主菜单顶部的小镇等级图标和“小镇总览”入口都会打开总览菜单。未加入小镇的玩家也可以从未加入菜单进入。

总览默认每页显示 21 个小镇；实际每页容量由 `menus.town-overview.content-slots` 的槽位数量决定。底栏默认提供：

- `创建时间`：新创建的小镇优先。
- `小镇等级`：等级从高到低，同等级按声望排序。
- `小镇声望`：声望从高到低，同声望按等级排序。
- 上一页、下一页和返回主菜单。

旧命令 `/litown gui ranking` 继续可用，并会打开新的小镇总览。

### 成员总览

成员菜单默认每页显示 21 名成员；实际每页容量由 `menus.town-members.content-slots` 的槽位数量决定。玩家头颅会写入该玩家的 Bukkit 档案，因此已进入过服务器并有皮肤档案的玩家会显示对应皮肤。

底栏排序方式：

- `加入时间`：较早加入的成员优先，旧数据没有时间时显示“历史数据”并排在后面。
- `成员职位`：按镇长、副镇长、远征队长、工匠、冒险者、见习者排序。
- `成员贡献`：累计贡献从高到低排序。

成员 Lore 会显示在线状态、职位、累计贡献、可用贡献和加入时间。

## 1.1.1 分页入口

页码省略为第 1 页，越界时自动回到有效页。每页提供页码、上一页与下一页；操作后返回原页，数据减少时重新计算有效页。

| 命令 | 列表 |
| --- | --- |
| `/litown gui quests [页码]` | 委托任务 |
| `/litown gui raids [页码]` | 小镇袭击 |
| `/litown gui applytowns [页码]` | 未入镇玩家选择申请小镇 |
| `/litown gui applications [页码]` | 入镇申请审核，仍检查职位权限 |
| `/litown redpacket list [页码]` | 镇民红包 |
| `/litown shop list [页码]` | 贡献商店 |

分页导航的通用配置位于 `menus.yml` 的 `common.items.previous`、`common.items.next`、`common.items.page-info`，可在单个菜单的 `items` 中覆盖。动态内容区会排除操作和导航槽位，避免按钮覆盖条目。建议采用已验证的 27 或 54 格布局；更小的布局需自行预留足够内容格。

已领取红包和不满足条件的商品不执行领取或兑换动作。商店点击商品进入确认页，取消回到原页，确认时重新检查贡献、等级与背包空间；装不下时不扣贡献。

创建小镇、编辑公告、设置职位和转让镇长图标会提供指令参数提示，仍需通过命令输入具体名称、玩家或内容。
