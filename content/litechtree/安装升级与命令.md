# 安装、升级与命令

运行要求：Java 25、Paper / Folia 26.2，玩家使用 Minecraft Java 26.2 并接受配套资源包。核心玩法无需 CraftEngine；使用 CE 物品、配方权限或 CE 合包时再安装匹配的 CraftEngine。MiniMessage 由运行库自动下载，首次启动需可连接 Maven 仓库。

## 安装和升级

1. 将 `LiTechTree-1.3.1.jar` 放入服务端 `plugins/`，旧版 Jar 移至备份目录，正常重启服务器。不要使用插件管理器热加载。
2. 按 [资源包使用说明](界面自定义与资源包.md) 更新 CE 独立目录 `plugins/CraftEngine/resources/litechtree_dialog_ui/`，并配套更新 `plugins/LiTechTree/ui-layout.yml`。图片和字体只使用 `litechtree` 命名空间。
3. 执行 `/ce reload all`，等待 CE 合并资源包生成及托管完成，再让客户端接收新包。若服务器启用自动上传与重发，请等待上传结束；需要手动发送时使用 `/ce feature send-pack 玩家名`。
4. 玩家应用资源包后执行 `/tech` 或 `/科技树`，点击节点查看材料与前置，确认研究后获得权限和首次奖励。页面回调有效期为 3 分钟，过期后重新打开；支持 ESC 关闭。

首次安装会生成默认配置。仍完整保留 1.2.3 默认树的服务器，会先将旧 `tree.yml` 与可识别的旧默认布局备份到 `plugins/LiTechTree/backups/upgrade-1.3.1-*/`，再升级为完整路线。只改了注释或键顺序仍视为相同内容，原文件字节保留在备份中。缺少 `tree.yml` 时生成新默认树，可识别的旧默认布局也会先备份再升级。

管理员改过名称、价格、权限、说明、前置或其他内容的树**不会被自动覆盖**，也不会混入新默认节点；新路线只导出到 `plugins/LiTechTree/examples/tree-1.3.1.yml` 供手动合并。已有 `config.yml`、`messages.yml`、玩家点数与解锁存档保留，缺少的新文案从内置默认值补齐到内存。自定义树必须按实际配置生成匹配的资源包和清单。

旧版 12 个节点 ID 与权限均保留，移动章节不会丢失解锁。旧存档已完成的节点不补发新增奖励；已解锁 `workbench` 但没有点数的玩家，可带 4 根木棍研究新增的零费用节点 `starter_kit`，领取 80 点继续推进。

## 指令

| 指令 | 功能 | 权限 |
| --- | --- | --- |
| `/tech`、`/tech open [章节]` | 打开第一章或指定章节图形科技树 | `litechtree.use`，默认所有人 |
| `/tech unlock 节点` | 检查前置、材料、其他条件及费用后研究 | 同上 |
| `/tech help` | 指令帮助 | 同上 |
| `/tech points 玩家 add 数量` | 发放研究点 | `litechtree.admin`，默认 OP |
| `/tech points 玩家 set 数量` | 设置研究点 | 同上 |
| `/tech grant 玩家 节点` | 免费赠予，仍需完成前置，不发首次研究点 | 同上 |
| `/tech revoke 玩家 节点` | 撤销节点及全部依赖后继，不退款 | 同上 |
| `/tech reload` | 验证并重载配置、布局，使旧页面失效并同步权限 | 同上 |

管理目标目前只接受在线玩家，指令有 Tab 补全。`experience-per-point` 可开启原版经验兑换，不扣原版经验，默认关闭；任务插件也可通过 `points add` 发点。异步事务进行中会提示稍后重试，连续发放应等待前一次完成。
