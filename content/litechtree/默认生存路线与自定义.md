# 默认生存路线与自定义科技

默认内容有 **12 章、97 个科技节点**。从制作工作台开始，经过农牧、矿业、红石、聚落、探索、附魔、下界、炼金、末地和海洋，最后汇合为「世界工匠」。无需自定义物品也能完成，CraftEngine 配方权限作为每个节点的可选扩展入口。

研究材料只检查背包持有，**不消耗物品**；经验等级只检查，不扣级。所有前置、物品、准入权限和进度条件同时满足后，才可支付研究点并解锁。默认路线没有杀怪数量、在线时长、建筑检测或累计提交任务；说明中的玩法建议不代表插件监测了这些事件。

## 从第一步到最后一步

1. 取得原木，制作工作台，随身携带后研究「基础工艺」，免费领取 80 点。再准备 4 根木棍研究「整装出发」，免费领取 80 点。
2. 准备圆石、煤炭和种子，取得铁锭、面包、盾牌和火把；携带箱子与熔炉完成「安稳营地」。箱子、熔炉和其他要求物品要在研究时放在背包中。
3. 农牧支线逐步储备作物、牛奶、蜂蜜和食物；建筑支线准备石木、玻璃、染料和装饰。两条支线可随时穿插，最终汇入终章。
4. 持铁镐下矿，取得铜、金、红石、钻石、青金石和黑曜石。研究「深层采矿」后可并行推进红石工业和下界路线。
5. 制作活塞、漏斗、中继器、轨道、高炉与烟熏炉，完成工程路线。准备书架、附魔书和钻石装备，达到 20 级后完成「附魔学识」。
6. 探索支线准备指南针、地图、弓箭、刷子和雪地装备，收集末影珍珠。远行装备齐备后开始海洋支线。
7. 下界之门节点在搭建前检查 10 块黑曜石与打火石。进入下界后取得石英、灵魂沙、烈焰棒和下界疣，开启炼金与末地路线。
8. 制作酿造台、药瓶并收集药材、红石、荧石粉、火药和发酵蜘蛛眼。末尾只检查普通药水材质，不区分具体药效；不把水瓶误称为已验证的特效药。
9. 制作末影之眼，准备末地补给；采集龙息、末地石、紫颂果和潜影壳，取得鞘翅并配备火箭。龙息样本只证明持有材料，不记录击杀归属。
10. 海洋支线储备口粮、海带和海晶材料，取得海洋之心并制作潮涌核心。潮涌核心是否放置激活由玩家自行完成。
11. 终章准备下界合金工具、凋灵召唤材料和下界之星，制作信标与底座材料，完善鞘翅运输。汇合农牧、聚落、炼金和深海成果，研究「世界工匠」。

末影之眼的默认检查数量只是研究门槛，实际寻路、补充门框、战斗和建造可能需要额外物资。物品可由玩家自己制作，也可通过服务器允许的交易取得；这套默认路线检查研究准备程度，不声称追踪玩家亲手完成了每件事。

## 研究点与旧存档

新玩家从 0 点开始即可完成全部节点：总费用 3135 点，首次奖励 4275 点，全部完成后净余 1140 点，不包括管理员、经验兑换或其他插件额外发放。

「基础工艺」和「整装出发」均为零费用、80 点奖励。其他节点研究奖励至少覆盖本次费用，单个节点最高费用 80 点。因此拿到任一笔起步奖励后，只要满足材料与前置，选择任意可用支线都不会因为默认研究点预算而卡住；物资准备是默认玩法的主要门槛。

保留旧版的 `workbench`、`smelting`、`farming`、`iron_tools`、`engineering`、`alloy`、`mechanics`、`advanced_tools`、`explorer`、`boots`、`alchemy`、`ender` 这 12 个节点 ID 和原权限。`alchemy` 移至炼金章，`ender` 移至末地章，历史解锁仍按 ID 识别。

升级时旧存档中已有的解锁记录不补发新增研究奖励，以免重复领取。旧玩家若已解锁工作台但没有研究点，可制作 4 根木棍并研究新增的 `starter_kit`，取得 80 点继续推进。奖励按玩家与节点记录为首次奖励，撤销后重新研究不会再次发放；管理员撤销也不退款。

## 改成自己的科技树

在 `plugins/LiTechTree/tree.yml` 修改节点，现有管理员配置和玩家存档不应被默认示例整份覆盖。保留节点 ID 可保留玩家解锁；显示名称、介绍、费用、奖励和条件都可以自行调整。增加自定义内容时先确定其材料来源和前置关系，避免让研究条件只能由研究后的配方产出。

下面是节点条件与奖励的字段示例，应合并到已有节点，而不是替换整个配置：

```yaml
# 研究条件，以下各项同时满足；空项表示不启用。
requirements:
  # 原版物品材质与正整数数量，只检查背包持有，不消耗。
  items:
    IRON_INGOT: 8
    REDSTONE: 4
  # CE 自定义物品 ID 与正整数数量；不用时保持 {}。
  # 启用示例：在 ce-items 下新增一行 'my_pack:steel_ingot': 2。
  ce-items: {}
  # 最低原版经验等级；0 为关闭，只检查而不扣除。
  levels: 0
  # 额外准入权限；需全部拥有，[] 为关闭。
  permissions: []
  # 要求完成的进度 ID 列表；请从本服确认 ID，[] 为关闭。
  advancements: []
# 本次研究点费用，0 为免费。
cost: 20
# 首次成功研究发放的研究点，撤销后不重复发放。
reward-points: 30
# 研究完成后授予的 CE 配方权限，禁止管理权限和通配符。
permissions: [litechtree.recipe.my_machine]
```

`requirements.permissions` 是研究前必须具备的权限，节点外层 `permissions` 是研究完成后授予的权限，两者用途不同。不要把同一个权限同时放进两处形成自锁。启用 CE 物品条件时，需要 CraftEngine 能识别对应自定义物品 ID；默认所有 `ce-items` 都为空，纯原版路线不依赖这些物品。

物品条件按配置类型检查，不比较原版物品的附魔等级、耐久、药水效果或自定义文本。需要严格识别 CE 特定物品时，使用 `ce-items`，不要只填写其底层原版材质。

只改名称、介绍、费用、条件、奖励和权限后可重载配置；修改节点 ID、章节、位置 `slot`、图标 `icon`、前置 `parents` 或增删节点，需要重新构建并同时应用字体资源包与 `ui-layout.yml`，再让客户端接收新资源包。`slot` 范围为 0~44，表示 9 列 × 5 行，同章不能重复。

## CraftEngine 配方接入

每个节点都有 `litechtree.recipe.<节点ID>` 权限。默认不会替换或锁定任何原版配方；只有管理员把该权限条件加进具体 CE 配方后，那个配方才跟随科技解锁。完整 CE 有序配方例子见 `examples/ce-recipe-example.yml`。

在支持配方条件的 CraftEngine 版本中，为目标自定义配方加入：

```yaml
# 配方执行条件列表，全部满足才能制作。
conditions:
  # 条件类型，固定为 permission。
  - type: permission
    # 必须与对应节点外层 permissions 完全一致。
    permission: litechtree.recipe.alloy
```

不要把示例中的「取得铁锭」节点绑定到唯一的铁锭获取配方，也不要把基础工作台、木棍、面包等入门所需原版配方锁在它们自己的研究后面。适合接入的是解锁后的自定义升级产物，例如工程零件、专用工具、高级装备；本插件不自动创建这些 CE 物品或配方。
