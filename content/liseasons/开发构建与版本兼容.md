# 开发构建与版本兼容

## 项目基线

- Maven 项目；
- Java release 21；
- Paper API 编译基线 1.21.11；
- ProtocolLib 5.5.0-SNAPSHOT 由 `lib/` 本地提供；
- PlaceholderAPI 2.11.6 为 `provided`；
- JUnit Jupiter 5.10.3 用于测试。

## 标准构建

PowerShell：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-21'
mvn clean package
```

默认产物：

```text
target/LISeasons-1.0.61.jar
```

项目另有 `obfuscate` Maven profile。对外 API、主类、PAPI 和集成入口有 ProGuard 保留规则；混淆构建发布前仍需真实服务器加载验证。

## 依赖打包规则

成品 Jar 只包含 LISeasons 自身业务类和资源，不应打入：

- Bukkit/Paper API；
- NMS 服务端类；
- ProtocolLib；
- PlaceholderAPI；
- PacketEvents。

ProtocolLib 是运行时服务器插件依赖，不是 shaded Java 库。

## 版本适配结构

NMS 季节色调由版本配置、NMS 区块调色板修改器和 ProtocolLib 数据包发送器分层处理。支持范围不是只靠 `api-version` 声明，而要同时满足：

1. Paper API 可编译；
2. CraftBukkit/NMS 类与方法签名匹配；
3. 群系调色板能正确写入；
4. 数据包能由 ProtocolLib 发送；
5. Paper 与 Folia 调度路径线程安全；
6. 客户端实际收到颜色变化。

因此“同为 26.2”不保证未来所有服务端构建永远兼容。服务端更新内部实现后，应重新跑 NMS 签名测试和实际加载测试。
