# 自然灾害与龙卷风

当前版本 1.0.75，共有 8 种持续灾害：龙卷风、热浪、寒潮、暴风雪、雷暴、冰雹、沙尘暴、冻雨。

## 新增的三种灾害

| 灾害 / 命令 ID | 自然季节 | 总时长 / 预警 | 满强度效果 |
| --- | --- | --- | --- |
| 冰雹 `hailstorm` | 春 | 90 / 8 秒 | 冰屑粒子、-5℃；每至少 3 秒以 70% 概率造成 1.5 点基础伤害 |
| 沙尘暴 `sandstorm` | 秋 | 120 / 10 秒 | 棕色风沙粒子、+4℃；每至少 4 秒给予虚弱 I，持续 60 tick；默认不直接扣血 |
| 冻雨 `freezing-rain` | 冬 | 120 / 10 秒 | 下落水滴、-10℃；每至少 4 秒给予缓慢 I（80 tick）和 60 tick 冻屏；冻伤取决于温度暴露 |

三者默认每次满足事件检查条件时有 2% 概率、1200 秒个人冷却，还受全局冷却/优先级限制。沙尘暴不额外限制沙漠群系；这是个人季节事件，不是共享气象模拟。预警期间没有新灾害粒子、温差、药水或伤害；默认 8 秒增强、12 秒消散。屋顶下和个人晴天完全跳过三者的粒子、温差和脉冲，但不会主动移除已经给予的短时药水，以免删除其他插件的效果。

只使用原生粒子，无需额外资源包，不产生真实冰雹实体、不放置水/沙/冰；无方块损坏和冰面物理。冰雹伤害走 Bukkit 事件，可由保护插件取消；冻屏限制在原版冻结伤害阈值以下。非致死开关继续限制基础伤害。

管理员在启用季节的世界执行以下命令，允许跨季节手动测试：

```text
/seasons event trigger hailstorm
/seasons event trigger sandstorm
/seasons event trigger freezing-rain
```

入口在 `season-events.yml` 对应季节分组；持续配置为 `climate-survival.yml -> disasters.HAILSTORM / SANDSTORM / FREEZING_RAIN`。`visual` 控制显示开关、粒子数（1–128）、半径、高度和最短更新间隔，实际帧率不快于温度检测周期；视觉节流独立于伤害概率，卡顿不补帧。要完全禁用请关闭事件入口，单独关闭 `visual.enabled` 只关粒子。

## 龙卷风模型

1.0.74 将龙卷风升级为原生立体粒子模型，并优化五种灾害的强度变化。这里的“模型”是程序化粒子几何，不是 ModelEngine 实体或 Blockbench 文件，无需安装客户端模组或下载额外资源包。漏斗风柱只向触发玩家显示，也只卷吸和伤害该玩家；不是全服共享风暴，不卷走其他玩家、动物、宠物或掉落物，不改变地形和建筑。

表现参考 [Weather2 的分层风柱参数设计](https://github.com/Corosauce/weather2/blob/1.20/src/main/java/weather2/weathersystem/tornado/ActiveTornadoConfig.java)，Bukkit 代码独立实现，不包含该模组的代码、贴图或模型资产。

## 如何触发

默认夏季每次满足事件检查条件时有 2% 概率，单人本事件冷却 1200 秒，同时受全局事件冷却和优先级选择限制。不是“每秒 2%”。

管理员站在启用季节的世界，用：

```text
/seasons event trigger tornado
```

该命令需要 `liseasons.admin`，只能由玩家执行。Tab 可补全 `tornado` 及新增灾害 ID；日历季节告示板列出 20 种默认事件。手动触发可用于非夏季测试。

## 默认表现与避险

| 设置 | 默认行为 |
| --- | --- |
| 预警 / 总时长 | 10 秒 / 90 秒，总时长包含预警 |
| 风柱 | 高 16 格，底部半径 0.6 格，顶部半径 4 格；弯曲漏斗、云盘、棕色尘屑环 |
| 演变 | 预警显示云盘，随后 8 秒逐步成形，最后 12 秒消散；风力、基础伤害与温差同步变化 |
| 路径 | 从触发时朝向前方 5 格出现，以 0.25 格/秒向初始玩家方向直线移动，不跟随玩家平移 |
| 作用范围 | 水平半径 7 格，垂直为起点下 2 格至风柱顶部 |
| 范围效果 | -3℃ 空气温差、向心卷吸、旋转和抬升，每至少 3 秒造成 2 点基础伤害 |
| 速度限制 | 水平合成速度最多 0.65 格/tick，主动抬升约至起点上 6 格后停止向上推 |
| 潜行 | 自身受到的风力降至 35%，不免疫范围伤害 |

预警期只有高空云盘，没有落地漏斗、卷吸、温差或脉冲伤害。跑出作用范围可以躲开本场温差、卷吸和脉冲；屋顶下跳过卷吸、粒子及脉冲，默认温差也归零。Residence 等插件给予的个人晴天 `WeatherType.CLEAR` 同样可屏蔽这些影响。

风柱路径高度固定，不追踪途经地形；这避免了在 Folia 上跨区域加载或读取风柱附近区块。玩家只在自己所属线程接受速度变更，移动碰撞仍由原版处理。骑乘、飞行、鞘翅飞行不受卷吸，但并不因此免疫范围伤害。

默认允许致死，腾空后仍可能摔伤；不修改玩家摔落距离、不豁免其他来源伤害。`allow-lethal-damage: false` 会关闭龙卷风位移，仅保留视觉及保底脉冲伤害，避免卷吸把玩家推出悬崖。创造、旁观、无敌、无季节世界与 `liseasons.climate.bypass` 权限保持免疫。

## 配置入口

- `season-events.yml -> summer-events.tornado`：事件开关、自然概率、冷却、优先级、菜单介绍。
- `climate-survival.yml -> disasters.TORNADO`：持续开关、时长、预警、温差、伤害、声音和消息。
- `climate-survival.yml -> disasters.TORNADO.vortex`：高度、半径、移动速度、粒子预算、卷吸、抬升上限和潜行减力。
- `climate-survival.yml -> disasters.TORNADO.vortex.appearance`：立体模型开关、预警云、尘屑、底部半径、弯曲幅度、旋转速度、粒子尺寸。`layered: false` 回退旧版单条云螺旋。
- `climate-survival.yml -> disasters.<类型>.evolution`：八种灾害的渐入和消散时间，范围 0–120 秒；0 关闭对应过渡。两段过渡各不超过有效时长的一半，确保短灾害能达到满强度。

完整范围和中文说明在 YAML 中。想完全禁用龙卷风，请将 `summer-events.tornado.enabled` 设为 `false`，然后 `/seasons reload`。重载会清理现有风柱；替换 Jar 则必须完整重启服务器。

每 5 tick 更新一帧，默认每帧最多 48 个粒子（云盘、漏斗、尘屑合计），预警云仅约 8 个；每轮最多处理 24 人。更多风柱按玩家轮转，卡顿时不积压同一个玩家的帧任务。48 格外不发送风柱粒子。灰色尘埃始终携带 `DustOptions`，避免数据型粒子缺参数错误。旧配置仅补新节点和中文注释，保留已有配置选择。

演变只缩放温差、基础脉冲伤害和风力，不缩放 `effects` 的药水等级/持续时间。风柱摆动是视觉表现，不扩大伤害半径；地面尘屑为棕色粒子，不代表真实方块被破坏。

## 插件联动与验证边界

脉冲伤害使用 Bukkit 伤害事件链。新增 `com.liseasons.api.event.TornadoWindEvent`，其他插件可取消每次卷吸；它在玩家所属线程触发，只读 `getVelocity()` 返回拟施加速度的副本，取消卷吸不等于取消独立脉冲伤害。屋顶和个人晴天屏蔽已在隔离服探针检查，但不承诺所有领地插件会自动识别新增事件。

死亡、重生、离线、换世界、换季、免疫状态、另一场灾害替换、重载和停服均清理风柱。服务代理检查可以验证粒子 API 参数、预警、强度和保护路径，但不等于真实在线玩家的受力、反作弊兼容与客户端视觉验收。
