# 安装与升级

## 安装前要求

- 服务端：Paper、Leaves、Lophine 或 Folia 的受支持版本。
- Java：插件使用 Java 21 字节码；Minecraft 26.x 服务端若要求 Java 25，应使用 Java 25 启动服务端。
- 强制前置：ProtocolLib。
- 可选前置：PlaceholderAPI、CustomCrops、Dominion。

当前 `plugin.yml` 声明：

```yaml
api-version: '1.21.11'
folia-supported: true
depend: [ProtocolLib]
softdepend: [CustomCrops, PlaceholderAPI, Dominion]
```

ProtocolLib 缺失时，插件会被服务端依赖检查阻止加载。这不是可忽略的颜色模块警告。

## 首次安装

1. 停止服务器。
2. 安装与当前服务端兼容的 ProtocolLib。
3. 将 `LISeasons-1.0.61.jar` 放入 `plugins/`。
4. 在启用 NMS 季节色调前备份正式世界；该模块会改写并保存区块群系调色板，不能自动恢复原始群系。
5. 启动服务器一次，等待 `plugins/LISeasons/` 生成配置。
6. 修改 `config.yml -> worlds`，确认季节系统应在哪些世界运行。
7. 完整重启服务器。
8. 进入游戏执行 `/seasons info`、`/seasons calendar` 检查基础功能。

默认世界范围：

```yaml
worlds:
  enable-all: false
  allowed:
    - world
  denied:
    - world_nether
    - world_the_end
```

判定顺序为：`denied` 优先拒绝；否则 `enable-all: true` 或世界名位于 `allowed` 时启用。

## 生成的文件

| 文件 | 是否建议手动编辑 | 用途 |
| --- | --- | --- |
| `config.yml` | 是 | 时间、世界、作物、天气、视觉、生物、冰雪和集成 |
| `messages.yml` | 是 | MiniMessage 文本、季节/世界名称映射 |
| `temperature.yml` | 是 | 空气温度、体温、湿度、装备、物品和温度事件 |
| `season-color.yml` | 是 | NMS 季节色调和区块预算 |
| `season-events.yml` | 是 | 季节事件、流星雨和奖励 |
| `festivals.yml` | 是 | 节日日期与说明 |
| `gui.yml` | 按需 | 旧版 GUI 兜底配置 |
| `gui/*.yml` | 是 | 六个独立菜单页面 |
| `calendar-state.yml` | 否 | 每个世界的持久化服内日历进度 |

## 从旧版本升级

升级前至少备份：

```text
plugins/LISeasons/
plugins/LISeasons.jar 或原 LISeasons Jar
```

推荐流程：

1. 停止服务器并备份整个插件目录。
2. 删除旧 Jar，但保留配置目录。
3. 放入新 Jar。
4. 启动后查看配置迁移日志和 NMS 初始化日志。
5. 对比新 Jar 内的默认 `temperature.yml`、`festivals.yml` 与自己的旧文件。
6. 执行功能验收后再开放服务器。

### 自动迁移范围

1.0.61 会为以下已有文件补全缺失节点，并保留已存在的自定义值：

- `config.yml`
- `messages.yml`
- `season-color.yml`
- `season-events.yml`
- `gui.yml`
- 六个 `gui/*.yml` 页面

它还包含冬冻春融旧字段迁移、默认品牌文本迁移和流星雨旧默认值迁移。流星数值只有仍等于旧版原始默认值时才会替换，管理员改过的值不会被强制覆盖。

`temperature.yml` 与 `festivals.yml` 当前只会在文件缺失时生成，不在通用“缺失节点自动补全”列表中。因此跨大版本升级时应手动对比这两个文件，避免漏掉新增字段。

## 重载还是重启

`/seasons reload` 会重读主配置、消息、体温、颜色、事件、节日和 GUI 配置，并重建相关定时任务。

以下情况建议完整重启：

- 更新 LISeasons Jar；
- 安装或更新 ProtocolLib；
- 更新服务端核心或切换 1.21.11、26.1.x、26.2；
- 出现 NMS 签名初始化失败；
- 更新 PlaceholderAPI、CustomCrops、Dominion 等依赖；
- 怀疑热重载残留旧任务或旧类。

不要使用会强制卸载/重载插件类的第三方热重载插件替代完整重启。

## 安装后验收

```text
/seasons info
/seasons calendar
/seasons event list
/seasons festival today
/seasons event trigger meteor-night
```

同时检查：

- 启动日志显示 LISeasons 1.0.61 已启用；
- ProtocolLib 在 LISeasons 之前启用；
- 当前世界不在 `worlds.denied`；
- 玩家附近草地和树叶会按预算逐步变色；
- TAB 等异步占位符插件不再出现异步读取区块报错；
- 流星测试时抬头观察，客户端粒子设置不要使用“最少”。
