# 玩家文档 · 常用指令

本页只列普通玩家可用的查询入口。管理指令、权限节点和 PlaceholderAPI 参考见[管理员指令、权限与占位符](指令-权限与占位符.md)。

主指令是 `/seasons`，别名是 `/season`。普通入口需要 `liseasons.player`，默认向玩家开放，但权限插件仍可拒绝。

## 日期与日历

| 指令 | 作用 |
| --- | --- |
| `/seasons` | 显示帮助 |
| `/seasons help` | 显示帮助和可用参数 |
| `/seasons info` | 查看当前世界的日期、节气、季节特征、作物、温度和下一节气 |
| `/seasons info <世界名>` | 查询指定已加载世界 |
| `/seasons calendar` | 打开六页季节手账，仅玩家可用 |

温度异常时，先用 `/seasons info` 确认世界和节气，再打开日历温度页查看玩家体感、空气温度与潮湿度。

## 季节事件

| 指令 | 作用 |
| --- | --- |
| `/seasons event list` | 列出服务器已加载的事件配置 |
| `/seasons event info` | 查看事件类型与配置数量 |

`event list` 会显示配置 ID、季节和优先级，但不代表事件已启用、现在可触发或今晚一定发生。普通玩家不能使用 `/seasons event trigger`。

## 节日

| 指令 | 作用 |
| --- | --- |
| `/seasons festival today` | 查看服务器现实日期对应的已启用节日 |
| `/seasons festival list` | 按日期列出全部已加载节日配置 |
| `/seasons festival info` | 查看节日类型与配置数量 |

节日使用服务器现实日期，不跟随服内世界日历。`festival list` 可能包含已停用记录，判断今天是否有节日请使用 `festival today`。

## 三个常见场景

### 我想知道为什么今天这么冷

1. 执行 `/seasons info`，确认世界、节气和温度摘要；
2. 打开 `/seasons calendar` 的温度页；
3. 检查潮湿、入水、降雨、高海拔、夜晚和保暖装备；
4. 按[体温生存指南](玩家-体温生存.md)中的自救清单处理。

### 我想看今晚会不会有流星雨

没有玩家指令可以准确预报。`/seasons event list` 只能确认 `meteor-night` 配置已载入，不能确认它已启用或即将命中。夏季夜晚前往开阔处观察高空，实际是否发生仍由服务器条件、随机概率和个人冷却决定。

### 我没有权限使用主指令

把你执行的完整指令和游戏提示发给管理员，请其检查 `liseasons.player`。不要只说“命令坏了”，因为未知世界、未启用世界和权限拒绝会显示不同消息。
