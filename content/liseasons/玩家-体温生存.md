# 玩家指南 · 体温生存

体感温度会随季节、节气、群系、昼夜、天气、海拔、室内外、水、装备、手持物和附近冷热源一起变化。它会逐步靠近目标值，不会因为跨进门槛就瞬间跳到最终温度。

> 本页列出 1.0.65 的默认“舒适版”数值。服务器可以修改或关闭任何一项，请优先相信游戏内提示。

## 在哪里看温度

- **操作栏**：默认持续显示当前季节与玩家体感；
- **日历温度页**：显示体感温度、空气温度和潮湿度；
- **聊天提醒**：体感描述发生变化并达到提示条件时出现；
- **`/seasons info`**：用于查看当前世界与位置的温度摘要。

如果不想持续显示操作栏，使用 `/seasons hud off`；需要恢复时使用 `/seasons hud on`，也可用 `/seasons hud status` 查看当前状态。该选择会跟随角色数据持久保存。

想判断装备、入水和热源是否生效，日历温度页最直观：先记录体感与潮湿度，改变环境后等待数秒，再次打开对比。

## 温度文字是什么意思

| 体感温度 | 默认描述 |
| ---: | --- |
| `≤ -30℃` | 极寒 |
| `-30～-20℃` | 严寒 |
| `-20～-10℃` | 寒冷 |
| `-10～0℃` | 阴冷 |
| `0～10℃` | 偏凉 |
| `10～22℃` | 舒适 |
| `22～35℃` | 偏热 |
| `35～45℃` | 炎热 |
| `> 45℃` | 酷热 |

表格边界按更低一档优先，例如正好 `-20℃` 显示“严寒”，正好 `22℃` 显示“舒适”。

## 冷了怎么处理

按影响最直接的顺序尝试：

1. 离开水面和雨雪，潮湿不会立刻消失，需要等待身体逐步变干；
2. 进入有屋顶的室内，冬季室内默认比室外暖 `5℃`；
3. 靠近普通营火、火焰、岩浆或岩浆块；
4. 穿戴皮革盔甲，默认每件提供 `+4℃`；
5. 手持火把或岩浆桶；
6. 喝蘑菇煲、兔肉煲、甜菜汤或蜂蜜瓶获得临时暖意。

### 默认升温物品

| 方法 | 温度修正 | 持续时间 |
| --- | ---: | ---: |
| 每件皮革盔甲 | `+4℃` | 穿戴期间；空气高于 25℃ 时不生效 |
| 手持火把 | `+1℃` | 手持期间 |
| 手持岩浆桶 | `+5℃` | 手持期间 |
| 附近普通火焰 | `+4℃` | 位于搜索范围内 |
| 附近营火 | `+6℃` | 位于搜索范围内 |
| 附近岩浆/岩浆块 | `+8℃` | 位于搜索范围内 |
| 蘑菇煲 | `+10℃` | 180 秒 |
| 兔肉煲 | `+14℃` | 240 秒 |
| 甜菜汤 | `+8℃` | 160 秒 |
| 蜂蜜瓶 | `+4℃` | 120 秒 |

## 热了怎么处理

1. 离开正午烈日和热带群系，进入室内或阴影；
2. 远离普通火焰、营火、岩浆和岩浆桶；
3. 靠近冰、浮冰、蓝冰、灵魂火或灵魂营火；
4. 手持雪球、冰或蓝冰；
5. 喝牛奶或食用甜浆果获得临时清凉；
6. 高温时不必为了保暖穿皮甲——默认空气高于 `25℃` 后皮甲不会继续升温。

| 方法 | 温度修正 | 持续时间 |
| --- | ---: | ---: |
| 手持雪球 | `-1℃` | 手持期间 |
| 手持冰 | `-2℃` | 手持期间 |
| 手持蓝冰 | `-4℃` | 手持期间 |
| 手持灵魂火把 | `-2℃` | 手持期间 |
| 附近冰 / 浮冰 / 蓝冰 | `-3 / -4 / -8℃` | 位于搜索范围内 |
| 附近灵魂营火 | `-6℃` | 位于搜索范围内 |
| 附近灵魂火 | `-8℃` | 位于搜索范围内 |
| 牛奶桶 | `-8℃` | 140 秒 |
| 甜浆果 | `-4℃` | 100 秒 |

## 水和潮湿为什么危险

入水会立刻变为完全潮湿。默认非冬季最多造成 `-4℃` 修正，冬季最多造成 `-10℃`；离水后潮湿度每次只恢复一部分。冬季落水后即使已经上岸，仍应先进入室内并靠近热源，直到日历温度页的潮湿度明显下降。

## 什么时候会出现生存效果

同一轮默认只执行最严重的一档，不会把所有低温或高温效果一起叠满。

| 条件 | 默认反馈 |
| --- | --- |
| 低于 `-2℃` | 呼吸附近出现雪花粒子 |
| 低于 `-12℃` | 短时缓慢与轻微冻屏 |
| 低于 `-20℃` | 冻屏、雪花和细雪声音 |
| 低于 `-26℃` | 更长冻屏与雪声音 |
| 高于 `38℃` | 汗水般的飞溅粒子 |
| 高于 `46℃` | 短时虚弱、粒子和熔炉声音 |
| 高于 `56℃` | 短时反胃、受伤反馈、火星和火焰声音 |

这些效果带有个人冷却，不会每个游戏刻连续触发。若服务器修改了阈值，以实际提示为准。

## 快速自救清单

| 状况 | 立即行动 |
| --- | --- |
| 冬季落水 | 上岸 → 进屋 → 营火/岩浆 → 热汤 → 等潮湿下降 |
| 高山夜行 | 下山或进洞 → 穿皮甲 → 携带火把和热汤 |
| 夏季中暑 | 进屋/遮阴 → 远离火源 → 冰或灵魂火 → 牛奶/浆果 |
| 温度似乎不变 | 等待体温平滑追近目标，再对比日历温度页 |
