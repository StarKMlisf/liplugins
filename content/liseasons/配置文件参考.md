# 配置文件参考

本页用于快速定位配置；每个默认 YAML 文件本身也带有逐项中文注释。详细机制请点击对应专题页。

## 流星奖励箱（1.0.81）

`season-events.yml → meteor-shower.rewards.chest` 新增 `enabled`、`remove-when-empty`、`title`、`message`，分别控制箱子模式、空单箱清理、MiniMessage名称与坐标提示。现有奖励池、坠地与发奖概率保持不变。安全位置生成真实箱子，领地或不安全位置回退同一批物品散落；未取完的箱子随世界保存。详见[季节事件与流星雨](季节事件与流星雨.md)。

## 灾害动态层次（1.0.80）

龙卷风 `appearance.mist`、雷暴/蘑菇云 `particle-scene`、流星 `appearance.fireball` 内新增 `atmosphere`：`enabled` 控制动态层次，`detail-share` 为0.1–0.4的原预算分配，`sound-enabled` 控制新增音景，`sound-volume` 为0–1，`sound-interval-seconds` 为2–20秒。四处独立配置，关闭不会禁用原本的大型粒子。详见[自然灾害与龙卷风](自然灾害与龙卷风.md)。

## 龙卷风原生云雾（1.0.78）

1.0.79 新增大型视觉倍率 `appearance.mist.height-scale/width-scale`（1–6），新默认均4；密度倍率上限提高为16，新默认12。雷暴/蘑菇云 `particle-scene` 与流星 `appearance.fireball` 的全部字段、预算、安全预览见[自然灾害与龙卷风](自然灾害与龙卷风.md)。以下1.0.78参数作为旧配置参考，不代表新默认。

整股风柱移动：`climate-survival.yml -> disasters.TORNADO.vortex.travel-speed` 为 0–1 格/秒（新默认 0.65，0 停止水平移动，旧值保留）；`movement.path` 选择 `wander` 缓弯或 `straight` 直线；`sway-amplitude` 为 0–6 格，`sway-period-seconds` 为 8–120 秒，`follow-ground: true` 在所属区域采样已加载地面并平滑贴地。预警结束后行进，视觉和卷吸共用移动中心。

`climate-survival.yml -> disasters.TORNADO.vortex.appearance.mist`：`enabled: true` 开启原生云雾并停止 ME 龙卷风；`density-multiplier: 3` 控制密度；`max-particles-per-second: 4096` 控制全服发送上限；`leaf-debris: true` 控制纯视觉碎叶。不改方块、不依赖资源包。其他灾害模型不受此开关影响。

## disaster-behavior.yml（1.0.77）

新增灾害行为配置，所有键带中文注释与范围；`enabled` 控制附加行为，`lightning` 控制闪电群与全服预算，`tornado` 控制自然敌对怪卷吸，`zombies` 控制每波/每人/全服数量、生命周期、MM/ME ID。原有伤害在 `climate-survival.yml`、事件概率在 `season-events.yml`、展示开关在 `model-display.yml`；旧值只补缺，不覆盖。

| `season-color.yml` | PacketEvents 客户端季节色调 | 是 |

## `config.yml`

1.0.73 龙卷风入口：`season-events.yml -> summer-events.tornado` 控制概率及开关；`climate-survival.yml -> disasters.TORNADO` 控制预警、伤害，`vortex` 子节点控制风柱和卷吸。详见[自然灾害与龙卷风](自然灾害与龙卷风.md)。

### `time`

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `use-gregorian-trigger` | `false` | 是否使用服务器现实日期 |
| `sync-real-time` | `false` | 是否同步所有已启用 NORMAL 世界的游戏时钟到现实时间 |
| `real-time-sync-interval-seconds` | `1` | 实时时钟同步周期 |
| `refresh-interval-seconds` | `60` | 季节自动刷新周期，实际最小 10 秒 |
| `world-calendar.enable` | `true` | 非公历模式下启用持久化服内日历 |
| `world-calendar.start-year` | `2026` | 起始年份 |
| `world-calendar.start-date` | `02-04` | 起始月日 |
| `world-calendar.start-world-day` | `0` | 日历锚点世界天数 |
| `world-calendar.world-days-per-calendar-day` | `1` | 每个日历日需要的世界天数 |
| `season-start-dates.*` | 03-04/06-04/09-04/12-04 | 四季开始日期 |
| `season-duration-days.*` | `24` | 旧版循环模式每季天数 |
| `gregorian-dates.*` | 24 节气表 | 节气公历日期 |

详见[日期、季节与二十四节气](日期-季节与二十四节气.md)。

### `worlds`

- `enable-all`：是否默认启用所有世界；
- `allowed`：显式允许的世界名；
- `denied`：显式拒绝的世界名，优先级最高。

### `biome_settings.frozen_biome`

- `enable`
- `lock_winter_mode`
- `disable_ice_melting`
- `disable_snow_melting`
- `target_biomes`

### `messages` 与 `effects`

- `messages.broadcast-change`：换季/换节气广播；
- `messages.join-notify`：加入时提示；
- `effects.change-particle.*`：变化时玩家粒子；
- `effects.change-sound.*`：变化时玩家声音。

### `season-buff-boss-bar`

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enable` | `true` | 季节增益 BossBar 全服总开关 |
| `show-term-progress` | `true` | 自动模式下用填充长度显示当前节气进度 |
| `overlay` | `PROGRESS` | 连续或 6/10/12/20 格分段样式 |
| `colors.<season>` | 春绿、夏黄、秋红、冬蓝 | 四季 BossBar 颜色 |

BossBar 不创建单独定时器，而是复用玩家体温刷新。四季标题位于 `messages.yml -> season-buff-boss-bar.title`；玩家的 `/seasons hud off` 会同时关闭 BossBar 与操作栏。

### `integration`

- `customcrops.enable`：尝试注册 CustomCrops 季节提供器；
- `dominion.protect-ice-and-snow`：保护领地内冰雪。

Residence 无额外集成开关：结冰/铺雪发送 `BlockFormEvent`，融化发送 `BlockFadeEvent`，让领地的 `iceform`、`icemelt` 自动生效。具体受保护材质范围见[世界规则](季节效果与世界规则.md)。

### `visual-effects`

- `interval-ticks`、`search-radius`
- `respect-player-weather`：布尔值，默认 `true`；暴风雪尊重 Residence 等插件设置的玩家晴天/降水，设为 `false` 只读取世界天气。
- `aurora.enable/chance-percent`
- `blizzard.enable/snow-placement-chance`
- `falling-leaves.enable`
- `autumn-leaf-color.enable/radius/budget-per-player`
- `tree-snow.enable`
- `apple-drop.enable/chance-percent`

1.0.65 极光实际使用五天一次门槛，`chance-percent` 暂未被渲染器读取。

### `season-effects.<season>`

- `uncovered-crop-growth-multiplier`
- `uncovered-crop-stop`
- `rain-chance`
- `thunder-chance`

1.0.65 的天气服务在冬季直接保留原版/管理员天气，不读取冬季雨雷概率。

### `season-world-rules.snow-accumulation`

以下值均为布尔值，水雪循环与暴风雪共用，不影响原版或其他插件自行生成的雪。

| 节点 | 默认值 | 用途与范围 |
| --- | --- | --- |
| `allow-top-slabs` | `true` | 允许上半台阶承雪；双台阶始终交给原版完整表面检测，下半台阶始终跳过 |
| `allow-top-stairs` | `true` | 允许倒置楼梯承雪；普通楼梯始终跳过 |
| `allow-leaves` | `false` | 允许树叶承雪；开启后仍须通过原版支撑检测 |

任何开关都不会把下半台阶填满、替换楼梯或强行制造悬空雪。目标位置有火把、地毯等方块时也不会覆盖。

### `season-world-rules.water-cycle`

- 总开关、周期、搜索范围；
- 冬季结冰、铺雪与春季融化概率；
- 换季融雪半径、列预算、方块读取预算、队列上限、区块刷新上限；
- `meltable-blocks` 方块到结果的映射；
- 结冰与融化各自的群系排除关键词。

### `season-world-rules.mob-rules`

- `enable`
- `summer-zombie-to-husk-chance-percent`
- `winter-skeleton-to-stray-chance-percent`

详见[季节效果与世界规则](季节效果与世界规则.md)。

## `messages.yml`

主要节点：

| 节点 | 用途 |
| --- | --- |
| `prefix` | 插件前缀 |
| `season-names` | 纯季节名 |
| `season.switch/case/default` | 带颜色季节映射 |
| `season-buff-boss-bar.title.*` | 四季增益 BossBar 文本与占位符 |
| `world.switch/case/default` | 带颜色世界映射 |
| `solar-term-names` | 24 节气显示名 |
| `command.*` | 权限、错误、设置、查询和帮助文本 |
| `notify.*` | 加入、变化、标题、体温和事件通知 |
| `hud.*` | ActionBar 文本 |
| `calendar.*` | 旧版 GUI 文案兜底 |

文本使用 MiniMessage。`<world>`、`<season>` 等上下文占位符由插件替换；未知标签或未闭合标签可能导致显示异常。

```yaml
  title: "<gradient:...>标题</gradient>"
  rows: 6
  size: 54
  layout: []
  icons: {}
  items: {}
```

独立页面优先，`gui.yml` 只作兜底。详见[日历 GUI](日历GUI.md)。

## `calendar-state.yml`

由插件按世界 UUID 自动保存。要校准时：

1. 停止服务器；
2. 备份文件；
3. 修改 `elapsed-calendar-days`、`world-day-remainder`、`last-world-day`；
4. 不要只修改只读展示用的 `date`；
5. 启动后用 `/seasons info <world>` 验证。
