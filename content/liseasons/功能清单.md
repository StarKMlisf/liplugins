# 管理员文档 · 功能清单

本页用于判断 LISeasons 是否覆盖服务器需要的季节玩法，以及每项能力应该从哪里配置。

## 日历与时间

| 功能 | 当前能力 | 入口 |
| --- | --- | --- |
| 日历模式 | 现实公历、持久化服内日历、旧版世界天数循环 | `config.yml -> time` |
| 世界独立状态 | 每个启用世界分别保存日期、季节、节气与自动状态 | `config.yml -> worlds` |
| 四季 | 春、夏、秋、冬及手动切换 | `/seasons set season` |
| 二十四节气 | 按季节组织的 24 个节气及下一节气提示 | `/seasons info`、日历 GUI |
| 自动与手动 | 自动轮转、手动设置、推进下一节气、恢复自动 | `/seasons set`、`next`、`auto` |

## 世界变化

| 功能 | 当前能力 | 入口 |
| --- | --- | --- |
| NMS 群系染色 | 批量修改区块群系调色板并发送区块数据包 | `season-color.yml` |
| 冬季结冰 | 玩家附近水面按预算结冰并铺设季节雪 | `config.yml` 世界规则 |
| 春季融化 | 只处理插件识别的季节冰雪并渐进恢复 | `config.yml` 世界规则 |
| 作物倍率 | 按季节控制原版及可选 CustomCrops 生长 | `season-effects` |
| 天气规则 | 按季节调整降水和天气反馈 | `season-effects` |
| 生物规则 | 按季节配置生物替换或相关世界行为 | `mob-rules` |
| 秋季叶块 | 可选真实叶块替换；备份仅保存在内存 | `visual-effects` |

## 玩家生存

| 功能 | 当前能力 | 入口 |
| --- | --- | --- |
| 体感温度 | 季节、节气、群系、时段、天气、海拔与环境综合计算 | `temperature.yml` |
| 潮湿度 | 入水、雨雪与干燥过程影响体感 | `temperature.yml` |
| 室内与热源 | 高度遮挡、附近方块与空气条件参与修正 | `temperature.yml` |
| 装备和物品 | 盔甲、手持物品及自定义模型可提供冷热修正 | `temperature.yml` |
| HUD 与效果 | 温度文本、警告和高低温事件 | `messages.yml`、`temperature.yml` |

## 事件与节日

| 功能 | 当前能力 | 入口 |
| --- | --- | --- |
| 季节事件 | 每季 4 个默认事件，共 16 个事件配置 | `season-events.yml` |
| 夜间流星雨 | 高空轨迹、辐射方向、随机流星、尾焰与暗飞行 | `meteor-night` |
| 陨石奖励 | 落点爆闪、掉落物、概率和奖励限制 | `season-events.yml` |
| 现实日期节日 | 19 个默认节日与自定义日期内容 | `festivals.yml` |

## 信息与界面

| 功能 | 当前能力 | 入口 |
| --- | --- | --- |
| 六页日历 GUI | 总览、月份节气、全年节气、体温、事件与节日 | `gui/*.yml` |
| 完整自定义 | 字符布局、槽位、材质、名称、Lore、动作和季节变体 | `gui.yml`、`gui/*.yml` |
| MiniMessage | 玩家文本支持渐变、RGB 与格式化 | `messages.yml` |
| PlaceholderAPI | 日期、世界、模式、季节、节气和温度占位符 | PAPI 可选前置 |
| 只读 API | 其他插件通过 ServicesManager 读取季节快照 | `LISeasonsApi` |

## 运维与兼容

| 功能 | 当前能力 | 说明 |
| --- | --- | --- |
| 配置补全 | 新版本补齐缺失默认节点，不覆盖已有自定义值 | 升级后仍应检查变更日志 |
| Paper 与 Folia | 普通主线程与区域调度路径分别处理 | 不代表所有第三方调用都线程安全 |
| 高在线预算 | 玩家轮转、区块半径和共享预算限制单轮工作量 | 见性能文档 |
| NMS 降级 | 签名不匹配时停用染色模块，其他系统继续运行 | 不回退到旧版逐点刷新 |
| 版本矩阵 | 1.21.11、26.1.2 与 26.2 | 以后端内部签名验证为准 |

## 当前边界

- 群系染色会保存到世界数据，当前没有原始群系自动回滚。
- 秋季叶块替换的原块备份只保存在内存，重启后不保证自动还原。
- 流星视觉是否清晰仍受客户端粒子、光影、资源包与视距影响。
- 配置存在不代表对应字段一定在当前版本被运行逻辑读取；以专题文档标注为准。
