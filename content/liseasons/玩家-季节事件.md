# 玩家指南 · 季节事件与流星雨

季节事件是随机落到玩家身上的短时气候片段，不是需要报名、接取或完成的任务。事件命中时，你会看到提示，并收到对应的药水、伤害、粒子或声音效果。

> 本页只描述 1.0.65 默认配置中真正执行的效果。菜单里的介绍文字可由服主自定义，不代表插件会自动实现文字中没有配置的奖励、刷怪、交易或世界改造。

## 事件如何来到玩家身边

自然事件需要同时满足当前季节、事件已启用、个人冷却结束和随机概率命中。一次检查最多选择一个事件，因此同一时刻不会把整季事件全部叠到你身上。

玩家不能手动触发事件：

- `/seasons event list`：查看服务器载入了哪些事件配置；
- `/seasons event info`：查看事件类型和配置数量；
- 日历“季节告示板”：查看当前启用的事件及说明；
- `/seasons event trigger ...`：仅管理员可用。

`event list` 不是天气预报。看到 `meteor-night` 只代表配置存在，不代表今晚一定出现流星雨；它甚至可能已被服主停用。

## 默认事件的真实效果

药水等级按原版显示，`I` 表示一级。粒子、声音和聊天提示在每个事件中都会同时出现，这里只列最影响玩法的部分。

### 春季

| 事件 | 实际玩法效果 |
| --- | --- |
| 风和日丽 | 生命恢复 I，60 秒 |
| 微风习习 | 速度 I，54 秒 |
| 春寒料峭 | 受到 2 点伤害（1 颗心） |
| 春雨绵绵 | 缓慢 I，45 秒 |

### 夏季

| 事件 | 实际玩法效果 |
| --- | --- |
| 烈日炎炎 | 缓慢 I，45 秒 |
| 盛夏晴空 | 急迫 I，60 秒 |
| 流星之夜 | 启动专用夜间流星雨；详见下节 |
| 雷暴季 | 电光粒子、雷声音与提示；不会自动强化苦力怕 |

### 秋季

| 事件 | 实际玩法效果 |
| --- | --- |
| 丰收时节 | 急迫 I，60 秒 |
| 落叶纷飞 | 落叶般粒子、声音与提示 |
| 秋雨连绵 | 缓慢 I，45 秒 |
| 南瓜庆典 | 女巫粒子、庆祝声音与提示；不会自动生成糖果 |

### 冬季

| 事件 | 实际玩法效果 |
| --- | --- |
| 大雪纷飞 | 缓慢 I，45 秒；事件本身只播放雪花、声音和提示 |
| 极寒之夜 | 受到 2 点伤害、约 2 秒盲目、雪花和声音 |
| 冰霜晨雾 | 盲目 I，45 秒 |
| 冬日庆典 | 烟花粒子、发射声音与提示；不会自动生成礼物箱 |

冬季世界本身仍可能按季节规则积雪和结冰，但那是持续的世界规则，不是“大雪纷飞”事件额外改造了地面。

## 真正的夜间流星雨

默认流星之夜只会在夏季、主世界类环境和夜间自然开始。触发后，一场会在玩家视线附近的高空依次划过 `8～13` 颗流星：

- 大多数流星共享一个大致辐射方向，同时带有角度偏差；
- 约 `22%` 是不跟随共同方向的偶发流星；
- 起点位于观察者上方约 `90～150` 格，普通流星会在高空燃尽；
- 每颗流星有 `8%` 概率尝试坠向玩家附近已加载区域；
- 坠地流星会先在离地 `32～52` 格处熄灭，暗飞行片刻后在落点爆闪；
- 落点只有粒子和声音，不破坏方块，也不造成爆炸伤害。

## 怎么看清流星

1. 在夜晚前往平原、海岸、山顶或大型屋顶等视野开阔处；
2. 仰望高空并缓慢转动视角，不要只盯着地平线；
3. 将客户端“粒子”调为“全部”或至少“减少”；
4. 避免站在树冠、洞穴、玻璃穹顶或高墙之间；
5. 听到紫水晶提示并收到“流星雨即将划过天空”后，立即观察四周高空。

流星的随机方位和高空轨迹意味着它不会每次从同一侧出现，也不会贴着地面飞过。

## 陨星奖励怎么找

坠地流星默认有 `70%` 概率产生奖励，每次成功掉落抽取 `1～2` 次。默认池包含：

- 星辉紫晶（紫水晶碎片）；
- 陨铁碎片（铁粒）；
- 星金碎片（金粒）；
- 稀有的寂星残片（回响碎片）。

当奖励真的生成时，触发这场流星雨的玩家会收到落点坐标。按坐标寻找爆闪位置；掉落物默认带发光描边，并在 1 秒后可拾取。其他玩家即使看到了流星，也不一定收到这条精确坐标消息。

没有坐标消息通常表示本场没有坠地奖励、坠地尝试没有找到安全已加载落点，或服主关闭/修改了奖励。

## 事件说明和实际表现不一致

日历中的事件说明来自服务器配置，实际执行效果来自同一事件的效果列表。若说明写着“动物增加”“村民降价”“礼物箱刷新”，但游戏里只有粒子或短时药水，这是配置文案与实际效果不一致，应由管理员修正文案或补充玩法，不是玩家操作错误。
