# 更新日志

## 1.0.70 · Folia 流星雨粒子修复（2026-09-02）

- 修复 Paper/Folia 1.21.10+ 中 `FLASH` 粒子改为强制要求 `org.bukkit.Color` 后，流星第一帧报 `missing required data class org.bukkit.Color` 并全部终止的问题。
- 运行时按服务端真实 `Particle#getDataType()` 自动选择：新版补颜色、Paper 1.21.1 旧契约继续传空数据。
- 配置中的其他数据型粒子不兼容时自动回退安全粒子，避免一项错误配置让整颗流星和后续落点流程消失。
- 保留现有 `season-events.yml` 自定义值；新增中文注释说明允许范围。
- 85 项回归测试通过；Folia 1.21.11 成品运行验证确认 `FLASH -> Color`，带色闪光和流星落点渲染均成功。

请停服替换为 `LISeasons-1.0.70.jar` 后完整启动。仅执行 `/seasons reload` 无法替换旧版类文件。

## 1.0.69 · Residence 与安全积雪（2026-08-31）

### 修复与兼容

- 冬季结冰、常规铺雪、暴风雪铺雪接入 Bukkit `BlockFormEvent`，春季融化接入 `BlockFadeEvent`，遵守 Residence 与其他保护插件的取消结果。
- Residence 的 `iceform` 控制雪层和冰生成，`icemelt` 保护雪层、普通冰和霜冰。雪块/细雪/浮冰/蓝冰的保留请使用 LISeasons 材质融化开关，避免误解 Residence 的原生保护范围。
- 铺雪使用原版支撑检测；支持上半台阶、双台阶和倒置楼梯，跳过下半台阶、普通楼梯等无合适顶面的方块，不覆盖建筑。
- 修复暴风雪用地表方块本身判断空气导致积雪失败；现在从表面上方一格尝试。
- 暴风雪默认尊重玩家独立天气，兼容领地晴天；普通水雪循环仍独立工作，可由领地 `iceform` 禁止。
- Folia 的随机铺雪、结冰、近身融雪按目标方块区域调度，执行前复查配置/季节/区块。
- 事件中已被其他插件修改的方块不会再次覆盖；保留受保护雪层下的草方块雪态。

### 配置与升级

新增 `season-world-rules.snow-accumulation.allow-top-slabs`、`allow-top-stairs`、`allow-leaves` 和 `visual-effects.respect-player-weather`，均有中文用途与取值说明。升级仅补全缺失节点/注释，保留原配置与玩家建筑。

停服备份后替换 `LISeasons-1.0.69.jar`，无需删除配置文件。PacketEvents 2.13.0+ 仍为强制前置；Residence/CMILib 可选，未安装不影响 LISeasons。

### 验证范围

81 项单元测试通过；Paper 1.21.1 与 Folia 1.21.11 搭配 Residence 6.0.0.1 + CMILib 1.5.8.1，分别通过 31 项冰雪/领地/方块支撑/区域线程实服检查。未进行真实客户端视觉验收或长期多人压测，详见[构建与兼容记录](开发构建与版本兼容.md)。

原版不能让雪层与下半台阶共用一格。本版不提供“贴面雪皮”模拟；完整规则和配置见[季节效果与世界规则](季节效果与世界规则.md)。
