# LISeasons

LISeasons 的使用、配置、维护和扩展指南。

> 本文档对应 `LISeasons 1.0.71`。季节染色通过 PacketEvents 生成玩家独立的客户端群系视图，不修改世界真实群系。

本次更新修复 Folia/Paper 1.21.10+ 的流星粒子 data 兼容问题，详见[更新日志](更新日志.md)。

## 从这里开始

玩家请阅读[玩家文档](玩家文档.md)，了解日期、节气、体温、日历菜单、季节事件和常用指令。

服主与运维人员请阅读[管理员文档](管理员文档.md)，了解安装、世界启用、配置文件、客户端染色、性能预算和故障排查。

附属插件开发者请阅读[附属插件 API](附属插件API.md)与[开发构建和版本兼容](开发构建与版本兼容.md)。

需要立即使用时：

- 普通玩家从[玩家文档 · 总览](玩家文档.md)开始；

## 核心系统

LISeasons 把一个服务器世界拆成六个相互连接、但可以分别配置的系统：

| 系统 | 负责内容 | 典型入口 |
| --- | --- | --- |
| 世界日历 | 日期来源、季节、二十四节气和自动轮转 | `config.yml -> time`、`/seasons info` |
| 世界气候 | 季节色调、天气、作物、冬冻春融和生物规则 | `config.yml`、`season-color.yml` |
| 玩家体感 | 体温、潮湿、时段、海拔、室内、水、装备、热源和季节 Buff BossBar | `temperature.yml`、`season-buff-boss-bar` |
| 季节内容 | 16 个季节事件、真实感流星雨和陨石奖励 | `season-events.yml` |
| 现实节日 | 按服务器现实日期显示节日记录与到来提醒 | `festivals.yml` |
| 信息界面 | 六页日历 GUI、命令、消息和 PlaceholderAPI | `gui/*.yml`、`messages.yml` |

这种拆分意味着“冬天不结冰”“群系没有变色”和“体温没有变化”属于三条不同的处理路径。排查前先确认问题属于日历状态、世界规则、玩家体感、事件还是显示层，可以避免在错误的配置文件中反复修改。

## 重要的安全边界

季节群系染色不会修改或保存服务端区块群系，关闭后无需恢复群系。注意：冬冻春融和秋季真实叶块替换仍属于世界方块变化，生产世界仍建议保留常规备份。

`calendar-state.yml` 保存服内日历的运行状态，由插件维护。服务器运行时不要手工改写，也不要把其他世界或旧服务器中的状态文件直接覆盖到生产服。

管理员或 OP 账号可能绕过普通权限限制。测试玩家指令、菜单和 PlaceholderAPI 显示时，应使用没有 `liseasons.admin` 的普通账号再次验证。

- 可以稳定复现问题的步骤；
- 涉及的配置片段，并隐藏密码、令牌和服务器地址；
- 视觉问题附客户端录像，并说明粒子、光影与资源包设置。
