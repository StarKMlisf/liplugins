# 玩家指南 · 日历与节日

季节手账把世界日期、体温、事件与现实节日放在一个箱子菜单里。它是查看信息的入口，不会因为点击某个事件或节日图标就主动触发玩法。

> 菜单标题、物品、排列和文字都可以由服主修改。下面说明的是 1.0.65 默认六页结构。

## 打开和关闭

```text
/seasons calendar
```

该指令只能由游戏内玩家执行。默认底栏用于换页：书本回到首页、地图查看本月节气、书架查看全年节气、营火进入温度页、烈焰棒进入事件页、蛋糕进入节日页，屏障关闭菜单。

## 六页分别看什么

| 页面 | 主要内容 | 什么时候用 |
| --- | --- | --- |
| 手账首页 | 当前季节、日期、世界、本月节气、当前节气、体温、天气和下一节气 | 登录后快速确认今天的状态 |
| 本月节气 | 当前月份包含的节气 | 安排短期农事与活动 |
| 全年节气 | 二十四节气完整顺序 | 查看整年的季节进度 |
| 温度小屋 | 玩家体感、空气温度、潮湿、季节底温和环境说明 | 判断冷热来源与物品是否生效 |
| 季节告示板 | 全部已启用季节事件、概率、冷却与效果摘要 | 了解可能遇到的随机事件 |
| 节日纪念册 | 全年已加载节日、日期和介绍，并标记今天 | 查看服务器记录的现实节日 |

事件和节日较多时会分页，使用上一页、下一页图标继续浏览。

## 日历日期和节日日期不是一回事

季节手账首页显示的是当前世界的季节日期；“今日节日”使用服务器操作系统的现实日期。两者可以不同：

- 服内日历可能显示春季某日；
- 现实日期可能正好是国庆节；
- 此时世界仍按服内日期计算季节，但节日纪念册会把现实今天标记出来。

因此不要根据服内日期推断节日，也不要根据现实节日推断当前季节。查询现实今日节日应使用：

```text
/seasons festival today
```

## 默认节日会做什么

LISeasons 1.0.65 的节日系统负责日期记录和到来提醒：

- 在对应现实日期向玩家发送节日到来消息；
- 同时向服务器广播一次节日来临；
- 同一节日对同一玩家一天只自然提醒一次；
- 节日纪念册展示日期、名称和祝福说明。

默认不会自动发物品、生成烟花、开启小游戏或创建节日任务。描述中的“赏月”“发糖”“办活动”等是氛围文字，不是承诺已经实现的玩法；额外活动是否存在要看服务器公告和其他插件。

## 节日查询指令

| 指令 | 作用 |
| --- | --- |
| `/seasons festival today` | 查看服务器现实日期对应的已启用节日 |
| `/seasons festival list` | 按日期列出全部已加载节日配置 |
| `/seasons festival info` | 查看节日类型和配置数量 |

`festival list` 和节日纪念册用于浏览配置，可能包含已被服主停用的记录；`festival today` 才只返回今天已启用的节日。

## 菜单数据没有更新怎么办

1. 关闭菜单后重新执行 `/seasons calendar`；
2. 切换世界后重新打开，因为季节与体温属于当前世界；
3. 对比 `/seasons info`，确认该世界已启用四季；
4. 若只有节日日期异常，请管理员检查服务器系统日期与时区；
5. 若图标或文字缺失，截图对应页面并把服务器版本交给管理员。
