# 玩家指南 · 看懂四季与节气

LISeasons 让每个启用世界拥有自己的日期、季节与二十四节气。你不需要知道服务器采用哪种日历算法，只需要先确认自己当前所在的世界。

> 以下季节表现是 1.0.61 默认值。颜色、作物、天气、冰雪和提示都可以由服主调整。

## 用一条指令看懂今天

```text
/seasons info
```

默认返回内容可以这样理解：

| 信息 | 对玩家意味着什么 |
| --- | --- |
| 当前节气与日期 | 今天所处的节气阶段；日期可能是服内日历，也可能跟随现实日期 |
| 特征 | 当前季节最重要的环境与生存提示 |
| 作物生长速度 | 露天原版作物相对正常速度的变化 |
| 下一节气 | 距离下一次节气切换还有多久 |
| 世界 | 这条结果属于哪个世界 |
| 温度 | 当前位置的温度摘要 |

`/seasons info <世界名>` 可以查询其他已加载世界。若要查看装备、潮湿和附近热源共同影响后的玩家体温，请以操作栏或日历的温度页为准。

## 默认四季会发生什么

| 季节 | 世界观感 | 露天农事 | 建议 |
| --- | --- | --- | --- |
| 春 | 花林般的鲜绿与花色；冬季冰雪逐步融化 | 生长速度约 `+25%` | 整理田地，留意春雨与短时春寒 |
| 夏 | 明亮绿色，天气偏热；可能出现落苹果与流星之夜 | 生长速度约 `+100%` | 注意遮阴和降温，夜晚去开阔地观察天空 |
| 秋 | 草木偏黄，部分树叶呈暖橙色，并有落叶效果 | 正常速度 | 适合集中收获，气温会逐渐转凉 |
| 冬 | 草叶偏白，夜晚可见极光，地表可能积雪和结冰 | 默认停止露天作物生长 | 避免长时间入水，准备室内农田、皮甲和热源 |

这里的“露天”指作物上方没有遮盖。服务器若关闭或修改季节规则，实际倍率会不同。

## 二十四节气怎么分

每个季节有六个节气。当前节气会显示在加入提示、换节气标题、`/seasons info` 和日历中。

| 季节 | 六个节气 |
| --- | --- |
| 春 | 立春、雨水、惊蛰、春分、清明、谷雨 |
| 夏 | 立夏、小满、芒种、夏至、小暑、大暑 |
| 秋 | 立秋、处暑、白露、秋分、寒露、霜降 |
| 冬 | 立冬、小雪、大雪、冬至、小寒、大寒 |

节气不只是名称。默认体温系统会在不同节气叠加不同冷暖修正，因此同一季节的开头和末尾也可能有明显温差。

## 换季时你会看到什么

- 屏幕中央出现新节气与季节标题；
- 聊天中收到世界进入新季节或节气的提示；
- 玩家附近草地、树叶、水面和天空色调逐步改变；
- 冬季露天静水逐步结冰并铺薄雪；
- 离开冬季后，普通冰、霜冰和雪类逐步融化；
- 温度与露天作物规则开始按新季节计算。

颜色与冰雪使用渐进刷新，不会在一帧内覆盖整个世界。已经离线很久或距离玩家很远的区域，会在玩家重新接近后继续处理。

## 为什么两个世界不是同一个季节

主世界、资源世界和活动世界可以分别启用或停用四季，也可以采用不同进度。进入新世界后，以该世界的 `/seasons info` 和日历首页为准；下界、末地或小游戏世界也可能完全不启用季节效果。

## 看不到季节变化怎么办

1. 执行 `/seasons info`，确认当前世界已启用四季；
2. 等待附近区块逐步刷新，或离开后重新进入这片区域；
3. 对比草地、树叶和天空，不要只观察一种方块；
4. 若冬季没有结冰，确认观察的是露天静水，而不是流水、室内水或受保护区域；
5. 仍无变化时，把世界名、当前季节、坐标和截图交给管理员。
