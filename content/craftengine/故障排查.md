# 故障排查与上线检查

定位启动失败、YAML 错误、紫黑贴图、资源包下载、ID 和插件联动问题。

## 先按故障层级判断

```text
插件是否启用
  ↓
配置是否加载
  ↓
资源包是否生成
  ↓
资源包是否上传并被玩家下载
  ↓
模型贴图是否正确
  ↓
方块/家具/配方逻辑是否正确
  ↓
第三方插件是否按完整 CE ID 联动
```

不要一看到紫黑贴图就修改物品 YAML，也不要一看到命令报错就重装全部内容。先确认故障属于哪一层。

## 插件没有启用

1. 查看启动日志中最早的 CraftEngine `ERROR`。
2. 核对 Java、Minecraft、Paper/Folia 与 CraftEngine 版本。
3. 检查是否同时放了多个 CraftEngine Jar。
4. 确认下载文件完整，不是网页或损坏的重命名文件。
5. 移除通用热卸载工具造成的残留后完整重启。

后续 `/ce` 报“未知指令”通常只是插件未成功启用的结果，不是根因。

## YAML 无法加载

常见原因：

- 使用 Tab；
- 冒号后漏空格；
- 列表 `-` 缩进错误；
- 包含 `:`、`#`、渐变标签的复杂文本没有引号；
- 同一个 ID 在多个文件重复定义；
- 从旧教程复制了当前版本已变化的节点。

修复时一次只处理控制台报告的第一个文件和第一处行号。第一个缩进错误可能制造大量后续假错误。

## 物品还是原版外观

- 配置只有 `material`，没有 `texture` 或 `model`；
- 客户端未接受资源包；
- 修改贴图后只执行了 `/ce reload config`；
- 玩家仍缓存旧资源包；
- 模型生成成功，但资源包上传的是旧 ZIP。

执行 `/ce reload all`，等待生成上传完成，再用 `/ce feature send-pack <玩家>` 重新发送。

## 紫黑贴图

逐项核对：

```text
配置引用：tutorial:item/ruby
实际贴图：assets/tutorial/textures/item/ruby.png
```

- 命名空间是否一致；
- 文件名大小写是否一致；
- 模型 JSON 是否引用磁盘绝对路径；
- PNG 是否放在 `textures/item` 或 `textures/block`；
- 贴图尺寸是否规范；
- 多个资源包是否写入同一模型/贴图路径；
- CraftEngine 生成后的最终 ZIP 中是否真的包含该文件。

只检查源目录不够，最终合并包才是客户端实际收到的内容。

## 改了内容但没有变化

| 改动 | 正确操作 |
| --- | --- |
| 物品名称、Lore、属性 | `/ce reload config` |
| 配方 | `/ce reload recipe` |
| PNG、JSON 模型、字体、声音 | `/ce reload all` |
| `commands.yml` 注册路径 | 完整重启 |
| CraftEngine Jar | 停服替换并完整重启 |

## 找不到 ID 来自哪里

```text
/ce resource search craftengine:item tutorial:ruby
/ce resource search craftengine:block tutorial:topaz_block
```

使用 Tab 补全选择资源类型。若同一路径冲突，检查所有启用内容包及 [官方文件冲突文档](https://xiao-momi.github.io/craft-engine-wiki/reference/file_conflict/)。

## 第三方插件无法识别 CE 物品

确认第三方插件：

- 明确支持当前 CraftEngine 版本；
- 比较完整 `namespace:id`；
- 没有只比较原版 `Material`；
- 在 CraftEngine 内容重载后刷新缓存；
- 未在异步数据库线程读取玩家手中 `ItemStack`；
- 扣除前重新核对当前物品 ID。

如果两个 CE 物品都使用 `PAPER`，只比较 `PAPER` 必然会误判。

## 家具或方块残留

- 检查插件是否安全关闭；
- 检查资源 ID 是否在更新中被删除或改名；
- 检查区块卸载/加载后能否恢复；
- 检查家具碰撞箱和显示实体是否同时清理；
- Folia 环境查看是否有跨区域线程错误；
- 不要直接用实体清理插件批量删除，先备份并确认 CE 官方恢复/迁移方案。

## 上线前检查

```text
[ ] 从空客户端缓存加入服务器并成功下载资源包
[ ] 自定义物品名称、Lore、贴图与模型正确
[ ] 方块可放置、挖掘、掉落并在重启后保持
[ ] 家具朝向、点击、碰撞、座位和掉落正确
[ ] 配方在工作台/熔炉等目标界面可用
[ ] 权限不足时不会绕过条件或消耗物品
[ ] /ce reload all 后第三方插件仍能识别内容
[ ] 完整重启后没有重复 ID、残留实体或注册错误
[ ] 已备份 resources、配置和相关世界数据
```

仍无法定位时，提交完整启动日志、Java/Paper/CraftEngine 版本、最小复现配置、资源目录树以及客户端看到的实际画面。
