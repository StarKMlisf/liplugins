# 常用命令、热重载与调试

物品、资源、上传、搜索、重载命令及必须完整重启的场景。

大部分命令以 `/craftengine` 开头，默认别名是 `/ce`。具体启用状态、权限和命令路径由 `plugins/CraftEngine/commands.yml` 控制。

## 重载命令

| 命令 | 用途 |
| --- | --- |
| `/ce reload config` | 重载物品、方块、家具等配置 |
| `/ce reload recipe` | 重载配方 |
| `/ce reload pack` | 重新生成资源包 |
| `/ce reload all` | 重载配置、配方并重建资源包 |
| `/ce upload` | 手动上传当前资源包到已配置后端 |

不带参数的 `/ce reload` 默认执行 `config`。改动 PNG、模型、字体或声音后，应使用 `pack` 或 `all`。

## 物品命令

```text
/ce
/ce item browser [玩家]
/ce item get <物品ID> [数量]
/ce item give <玩家> <物品ID> [数量]
/ce item clear <玩家> <物品ID> [最大数量]
/ce item search-recipe <玩家> <物品ID>
/ce item search-usage <玩家> <物品ID>
```

`/ce` 默认打开自己的物品浏览器。批量发放前先对自己执行 `item get`，检查命名空间、名称、模型和实际身份。

## 资源包命令

```text
/ce resource list
/ce resource create <包名> [命名空间] [作者] [说明]
/ce resource enable <包名>
/ce resource disable <包名>
/ce resource search <资源类型> <资源ID>
```

`resource search` 很适合定位“这个 ID 到底由哪个文件定义”。资源类型支持 Tab 补全，例如 `craftengine:item`、`craftengine:block`。

## 向玩家重新发送资源包

```text
/ce feature send-pack <玩家>
```

先确认服务器生成和上传的是新包，再发送给玩家。若 URL 未变且缓存策略不合理，客户端可能继续使用旧文件，应同时核对哈希和下载响应。

## 哪些改动必须重启

以下情况不要依赖热重载：

- 更换 CraftEngine Jar；
- 修改 `commands.yml` 中命令注册路径、启用状态或权限；
- 更新 Java、Paper/Folia 或底层依赖；
- 第三方插件只在启动阶段建立 CE 挂钩；
- 更新涉及世界存储、底层注册或官方明确要求重启的功能；
- 使用通用热卸载插件后出现重复监听器、残留实体或类加载错误。

## 操作习惯

1. 保存配置前保留一份可回滚版本。
2. 一次只改一个内容包或一个功能组。
3. 执行重载后等待完成，不要连续刷命令。
4. 先看控制台首个错误，再处理后续连锁报错。
5. 用 `/ce resource search` 验证实际生效来源。
6. 对模型贴图做客户端实机检查。

## 权限和静默执行

官方命令参考说明，大多数命令支持 `--silent` 或 `-s` 静默参数。自动化脚本使用前应在当前版本测试参数位置，并给脚本账号最小权限，不要直接授予全量管理员权限。
