# 自定义方块与家具

放置物品、视觉方块状态、硬度掉落、家具变体、碰撞箱和座位。

## 最小可放置方块

先准备贴图：

```text
resourcepack/assets/tutorial/textures/block/topaz_block.png
```

再配置放置物品与方块：

```yaml
items:
  tutorial:topaz_block:
    material: paper
    model: tutorial:block/topaz_block
    behavior:
      type: block_item
      block:
        state:
          auto_state: note_block
          texture: tutorial:block/topaz_block
```

执行：

```text
/ce reload all
/ce item get tutorial:topaz_block 1
```

右击地面即可放置。`block_item` 表示物品用于放置方块，`auto_state` 让 CraftEngine 从可用视觉状态中分配一种表现。

## 硬度、工具和声音

在 `block` 下加入：

```yaml
settings:
  hardness: 4.5
  sounds:
    break: minecraft:block.stone.break
    step: minecraft:block.stone.step
    place: minecraft:block.stone.place
    hit: minecraft:block.stone.hit
    fall: minecraft:block.stone.fall
  tags:
    - minecraft:mineable/pickaxe
```

视觉、碰撞和挖掘行为是不同层面。只看到正确贴图，不代表工具速度、掉落或碰撞已经正确。

## 让方块掉落自身

没有掉落表时，方块可能什么也不掉。在 `block` 下加入：

```yaml
loot:
  template: default:loot_table/self
```

上线前分别测试：生存模式、创造模式、精准采集、爆炸、活塞和保护插件区域。需要更复杂掉落时查阅官方 Loot Table 文档，不要假设所有原版事件都会自动生成 CE 掉落。

## 方块状态选择

常见自动状态组：

| 状态组 | 典型外形 | 适合内容 |
| --- | --- | --- |
| `note_block` / `solid` | 完整方块 | 矿石、砖块、机器 |
| `tripwire` | 很薄 | 作物、小型植物、地面装饰 |
| `leaves` | 完整透明方块 | 叶子、半透明方块 |

状态组影响客户端表现和碰撞候选。正式内容应根据当前官方配置参考选择，避免不同插件或资源包抢占同一视觉状态。

## 第一个家具

家具使用显示实体表现，不被 1×1×1 方格完全限制。先准备 `models/item/chair.json` 及其贴图，再定义：

```yaml
items:
  tutorial:my_chair:
    material: paper
    model: tutorial:item/chair
    behavior:
      type: furniture_item
      rules:
        ground:
          rotation: four
          alignment: center
      furniture:
        variants:
          ground:
            elements:
              - item: tutorial:my_chair
            hitboxes:
              - position: 0,0,0
                type: shulker
```

应用后：

```text
/ce reload all
/ce item get tutorial:my_chair 1
```

## 家具交互与座位

在 hitbox 中按当前版本配置交互和座位：

```yaml
hitboxes:
  - position: 0,0,0
    type: shulker
    blocks_building: true
    interactive: true
    interaction_entity: true
    seats:
      - 0,0.5,0
```

并可在 `furniture` 下配置耐久、声音与掉落：

```yaml
settings:
  hit_times: 3
  sounds:
    break: minecraft:block.bamboo_wood.break
    place: minecraft:block.bamboo_wood.place
    hit: minecraft:block.bamboo_wood.hit
loot:
  template: default:loot_table/furniture
  arguments:
    item: tutorial:my_chair
```

## 实机验收

- 四个朝向模型没有倒转；
- 点击范围与模型大小一致；
- 玩家不会卡进碰撞箱；
- 座位高度和朝向正确；
- 破坏次数、声音与掉落正确；
- 区块卸载、重启和移除后没有残留显示实体；
- Folia 服务端上的相关附属插件没有跨区域访问实体。

官方参考：[Your First Block](https://xiao-momi.github.io/craft-engine-wiki/getting_start/first_block/) 与 [Your First Furniture](https://xiao-momi.github.io/craft-engine-wiki/getting_start/first_furniture/)。
