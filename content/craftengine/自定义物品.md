# 第一个自定义物品

从三行 YAML 开始，加入中文名称、Lore、贴图、精确 ID 与发放验证。

## 最小物品

在 `plugins/CraftEngine/resources/tutorial/configuration/items.yml` 写入：

```yaml
items:
  tutorial:ruby:
    material: paper
```

应用配置并获取物品：

```text
/ce reload config
/ce item get tutorial:ruby 1
```

这里的 `tutorial:ruby` 是物品真实身份，`paper` 只是它的原版底材。其他插件若只检查 `Material.PAPER`，会把所有纸底材 CE 物品混在一起；正确做法是读取完整 CE ID。

## 中文名称与 Lore

```yaml
items:
  tutorial:ruby:
    material: paper
    data:
      item_name: "<!i><gradient:#FF6B9D:#A66CFF>云梦红玉"
      lore:
        - "<!i><gray>凝结着泽国灵气的矿石"
        - "<!i><dark_gray>ID: tutorial:ruby"
```

`<!i>` 用于关闭 Minecraft 物品文本默认斜体。颜色使用 MiniMessage；正式发布时建议把显示文本与稳定 ID 分开管理，改名不改 ID。

## 加入贴图

把 PNG 放在：

```text
resourcepack/assets/tutorial/textures/item/ruby.png
```

然后加入一行：

```yaml
items:
  tutorial:ruby:
    material: paper
    texture: tutorial:item/ruby
    data:
      item_name: "<!i><gradient:#FF6B9D:#A66CFF>云梦红玉"
      lore:
        - "<!i><gray>凝结着泽国灵气的矿石"
```

贴图属于资源包改动，因此执行：

```text
/ce reload all
/ce item get tutorial:ruby 1
```

## 常用组成部分

| 节点 | 用途 |
| --- | --- |
| `material` | 服务端原版底材 |
| `data` | 名称、Lore、附魔、组件等物品数据 |
| `texture` / `model` | 客户端外观 |
| `settings` | 燃烧时间、标签、可修复等 CE 机制 |
| `behavior` | 放置方块、家具或其他交互行为 |
| `events` | 点击、攻击、消耗等事件响应 |
| `category` | 物品浏览器或分类位置 |

字段会随 Minecraft 和 CraftEngine 版本扩展。复杂组件应查阅当前 [官方物品配置参考](https://xiao-momi.github.io/craft-engine-wiki/configuration/item/)，不要照搬旧版 NBT 示例。

## 发放与清理

```text
/ce item get tutorial:ruby 16
/ce item give Steve tutorial:ruby 16
/ce item clear Steve tutorial:ruby 64
```

命令参数支持 Tab 补全时优先使用补全结果，避免把路径或命名空间拼错。

## 常见错误

- YAML 用了 Tab：改为空格。
- ID 没有命名空间：改成 `tutorial:ruby`。
- PNG 放错目录：物品贴图放到 `textures/item/`。
- 修改贴图后只执行 `reload config`：改用 `reload all`。
- 名称和 Lore 变成斜体：在每个独立文本组件前加 `<!i>`。
- 第三方插件把 CE 物品认成普通纸：该插件需要按完整 CE ID 适配。

官方参考：[Your First Item](https://xiao-momi.github.io/craft-engine-wiki/getting_start/items/)。
