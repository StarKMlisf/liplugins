# 签文、费用与奖励

每条签文可以配置名称、说明、抽取权重、物品、经济奖励和药水效果。只有通过配置校验的签文才会进入抽取池。

## 扣费与保护

1. 检查玩家权限、今日次数和经济余额。
2. 从有效签文池抽取结果。
3. 扣除本次费用并发放奖励。
4. 保存抽签次数和上次签位。

没有有效签文时不会扣费。奖励发放过程中发生异常时，插件会自动尝试退款；退款失败会明确提示需要管理员处理。

## 药水效果格式

格式为 `效果名:持续时间:等级`，等级从 `0` 开始，因此等级 `1` 表示 II 级。

```yaml
effects:
  - "SPEED:30s:1"
  - "REGENERATION:2m:0"
  - "NIGHT_VISION:600:0"
  - "LUCK:永久:0"
```

持续时间支持 `t`、`ms`、`s`、`m`、`h`、`d`；无单位数字兼容按秒处理。`永久`、`infinite` 和 `-1` 表示永久效果。

## 物品与金币

物品奖励应使用服务端当前版本存在的材质名。经济奖励与抽签费用通过 Vault 处理，需要 Vault 和一个正常工作的经济插件。
