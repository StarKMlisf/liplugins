# 安装与更新

## 运行要求

- Paper `26.1.2`
- Java 25
- Vault 与一个 Vault 经济插件，例如 XConomy
- PlaceholderAPI 可选

## 首次安装

1. 安装 Vault 和经济插件并确认经济功能正常。
2. 将 LichQian Jar 放入 `plugins/`。
3. 完整启动服务器，生成 `plugins/LichQian/config.yml`。
4. 停服后调整费用、每日次数、时区、签文和界面。
5. 再次启动并用 `/lottery status`、`/lottery draw` 验证。

## 更新

1. 停服并备份 `plugins/LichQian/`。
2. 替换 Jar 后完整启动服务器。
3. 检查控制台配置加载信息。
4. 执行 `/lichqian reload` 验证现有配置。

插件升级时只补全缺少的节点，不覆盖已有费用、消息、签文和 GUI。YAML 格式错误时重载会被拒绝，原文件不会被替换。
