# 故障排查

## 无法抽签

依次检查：

1. 玩家是否有 `lichqian.use`。
2. 是否达到当前周期次数上限。
3. Vault 和经济插件是否正常加载。
4. 玩家余额是否达到抽签费用。
5. 配置中是否至少有一条有效签文。

没有有效签文时插件不会扣费。

## 重载失败

`/lichqian reload` 拒绝应用时，查看控制台中的 YAML 行号和错误。常见原因是缩进错误、冒号后缺少空格或带特殊字符的文本没有加引号。

修正原文件后再次重载。插件不会用默认配置覆盖损坏的自定义文件。

## 奖励异常

- 背包已满：多余物品会掉落在玩家脚下。
- 发奖中途报错：插件会尝试退款，并在失败时提示人工处理。
- 药水等级不对：配置等级从 0 开始，`1` 表示 II 级。
- 每日重置不对：确认 `time.zone` 是合法 IANA 时区，并核对 `daily_reset`。

提交问题时附完整启动日志、Paper 构建、Java 版本、LichQian 版本与相关配置片段。
